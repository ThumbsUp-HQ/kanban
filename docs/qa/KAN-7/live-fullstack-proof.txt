--- 6. Live Stack Findings & Surgical Remediations ---
Finding 1: Unauthenticated & mfa_pending WebSocket/SSE Console Errors (403 / 401)
- Root Cause: RealtimeProvider / RealtimeClient initiated connection attempts regardless of session authentication state, attempting /ws (403) and /sse (401) on /login and during 2FA.
- Remediation:
  1. Gated RealtimeClient.connect() strictly behind isSessionAllowed() (session.authenticated === true && session.mfa_pending !== true).
  2. In RealtimeProvider, added isPublicAuthRoute() detection (/login, /setup, /activate) and useQuery for session on protected routes.
  3. Added session update observer in RealtimeClient (setSession) that immediately closes active connections if session becomes invalid.
  4. Hardened WebSocket onclose to terminate cleanly without retry or SSE fallback on close code 4401 (WS_CLOSE_UNAUTHENTICATED) or 4403.
  5. Added cleanup handlers for kb:auth-logout and storage logout events.
- Verification: 0 WebSocket/SSE attempts made while unauthenticated or mfa_pending; connection established only upon successful session authentication; 0 console errors emitted.

Finding 2: Mobile 390x844 Second-Factor Method Tabs Overflow
- Root Cause: .auth-tablist in auth.css did not specify flex-wrap: wrap, causing the three MFA tabs (Authenticator code, Passkey, Recovery code) to exceed the width of .auth-panel at 390px.
- Remediation:
  1. Added flex-wrap: wrap, width: 100%, max-width: 100%, and box-sizing: border-box to .auth-tablist.
  2. Under @media (max-width: 767px), added responsive compact layout: gap: var(--space-1, 4px), font-size: var(--text-xs, 0.75rem), padding: var(--space-2, 8px) var(--space-3, 12px), and min-height: var(--tap-min, 44px) meeting WCAG tap targets.
  3. Verified zero inline style props (0 style={{...}}) and 100% canonical CSS tokens via cssTokensAudit.test.ts.
- Verification: All three tabs wrap cleanly inside .auth-panel with scrollWidth <= clientWidth at 390px viewport width; zero horizontal overflow.
