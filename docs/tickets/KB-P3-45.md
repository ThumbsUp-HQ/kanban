### User Story
As a **developer or technical lead editing CLI-authored or agent-authored tickets, comments, stickies, and docs**, I need **a breathable ProseMirror GitHub-Flavored Markdown editor with zero mode-switcher clutter, byte-exact `sourceSlice` preservation on untouched blocks, and a `Cmd/Ctrl+Shift+M` (`📝`) raw Markdown source inspection toggle** so that **fixing a single typo in the web UI never reformats untouched Markdown tables, reference links, or fenced code blocks, and 100% of prose persists strictly as canonical UTF-8 Markdown**.

**Requirement Traceability:** `S5.1` (canonical Markdown-only invariant, zero mode-picker clutter, `Cmd/Ctrl+Shift+M` raw source inspection), `S5.2 item 5` (`attrs.sourceSlice { from, to }` byte-exact round-trip guarantee), `S6.1` (`--prose-pad`, `--text-body`, `--leading-prose`, `--font-mono`), `S6.2` (`📝` `rawMarkdown` `<EmojiHint>`), requirements `#5`, `#10`, `#15` | **Dependencies:** `KB-P3-30`, `KB-P3-31`

### Scoped Technical Actions
1. **Target Files:**
   - `kanban/web/src/editor/schema.ts` (ProseMirror GFM schema + `sourceSlice` block attrs)
   - `kanban/web/src/editor/parseMarkdown.ts` (`remark-parse` + `remark-gfm` -> ProseMirror `Node` with `sourceSlice` offsets)
   - `kanban/web/src/editor/serializeMarkdown.ts` (dirty-aware lossless `sourceSlice` + canonical GFM serializer)
   - `kanban/web/src/editor/sourceSlicePlugin.ts` (ProseMirror `Plugin` tracking block mutations and marking touched top-level blocks `dirty: true`)
   - `kanban/web/src/editor/editorSurfaceFactory.ts` (`EditorSurfaceKind`, `registerSurfaceExtension`, `createEditorPlugins` hook point for KB-P3-46, KB-P3-47, KB-P3-48, KB-P5-08)
   - `kanban/web/src/editor/MarkdownEditor.tsx` + `kanban/web/src/editor/MarkdownEditor.css`
   - `kanban/web/src/dev/EditorStory.tsx` (dev-only route `/__dev/editor`, registered under `import.meta.env.DEV || VITE_ENABLE_STORY === '1'`)
2. **ProseMirror GFM Schema (`schema.ts`) & Link Allowlist:**
   - Top-level block nodes: `paragraph`, `heading` (`level: 1..6`), `code_block` (`lang: string`, `meta: string`), `blockquote`, `bullet_list`, `ordered_list` (`order: number`), `task_list` (`task_item` with `checked: boolean`), `table` (`table_row`, `table_header`, `table_cell` with `align: 'left' | 'center' | 'right' | null`), `horizontal_rule`, and block `image_block` (`src`, `alt`, `title`).
   - Inline nodes and marks: `text`, `hard_break`, `image` (`src`, `alt`, `title`), `strong`, `em`, `strike`, `code`, `link` (`href`, `title`).
   - Every top-level block node defines `attrs.sourceSlice: { from: number; to: number } | null` (default `null`) and `attrs.dirty: boolean` (default `false`).
   - URI scheme allowlist enforced on `link.href` and `image.src` in both `parseMarkdown` and `serializeMarkdown`: allow only `https://`, `http://`, `mailto:`, `#`, `/`, and `attachment://`; any `javascript:`, `vbscript:`, `data:`, or `file:` scheme is stripped to plain text (link) or omitted (image).
3. **Byte-Exact `sourceSlice` Parser, Dirty Tracker & Serializer (`parseMarkdown.ts`, `sourceSlicePlugin.ts`, `serializeMarkdown.ts`):**
   - `parseMarkdown(markdown: string): { doc: ProseMirrorNode; originalSource: string }`:
     - Normalizes input cap (`<= 1,048,576` UTF-8 bytes; inputs exceeding `1 MiB` throw `EditorRangeError('MARKDOWN_MAX_BYTES_EXCEEDED')`).
     - Parses with `unified().use(remarkParse).use(remarkGfm)` using `mdast` positional byte/code-unit offsets (`node.position.start.offset`, `node.position.end.offset`) so each top-level ProseMirror child gets `attrs.sourceSlice = { from, to }` and `attrs.dirty = false`.
   - `sourceSlicePlugin`:
     - Inspects every `Transaction` where `tr.docChanged === true` (excluding initial load and programmatic raw-toggle resets).
     - Maps each `StepMap` range onto top-level child indices (`0 .. newDoc.childCount - 1`); any top-level block overlapping a modified, split, merged, or inserted range has its `attrs` updated to `{ sourceSlice: null, dirty: true }` in `appendTransaction`. Untouched sibling blocks retain their exact `{ from, to }` slice and `dirty: false`.
   - `serializeMarkdown(doc: ProseMirrorNode, originalSource: string): string`:
     - Iterates top-level blocks. If `block.attrs.dirty === false && block.attrs.sourceSlice !== null`, emits `originalSource.slice(from, to)` verbatim byte-for-byte.
     - Preserve exact inter-block blank-line separators (`originalSource.slice(prev.to, curr.from)`) when both adjacent blocks are clean; otherwise emit `\n\n`.
     - If `block.attrs.dirty === true || block.attrs.sourceSlice === null`, serializes only that block using canonical GFM rules (`-` unordered bullets, `|` pipe tables, ```` ``` ```` fenced code blocks, `[ ]`/`[x]` task items).
4. **Surface Factory (`editorSurfaceFactory.ts`):**
   - Exports `export type EditorSurfaceKind = 'summary' | 'description' | 'comment' | 'sticky' | 'doc';` and `registerEditorExtension(ext: EditorExtensionDescriptor): () => void` (supporting custom ProseMirror `Plugin` factories and `NodeViewConstructor` maps) so later tickets (`KB-P3-46` paste classifier, `KB-P3-47` Mermaid worker nodeView, `KB-P3-48` safe SVG/image nodeView, `KB-P5-08` Sparkle plugin) attach without editing core schema internals.
5. **`MarkdownEditor.tsx` & Zero Mode-Picker Clutter (`S5.1`, `S6.1`, `S6.2`):**
   ```tsx
   export interface MarkdownEditorProps {
     surface: EditorSurfaceKind;
     value: string;
     onChange: (nextMarkdown: string) => void;
     onBlur?: (currentMarkdown: string) => void;
     readOnly?: boolean;
     maxBytes?: number; // defaults: sticky 65536, comment 262144, description/doc 1048576
     placeholder?: string;
     ariaLabel: string;
     testId?: string;
   }
   ```
   - **Zero Mode-Picker Clutter:** Renders NO `[Rich | Markdown | HTML]` mode tabs, dropdown, or formatting toolbar ribbon. Users type GFM input rules (`# `, `- `, `1. `, `- [ ] `, `> `, ```` ``` ````, `` `code` ``, `**bold**`, `~~strike~~`) directly in WYSIWYG.
   - **Raw Canonical Source Inspection (`📝`, `Cmd/Ctrl+Shift+M`):**
     - Pressing `Cmd+Shift+M` (macOS) / `Ctrl+Shift+M` (Linux/Windows) while focused in the editor, or activating the subtle top-right `<EmojiHint kind="rawMarkdown" variant="interactive">` (`📝`) pill, switches in-place between ProseMirror WYSIWYG and a monospace `<textarea class="kb-editor__raw mono">` displaying the exact `serializeMarkdown()` string.
     - In WYSIWYG mode, the `📝` pill sits quietly in the top-right corner (`opacity: 0` until editor hover/focus, `opacity: 1` when focused or in raw mode); in raw mode, `<EmojiHint kind="rawMarkdown">` displays active ring + literal hover/focus hint: `Raw canonical Markdown source inspection is active (Cmd/Ctrl+Shift+M to toggle)`.
     - Switching raw -> WYSIWYG re-runs `parseMarkdown(rawValue)` so all blocks receive fresh `sourceSlice` baselines.
   - **Breathable Typography & CSP Compliance (`MarkdownEditor.css`):**
     - Editorial surfaces (`description`, `doc`) apply `padding: var(--prose-pad)` (`32px 40px`), `font-size: var(--text-body)` (`15px`), `line-height: var(--leading-prose)` (`1.73`), block vertical rhythm `var(--space-4)` (`16px`), code blocks `font-family: var(--font-mono)` with `padding: var(--space-4)` and `background: var(--bg-surface-raised)`.
     - Zero inline `style="..."` attributes and zero `<style>` tag injection (`style-src 'self'`). Raw HTML inside Markdown (`<script>`, `<img onerror=...>`, `<div onclick=...>`) is never rendered as live HTML DOM; inline/block raw HTML tokens are rendered as inert escaped literal text nodes.
6. **`EditorStory.tsx` (`/__dev/editor`):** Renders a sample CLI-authored multi-block document containing an aligned ASCII GFM table, reference-style links (`[Plane parity][1]` + `[1]: https://kanban.hackedyour.info`), a 4-backtick code block, a task list, and a prose paragraph, alongside a live `data-testid="serialized-output"` diff inspector and byte-equality indicator for Playwright verification.

### Mandatory Feature Unit Tests
- **Test File(s):**
  - `kanban/web/src/editor/sourceSlice.test.ts`
  - `kanban/web/src/editor/schema.test.ts`
  - `kanban/web/src/editor/MarkdownEditor.test.tsx`
- **Required Test Cases:**
  1. **Golden Round-Trip (`sourceSlice` untouched document):** Parse and immediately serialize a 12-block golden fixture containing `*` bullets, custom-padded GFM pipe tables, `[ref][id]` reference links, ```` ````ts ```` 4-backtick fences, and checklists -> output is `100%` byte-identical (`output === input`).
  2. **Surgical Single-Paragraph Edit (`S5.2 item 5`):** Load a 5-block document (heading, ASCII-padded table, paragraph 3 with typo `"teh"`, reference-link paragraph, ```` ```python ```` block), dispatch a ProseMirror text replacement `"teh"` -> `"the"` in paragraph 3 -> serialized output preserves blocks 1, 2, 4, and 5 byte-for-byte while updating only paragraph 3.
  3. **Structural Edits (split, merge, delete, table cell edit):** Splitting paragraph 2 with `Enter` marks both halves `dirty: true` while keeping blocks 1 and 3 byte-identical; editing one cell in a GFM table re-serializes that table cleanly into valid GFM pipe syntax without corrupting neighboring blocks.
  4. **Raw Markdown Toggle (`Cmd/Ctrl+Shift+M` & `📝` `<EmojiHint>`):** Pressing `Ctrl+Shift+M` swaps ProseMirror `.ProseMirror` surface for `<textarea>` with identical Markdown text and renders `<EmojiHint kind="rawMarkdown">`; editing in raw `<textarea>` and pressing `Ctrl+Shift+M` again updates the ProseMirror doc and preserves new `sourceSlice` offsets; assert `queryByRole('combobox', { name: /mode/i })` and any `Rich | Markdown | HTML` picker are `null`.
  5. **Negative / Security:** Input containing `<script>window.__xss=1</script>`, `<img src=x onerror=alert(1)>`, `[click](javascript:alert(1))`, and `![x](data:text/html,<script>)` creates zero `<script>` elements, strips `javascript:` and `data:` schemes, and renders raw HTML tags strictly as literal text.
  6. **Boundary:** Document of `1,048,576` UTF-8 bytes (`1 MiB`, including 4-byte emoji characters) parses and serializes cleanly; `1,048,577` bytes throws `MARKDOWN_MAX_BYTES_EXCEEDED`; sticky `maxBytes={65536}` blocks input exceeding `65,536` UTF-8 bytes with an `aria-live="polite"` byte-limit warning.
- Coverage on touched files under `kanban/web/src/editor/` `>= 95%` lines/functions/branches/statements.
