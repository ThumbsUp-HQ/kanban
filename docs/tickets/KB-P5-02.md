### User Story
As an **AI/LLM systems engineer**, I need **a `GeminiProvider` that implements the `LLMProvider` protocol on the `google-genai` SDK (AI Studio and Vertex AI) with native `response_schema` JSON enforcement, explicit `safety_settings`, and a pinned Vertex region** so that **long-context structuring and fast workflow-gate workloads run on Gemini without prompt retention and without silently drifting to an unapproved region**.

**Requirement Traceability:** `S10.1 (GeminiProvider row)`, `S10.2 (residency tier)`, `S15.2`, `S2.5 (Apache-2.0 supply chain)`, original requirement `#2` | **Dependencies:** `KB-P0-12`, `KB-P5-01` (reuses `registry.py`, `CassetteTransport`, `--http-cassette` CLI flag)

### Scoped Technical Actions
1. **Target Files:**
   - `agent/providers/gemini.py` (new)
   - `agent/providers/registry.py` (modify: register `gemini`)
   - `agent/pyproject.toml` + `uv.lock` (add `google-genai`, exact version pin with hash)
   - `agent/GEMINI.md` (update)
   - `docs/qa/<TICKET_ID>/dependency-evaluation.md` (new, required for `[DEP]`)
2. **`GeminiSettings` (Pydantic v2, `frozen=True`, `extra="forbid"`):** `mode: Literal["vertex", "ai_studio_paid"]` (the free AI Studio tier is NOT representable - spec requires zero prompt retention under paid/Vertex configs), `api_key: SecretStr | None` (required for `ai_studio_paid`, forbidden for `vertex`), `vertex_project: str | None`, `vertex_location: str | None` (required for `vertex`), `allowed_vertex_regions: tuple[str, ...]` (min length 1 for `vertex`; `vertex_location` must be a member, `"global"` rejected), `model_allowlist: tuple[str, ...]` (e.g. `gemini-2.5-flash`, `gemini-2.5-pro`), `safety_settings: tuple[SafetySetting, ...]` (explicit; default sets `HARM_CATEGORY_HARASSMENT`, `HARM_CATEGORY_HATE_SPEECH`, `HARM_CATEGORY_SEXUALLY_EXPLICIT`, `HARM_CATEGORY_DANGEROUS_CONTENT` to `BLOCK_MEDIUM_AND_ABOVE`), `timeout_s: float = 30.0` (bounds `1..300`).
3. **`GeminiProvider` implementing `LLMProvider`:**
   - Client: `genai.Client(vertexai=True, project=..., location=...)` or `genai.Client(api_key=...)`, with `http_options=types.HttpOptions(timeout=..., async_client_args={"transport": transport, "trust_env": False})` so `CassetteTransport` is injectable and env proxies are ignored. If the pinned SDK version cannot accept an injected async transport, record that in `dependency-evaluation.md` and inject via a test-only `httpx.AsyncClient` factory patch; production code path must not differ.
   - `stream_complete(req)` -> `client.aio.models.generate_content_stream(...)` with `GenerateContentConfig(temperature, max_output_tokens, safety_settings)`; yields typed `StreamChunk`; a chunk with `finish_reason == SAFETY` ends the stream with `ProviderSafetyBlock` (typed, never surfaced as content).
   - `generate_structured(req)` -> `client.aio.models.generate_content(...)` with `response_mime_type="application/json"` and `response_schema=<Pydantic model>`; result re-validated locally with Pydantic (`ProviderSchemaError` on mismatch - server-side schema enforcement is not trusted alone).
   - `embed_batch(req)` -> `client.aio.models.embed_content(...)`; batch `<= 64`, each input `<= 8,192` chars.
   - `health_probe()` -> lightweight `models.get(model)` call; returns `HealthStatus`, never raises.
   - Error mapping: SDK `ClientError(429)` -> `ProviderHTTPError(429)`, `ServerError(5xx)` -> `ProviderHTTPError(5xx)`, timeouts -> `ProviderTimeout`; no SDK exception type escapes the module.
   - Residency: provider exposes `residency_tier` = `f"gemini-vertex:{vertex_location}"` or `"gemini-ai-studio-paid"` for the router (KB-P5-04).
   - API keys are held as `SecretStr`, never logged, never included in `repr`, never echoed in exceptions (test asserts).
4. **`dependency-evaluation.md`:** package `google-genai`, license `Apache-2.0`, exact pinned version + wheel SHA-256 from `uv.lock`, transitive dependency list with licenses, alternatives considered (raw `httpx` REST client against `generativelanguage.googleapis.com` / Vertex REST; deprecated `google-generativeai`), sign-off sections from 1 architect agent (`backend-architect`) and at least 2 engineer agents (`security-engineer` + one more).

### Mandatory Feature Unit Tests
- **Test File(s):** `agent/tests/providers/test_gemini.py`
- **Cassettes (new, under `tests/fixtures/ai/`):** `gemini_stream_ok.yaml`, `gemini_structured_ok.yaml`, `gemini_structured_schema_mismatch.yaml`, `gemini_safety_block.yaml`, `gemini_embed_ok.yaml`, `gemini_fault_429.yaml`, `gemini_fault_503.yaml`, `gemini_fault_timeout.yaml`
- **Required Test Cases:**
  1. Positive: streamed text chunks match cassette; request body contains every configured `safetySettings` entry.
  2. Positive: structured output validated into the Pydantic model; request carries `responseMimeType=application/json` and `responseSchema`.
  3. Contract parity with `FixtureLLMProvider` for the same scenario (equal typed outputs).
  4. Security: settings with `mode="vertex"`, `vertex_location="us-east4"`, `allowed_vertex_regions=("europe-west4",)` -> validation error; `"global"` rejected.
  5. Security: free-tier representation impossible (`mode="ai_studio"` rejected); `api_key` with `vertex` rejected.
  6. Security: `repr(settings)`, `str(provider)` and every raised exception message do not contain the API key string.
  7. Fault injection: `429`, `503`, timeout -> typed errors; safety-blocked candidate -> `ProviderSafetyBlock`.
  8. Negative: `gemini_structured_schema_mismatch.yaml` (missing required field) -> `ProviderSchemaError`.
  9. Boundary: model outside `model_allowlist` -> `MODEL_NOT_ALLOWED` before any transport call; embed batch of `65` rejected.
- **Coverage:** `>= 95%` line + branch for `agent/providers/gemini.py`; `pytest-socket` enforced.
