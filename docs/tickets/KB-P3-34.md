### User Story
As a **workspace member arriving from Plane**, I need **a calm, Plane-parity application shell (256px collapsible navigation rail, 52px uncluttered topbar with breadcrumb, view switcher and `⚠️` / `🛡️` / `📴` emoji pills, and a `Cmd/Ctrl+K` command palette)** so that **my spatial muscle memory carries over, every screen sits on generous whitespace, and deployment mode, sharing scope and air-gap status are visible as single emojis whose hover/focus/tap reveals the full detail**.

**Requirement Traceability:** `S6.3` (shell wireframe), `S6.1` (`--sidebar-w`, `--topbar-h`, `--board-canvas-pad`), `S6.2` (`⚠️`, `🛡️`, `📴` rows), `S6.4 item 4` (`Cmd/Ctrl+K`, `[`), `S2.2 item 5` (standalone `⚠️` hover text), `S3.4` (`🛡️` pill), `S7.2 8f` (Modules nav unmounted when disabled), requirements `#9j`, `#15`, `#1` | **Dependencies:** `KB-P3-31`, `KB-P3-33`

2. **Router (`routes.tsx`, `react-router` v7 data router, exact pin):** routes `/login`, `/setup`, `/admin/auth`, `/projects/:projectKey/issues` (search param `layout` in `list|board|table|calendar|timeline`, default `list`; any other value is replaced with `list` via `navigate(..., { replace: true })`), `/projects/:projectKey/issues/:issueKey`, `/projects/:projectKey/overview`, `/projects/:projectKey/docs`, `/projects/:projectKey/docs/:pageId`, `/stickies`, `/__dev/*` (dev only), and a `*` route rendering `Not found or no access` (same copy for 403 and 404 per S3.4). Route elements for later tickets render a placeholder `<section data-testid="route-placeholder" data-route="...">` inside the shell. `projectKey` validated against `/^[A-Z][A-Z0-9]{1,9}$/`, `issueKey` against `/^[A-Z][A-Z0-9]{1,9}-[0-9]{1,9}$/`; invalid values render the not-found view without issuing API calls.
3. **Shell grid (`AppShell.tsx`):** CSS grid `grid-template-columns: var(--sidebar-w) 1fr` and `grid-template-rows: var(--topbar-h) 1fr`. Main region `<main id="main" tabIndex={-1}>` with `padding: var(--board-canvas-pad)` (24px 28px; only `<= 767px` uses `16px`, documented exception). A visually hidden `Skip to content` link is the first focusable element and focuses `#main`. A stable `<div id="kb-surface-host">` is rendered once inside the shell for the KB-P3-41 drawer. Hosts `RealtimeStatus` (KB-P3-33) and `#kb-hint-root` (KB-P3-31).
4. **Sidebar (`Sidebar.tsx`), Plane parity with breathable spacing:**
   - Width `var(--sidebar-w)` (256px); inner padding `var(--space-4)` (16px); nav item `min-height: 36px`, `padding: var(--space-2) var(--space-3)` (8px 12px), `gap: var(--space-3)` between icon and label, `border-radius: var(--radius-md)`; section separation `var(--space-6)` (24px); section headings `Workspace`, `Projects` in `--fg-muted` small caps.
   - Top: workspace switcher `[K] kanban v` button, then `+ New work item` button (full width, `padding: var(--space-2) var(--space-3)`; dispatches `kb:create-issue` CustomEvent; no-op handler until a later ticket listens).
   - Items (icon `aria-hidden="true"` + visible text): `🏠 Home`, `📝 Drafts`, `👤 Your work`, `🟨 Stickies` (`/stickies`); `Projects` section with project row `⚡ kanban` expandable (`aria-expanded`) showing `📋 Work Items`, `🔄 Cycles`, `🧩 Modules`, `🎛️ Views`, `📄 Docs (Pages)`. The `🧩 Modules` item is NOT rendered at all (absent from DOM, not hidden) when the project has `modules_enabled === false` (S7.2 8f).
   - Active item: `aria-current="page"`, `--bg-hover` background, `--fg-primary` text.
   - Collapse: `[` (via `shortcuts.ts`) or the collapse button toggles `collapsed`; desktop collapsed width `0` with `visibility: hidden` so collapsed links are not focusable; state persisted in `localStorage['kb.sidebar']` (`'open' | 'collapsed'`; other values ignored). Tablet/mobile (`<= 1279px`): collapsed by default; opening renders it as an overlay `role="dialog"` `aria-modal="true"` with a scrim, focus moved to the first item, focus trapped, `Escape` or scrim click closes and returns focus to the hamburger button. Width transition `160ms`, disabled under reduced motion.
5. **Topbar (`Topbar.tsx`):** height `var(--topbar-h)` (52px), horizontal padding `var(--space-6)` (24px), items separated by `var(--space-4)` (16px), bottom border `1px solid var(--border-subtle)`. Left: hamburger (tablet/mobile only, `aria-label="Open navigation"`, `aria-expanded`), `Breadcrumb`. Center: search trigger button styled as an input `🔍 Search / Cmd+K...` (`aria-keyshortcuts="Meta+K Control+K"`), min width `320px` desktop, icon-only `44x44` on mobile. Right: `HeaderPills`, `LayoutSwitcher` (only on `/projects/:projectKey/issues`), user avatar menu with theme radiogroup `Light / Dark / System` wired to `useTheme()` from KB-P3-30.
6. **Breadcrumb (`Breadcrumb.tsx`):** `<nav aria-label="Breadcrumb"><ol>` with `⚡ kanban` > `Work Items` and a count badge `(7)` from the issues query total; last item `aria-current="page"`; separators `aria-hidden`. On mobile only the last segment is shown with a back button.
7. **Header pills (`HeaderPills.tsx`) using `<EmojiHint>` from KB-P3-31, data from `useSystemStatus()` (`GET /api/v1/system/status`, `qk.systemStatus()`) and project `access_manifest` (`GET /api/v1/objects/{project_id}/access` from KB-P2-11, `qk.access(id)`), rendered in this order with `var(--space-2)` (8px) gap:**
   - `⚠️` (`kind="warning"`, `variant="interactive"`) only when `deployment_mode === 'standalone_embedded_pg'`. Label `Standalone mode warning`. Content line 1 exact: `Standalone Single-Container Mode (Not Recommended for Production) - Click for volume status, encrypted backup, & 1-click docker-compose.yml export`. If `persistent_volume === false` add line exact: `Ephemeral Storage: Mount -v kanban_data:/var/lib/kanban/data to persist data across container removal`. `onActivate` = `openPanel('standalone')`; `activateLabel` = `Open standalone status`.
   - `📴` (`kind="airGap"`, tooltip) only when `air_gap_mode === true`. Content exact: `Air-Gap Local-Only Mode: external LLM and media egress are disabled at the socket level.` plus line `Local model endpoint: <local_llm_endpoint_host>` or `Local model endpoint: visible to server admins only` when `null`.
   - `🛡️` (`kind="access"`, `variant="interactive"`) on project routes. Label `Access: <scope label>` (e.g. `Access: Project + 2`). Content: line 1 `Project: Platform Core`, line 2 `<U> users, <G> groups, <A> 🤖 agents, <D> 🔒 deny rules` computed from the manifest; redacted principals counted as `<N> external collaborator(s)` with zero names. `onActivate` = `openPanel('access', projectObjectId)`; `activateLabel` = `Open Access Inspector`.
   - `ShellPanelsProvider`: `openPanel(id, arg?)` looks up a panel registered via `registerShellPanel(id, Component)`; when none is registered (panels arrive in KB-P3-49 and KB-P3-52) it announces `Panel not available yet` via `announce()` and does nothing else.
8. **Layout switcher (`LayoutSwitcher.tsx`):** `role="radiogroup"` `aria-label="Layout"` with 5 options `List`, `Board`, `Table`, `Calendar`, `Timeline`; arrow keys move and select; selection writes `?layout=`. Desktop shows text segments with `padding: var(--space-1) var(--space-3)`; `<= 1279px` collapses into a single `Layout: Board v` menu button.
9. **Command palette (`CommandPalette.tsx`):** opened by `Cmd+K` (macOS) / `Ctrl+K` (others) or the search trigger. `role="dialog"` `aria-modal="true"` `aria-label="Command palette"`, width `min(640px, 100vw - 48px)`, top offset `15vh`, inner padding `var(--space-4)`, result row `min-height: var(--list-row-h)` (46px). Input `role="combobox"` `aria-expanded` `aria-controls` -> `role="listbox"`; options `role="option"` with `aria-selected`; `ArrowUp/ArrowDown` move, `Enter` runs, `Escape` closes and restores focus to the previously focused element; focus trapped while open. Commands: `Go to Work Items`, `Go to Board`, `Go to Docs`, `Go to Stickies`, `Create work item` (dispatches `kb:create-issue`), `Toggle sidebar`, `Theme: Light`, `Theme: Dark`, `Theme: System`, plus up to 20 cached issues from the TanStack cache matched by key or summary. Matching: case-insensitive subsequence with scoring (prefix > word-start > subsequence), no library. Query input capped at `200` chars; issue summaries rendered as text (fixture issue with `<img src=x onerror=alert(1)>` must render literally).
10. **Shortcuts (`shortcuts.ts`):** `registerShortcut(combo, handler, { allowInInputs?: boolean })`, single global `keydown` listener; ignored while focus is in `input`, `textarea`, `select` or `[contenteditable]` unless `allowInInputs` (only `Cmd/Ctrl+K` uses it); ignored when `event.isComposing`. Registers `Mod+K` and `[` in this ticket; returns an unregister function.

  3. Pills: standalone status renders `⚠️` with the exact S2.2 hover text and the ephemeral line when `persistent_volume: false`; prod status renders no `⚠️`; air-gap with `local_llm_endpoint_host: null` shows `visible to server admins only`; `🛡️` content counts and redacted principals show no names.
  4. Negative / security: `?layout=<script>` normalizes to `list`; route `/projects/kan/issues` (lowercase) and `/projects/KAN/issues/KAN-1x` render `Not found or no access` with zero fetch calls; palette renders the hostile summary as text (no `img` element); `localStorage['kb.sidebar']='evil'` yields default state.

  6. Boundary: palette query of 201 chars is truncated to 200; palette caps issue results at 20; `openPanel` with an unregistered id calls `announce('Panel not available yet')`.
