### User Story
As an **engineer or product architect writing living specifications in `Docs (Pages)`**, I need **a hierarchical `ltree` page tree (`max_depth <= 10`), a breathable canonical Markdown/Mermaid/SVG page editor with `🛡️` access visibility, a live heading Outline & immutable Version History restore rail, and a text-selection `Create Linked Issue` action** so that **specifications stay versioned in canonical Markdown and turn directly into traceable Kanban tickets in two clicks**.

**Requirement Traceability:** `S8.1 item 1` (`Docs (Pages)` tab, `ltree` tree `max_depth <= 10`, `body_markdown` storage, outline rail, version history snapshots & restore, `🛡️` sharing pill, inline text-selection -> `Create Linked Issue`), `S5.1` (canonical Markdown-only), `S6.1` (`--prose-pad`, `--text-body`, `--leading-prose`, `--section-gap`), `S6.2` (`🛡️`, `📝`), requirement `#11` | **Dependencies:** `KB-P3-34` (AppShell & `/projects/:projectKey/docs` routes), `KB-P3-45` (`MarkdownEditor`), `KB-P3-14` (Docs & Pages REST API)

### Scoped Technical Actions

   - `kanban/web/src/features/docs/DocsTreeNav.tsx` (`role="tree"` / `role="treeitem"` `ltree` navigation up to depth `10`, create child, reparent/move)
   - `kanban/web/src/features/docs/PageEditorPane.tsx` (breadcrumbs, `🛡️` pill, inline title `1..500` chars, `ETag`/`If-Match` autosave + `412` conflict guard, `MarkdownEditor` `surface="doc"`)
   - `kanban/web/src/features/docs/OutlineAndVersionsRail.tsx` (`Outline` heading TOC + linked issues list, and `History` `page_versions` viewer + `Restore v<N>`)
   - `kanban/web/src/features/docs/SelectionToIssueToolbar.tsx` (floating selection button `Create Linked Issue` + inline issue creation dialog linking `RELATES_TO` / `VERIFIED_BY_DOC`)
   - `kanban/web/e2e/fixtures/docs-tree-kan.json`, `kanban/web/e2e/fixtures/page-auth-studio.json`, `kanban/web/e2e/fixtures/page-versions-auth-studio.json`
   - Edits: `kanban/web/src/app/routes.tsx` (wire `/projects/:projectKey/docs` and `/projects/:projectKey/docs/:pageId` to `DocsWorkspaceView`, replacing route placeholders from `KB-P3-34`)
2. **`ltree` Sidebar Tree (`DocsTreeNav.tsx`, `S8.1`, `KB-P1-09`):**
   - Queries `useQuery(qk.docsTree(projectKey))` (`GET /api/v1/projects/{projectKey}/docs/tree`, `KB-P3-14`).
   - Implements WAI-ARIA Treeview (`role="tree" aria-label="Project documents"`, `role="treeitem"`, `aria-expanded`, `aria-level={1..10}`, `aria-current="page"`): `ArrowDown`/`ArrowUp` move visible focus, `ArrowRight` expands or moves to first child, `ArrowLeft` collapses or moves to parent, `Enter` navigates to `/projects/:projectKey/docs/:pageId`.
   - Enforces `max_depth <= 10` (`KB-P1-09`): on a page at `depth === 10`, the `+ Sub-page` button is `disabled` (`aria-disabled="true"`) with tooltip `Maximum nesting depth of 10 pages reached`.
   - Supports `+ New Doc` (root) and `+ Sub-page` (`POST /api/v1/projects/{projectKey}/docs` / `pages`), plus `Move to...` parent picker filtering out self, descendants (cycle prevention), and targets that would push subtree depth `> 10`.
3. **Spacious Editorial Page Pane (`PageEditorPane.tsx`):**
   - Queries `useQuery(qk.page(pageId))` (`GET /api/v1/pages/{pageId}`, `KB-P3-14`). `403` and `404` render identical `Page was not found or you do not have access.`.
   - Top metadata bar: `ltree` ancestor breadcrumbs (`Docs / Architecture / Auth Studio`), version pill `v<version_seq>` in `.mono`, `<EmojiHint kind="access" variant="interactive">` (`🛡️`, dispatching `kb:open-access-inspector` with `page.id`), and `History` rail toggle button.
   - Inline title `<textarea>` / `<h1>` (`1..500` Unicode code points after trim, control chars stripped, `Enter` focuses `MarkdownEditor`).
   - Body mounts `<MarkdownEditor surface="doc" maxBytes={1048576} .../>` (`KB-P3-45`) inside `.docs-prose` with `padding: var(--prose-pad)` (`32px 40px`), inner prose `max-width: 720px`, `font-size: var(--text-body)` (`15px`), `line-height: var(--leading-prose)` (`1.73`), `row-gap: var(--section-gap)` (`32px`).
   - Debounced save (`800ms` idle or blur / `Cmd+S`) sends `PATCH /api/v1/pages/{pageId}` with `If-Match: <etag>` (`body_sha256` hex). On `412 Precondition Failed`, preserves local unsaved Markdown in state and displays a non-destructive `role="alert"` conflict banner (`Page was updated elsewhere (v<remote>). Copy your draft or reload latest.`) with `Copy My Draft` and `Reload Latest` actions.
4. **Outline & Version History Rail (`OutlineAndVersionsRail.tsx`):**
   - Two accessible tabs (`role="tablist"`): `Outline` (default) and `History`.
   - **`Outline` Tab:** Extracts `h1..h3` headings outside fenced code blocks (`id` slugged deterministically), renders indented jump links (`min-height: 32px`), highlights active section via `IntersectionObserver` (`aria-current="location"`), and lists linked `object_links` (`KAN-*` issue chips + `PROMOTED_TO_DOC` source sticky badge if promoted).
   - **`History` Tab:** Fetches `GET /api/v1/pages/{pageId}/versions` (`page_versions` rows ordered `version_seq DESC`). Selecting `v<N>` renders a read-only preview of `v<N>.body_markdown` alongside its short `body_sha256` mono digest (`8` hex chars), timestamp, and author, plus `[Restore v<N>]` (`POST /api/v1/pages/{pageId}/versions/{seq}/restore` with `If-Match`, which snapshots current body and increments `version_seq + 1` per `KB-P1-09` immutability, then invalidates `qk.page(pageId)`).
5. **Text Selection -> `Create Linked Issue` (`SelectionToIssueToolbar.tsx`, `S8.1 item 1`):**
   - Monitors non-collapsed selection (`[...selectedText.trim()].length >= 3`) contained strictly inside `.docs-prose`. Positions a compact floating action button `➕ Create Linked Issue` (`positionHint` CSSOM `top`/`left`, zero `style` attribute strings; dismissed on `Escape` or collapsed selection).
   - Activating opens a modal dialog (`role="dialog" aria-modal="true" aria-label="Create linked issue"`):
     - Pre-fills `Summary` with the first selected line truncated cleanly to `<= 120` code points (editable `1..500`).
     - Pre-fills `Description` as canonical Markdown: blockquote of the selected text (`> ...`, capped at `4,000` chars) + `\n\nSource: [<Page Title>](/projects/<KEY>/docs/<pageId>)`.
     - Submitting calls `POST /api/v1/projects/{projectKey}/issues` (`KB-P3-02`) followed by `POST /api/v1/links` (`{ source_id: issue.id, target_id: page.id, link_type: 'VERIFIED_BY_DOC' }`, fallback `'RELATES_TO'` per `KB-P3-07`), invalidates `qk.page(pageId)`, and announces `Created linked issue <ISSUE_KEY>` with a clickable link.
6. **Responsive Breakpoints (`DocsWorkspaceView.css`):**
   - Desktop (`>= 1280px`): `240px` tree rail + `minmax(0, 1fr)` prose center + `240px` outline/history rail.
   - Tablet (`768px .. 1279px`): `220px` tree rail + `1fr` prose center; Outline/History opens as a slide-over non-modal sheet.
   - Mobile (`<= 767px`): Full-width prose center (keeping `--prose-pad: 32px 40px` vertical rhythm or `24px 20px` horizontal guard without cramping `--leading-prose`); both Tree and Outline/History open via dedicated topbar sheet buttons (`Pages Tree`, `Outline & History`) with focus trap + `Escape`.
