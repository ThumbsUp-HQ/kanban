### User Story
As an **AI/LLM systems engineer**, I need **a `kanban-agent` CLI entrypoint with a typed subcommand registry, shared provider/model/verbosity flags, the standardized 4-section validation report, deterministic exit codes (`0` / `2` / `1`), and a working `validate-echo` command backed by `FixtureLLMProvider`** so that **every later AI workflow (`validate-transition`, `validate-sparkle`, `validate-sticky-promo`, `validate-qa-packet`) plugs into one uniform local manual validation harness**.

**Requirement Traceability:** `S15.3` (`uv run kanban-agent validate-*`, 4-part report: scrubbed context, tool trace, TTFT + wall-clock + tokens, schema validation status; `EXIT 0` valid, `EXIT 2` schema/policy violation), `S15.2` (`--provider fixture` cassette execution), Requirement `#2` | **Dependencies:** `KB-P0-12`

### Scoped Technical Actions
1. **Target Files:**
   - `agent/cli.py`, `agent/cli_report.py`

   - `agent/tests/cli/__init__.py`, `agent/tests/cli/test_cli_skeleton.py`

2. **Exit Codes & 4-Section Report (`agent/cli_report.py`):**
   - `class ExitCode(IntEnum)`: `OK = 0` (valid output/verdict), `RUNTIME_ERROR = 1` (`ProviderHTTPError`, `ProviderUnavailable`, `AllProvidersUnavailable`, I/O errors, uncaught exceptions), `SCHEMA_OR_POLICY_VIOLATION = 2` (CLI flag validation errors, `CassetteValidationError`, `CassetteMismatchError`, `ProviderSchemaError`, `ProviderPolicyError` / `EgressDenied`, `ProviderSafetyBlock`, `ProviderRefusal`, TTFT SLA `ProviderTimeout`).
   - `ValidationReport` (Pydantic v2, `frozen=True`, `extra="forbid"`):
     - `schema_version: Literal["kb-cli-validation-report/v1"] = "kb-cli-validation-report/v1"`
     - `command: str`
     - `rendered_context: str` (Section 1: exact rendered prompt / `${context}` after passing through a pluggable `ContextScrubber` callable; defaults to identity in Phase 0 and accepts KB-P2-17 scrubber injection)
     - `tool_trace: tuple[ToolCallStep, ...]` (Section 2: every `:ro` repo or MCP tool call; in `text` format prints call count + tool names by default, and full JSON args + results when `--verbose-tools` is set)
     - `metrics: ReportMetrics` (Section 3: `ttft_ms: float | None`, `total_latency_ms: float`, `prompt_tokens: int`, `completion_tokens: int`, `route_trace: tuple[dict[str, Any], ...] = ()`)
     - `schema_status: SchemaStatus` (Section 4: `valid: bool`, `status: str`, `error_code: str | None = None`, `detail: str | None = None`)
   - `render_report(report: ValidationReport, fmt: Literal["text", "json"], *, verbose_tools: bool) -> str`:
     - `text` format emits four literal headings: `=== 1. RENDERED CONTEXT ===`, `=== 2. TOOL TRACE ===`, `=== 3. LATENCY & TOKENS ===`, `=== 4. SCHEMA & POLICY STATUS ===`.
     - `json` format emits compact valid JSON conforming to `ValidationReport.model_json_schema()`.

3. **Subcommand & Provider Registry (`agent/cli.py`, stdlib `argparse`, zero new CLI deps):**
   - `SubcommandSpec(name: str, help: str, configure_parser: Callable[[ArgumentParser], None], handler: Callable[[Namespace], Awaitable[tuple[ValidationReport, ExitCode]]])`.
   - `register_subcommand(spec: SubcommandSpec) -> None` and `get_registered_subcommands() -> Mapping[str, SubcommandSpec]` (rejects duplicate names with `ValueError`).
   - `add_common_agent_flags(parser: ArgumentParser, *, available_providers: Sequence[str] = ("fixture",)) -> None`: adds `--provider` (choices from registered provider factories, initially `fixture`), `--model` (default `"fixture-echo-v1"`), `--cassette PATH` (path to YAML cassette), `--verbose-tools` (`action="store_true"`), `--report {text,json}` (default `"text"`).
   - Custom `ArgumentParser.error()` override exiting with code `2` (`SCHEMA_OR_POLICY_VIOLATION`) and writing structured error text to `stderr` without Python tracebacks.
   - `main(argv: Sequence[str] | None = None) -> int` (sync entrypoint calling `asyncio.run(_async_main(argv))` and returning integer exit code; `if __name__ == "__main__": raise SystemExit(main())`).

4. **Demo Command `validate-echo` (`agent/cli_commands/validate_echo.py`):**
   - Registered automatically at import of `agent.cli`.
   - Flags: common flags plus `--prompt TEXT` (default `"Hello Sparkle"`), `--mode {stream,structured}` (default `"stream"`), `--ttft-deadline-ms INT` (optional `1..60000`).
   - Behavior: loads `--cassette` (defaulting to `tests/fixtures/ai/echo_stream_ok.yaml` when `--provider fixture` and `--cassette` omitted; missing file -> exit `1`), runs `stream_complete` or `generate_structured` (using `EchoVerdict(BaseModel): echo: str; ok: bool`), measures wall-clock with `time.perf_counter()`, populates `ValidationReport`, prints to `stdout`, and maps any `ProviderError` / `CassetteValidationError` to the exact `ExitCode` (`0`, `2`, or `1`) while still emitting Section 4 failure details.

### Mandatory Feature Unit Tests
- **Test File(s):** `agent/tests/cli/test_cli_skeleton.py`
- **Required Test Cases:**
  1. Positive (`text` report): `main(["validate-echo", "--provider", "fixture", "--cassette", "tests/fixtures/ai/echo_stream_ok.yaml", "--prompt", "Hello Sparkle"])` returns `0`; stdout contains all 4 `=== N. ... ===` headings, rendered prompt, `ttft_ms`, token counts, and `valid: true`.
  2. Positive (`json` + `--verbose-tools`): `validate-echo --mode structured --report json --verbose-tools` against a cassette with `tool_script` returns `0`; `json.loads(stdout)` validates against `ValidationReport` with `tool_trace` args/results preserved; without `--verbose-tools`, `text` output omits raw tool result bodies.
  3. Policy/schema violation (`EXIT 2`): invoking `validate-echo` with `--ttft-deadline-ms 5` against `transition_rls_veto.yaml` (`simulated_ttft_ms: 18`), or against a schema-mismatch / `safety_block` / `EgressDenied` cassette, or with unknown CLI flag `--bogus`, returns exit code `2`.
  4. Runtime error (`EXIT 1`): invoking `validate-echo` against `tests/fixtures/ai/fault_429.yaml` or a nonexistent `--cassette /nonexistent.yaml` returns exit code `1` with zero raw Python traceback on `stderr`.
  5. Extensibility & boundary: registering a duplicate subcommand name raises `ValueError`; custom `ContextScrubber` hook replaces `"SECRET-123"` with `"[REDACTED]"` in Section 1 before printing; `uv run kanban-agent --help` subprocess smoke test exits `0`.
