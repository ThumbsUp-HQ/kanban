### User Story
As an **operator running the hardened multi-container stack**, I need **a `docker-compose.yml` whose services and networks match the S2.4 matrix exactly and a Caddy 2.8 edge config enforcing TLS 1.3, unbuffered streaming for `/ws`, `/sse`, `/mcp/*`, precompressed static delivery and the S5.4 CSP/HSTS** so that **the MCP gateway has no route to the database and the edge is the only exposed surface**.

**Requirement Traceability:** `S2.3` (Caddy 2.8+, `flush_interval -1`, `.br`/`.gz` static), `S2.4` container matrix, `S5.4` CSP, Requirement `#3` | **Dependencies:** `KB-P0-07`, `KB-P0-10`

### Scoped Technical Actions
1. **Target Files:** `docker-compose.yml`, `deploy/caddy/Caddyfile`, `scripts/check_compose_networks.py`, `scripts/tests/test_check_compose_networks.py`, `tests/deploy/test_caddyfile.py`, `deploy/README.md`, `.gitignore` (add `deploy/secrets/`), `Makefile` (target `compose-check`)
2. **Networks (exact names):** `edge_net` (bridge), `app_net` (`internal: true`), `data_net` (`internal: true`), `sandbox_net` (`internal: true`), `egress_llm_net` (bridge, not internal).
3. **Services, images and networks (exact; images pinned by `@sha256:` digest; locally built images reference the `Dockerfile` targets):**

   | Service | Image / build target | Networks |
   | :-- | :-- | :-- |
   | `reverse-proxy` | `caddy:2.8-alpine@sha256:<digest>` | `edge_net`, `app_net` |
   | `kanban-api` | build `target: runtime-slim` (`kanban:runtime-slim`) | `app_net`, `data_net` |
   | `mcp-server` | `kanban:runtime-slim` | `app_net` only |
   | `agent-runtime` | `kanban:runtime-slim` | `app_net`, `egress_llm_net` |
   | `script-sandbox` | `kanban:sandbox` (built in KB-P5-14), `profiles: ["sandbox"]` | `sandbox_net` only |
   | `outbox-relay` | `kanban:runtime-slim` | `data_net` only |
   | `postgres` | `pgvector/pgvector:pg16@sha256:<digest>` | `data_net` only |
   | `valkey` | `valkey/valkey:8.0-alpine@sha256:<digest>` | `data_net` only |

   Only `reverse-proxy` publishes ports (`80:80`, `443:443`, `443:443/udp`). No other service has `ports:`.
4. **Hardening for every service (except where noted):** `read_only: true` with explicit `tmpfs` for writable paths, `cap_drop: [ALL]`, `security_opt: ["no-new-privileges:true"]`, `restart: unless-stopped`, `pids_limit`, `mem_limit`. App services (`kanban-api`, `mcp-server`, `agent-runtime`, `outbox-relay`) use `user: "65532:65532"`. `reverse-proxy` gets `cap_add: [NET_BIND_SERVICE]` only. `postgres` keeps its image user and named volume `pgdata`; `valkey` named volume `valkeydata`.
5. **Secrets:** PostgreSQL passwords and `MASTER_KEK` provided via Compose `secrets:` from files `deploy/secrets/*.txt` (gitignored; `deploy/README.md` documents generation with `openssl rand -base64 32`). No secret value or default password appears in `docker-compose.yml`. `mcp-server` receives no database secret and no `DATABASE_URL`.
6. **Commands:** `kanban-api`: `uvicorn kanban.app:create_app --factory --host 0.0.0.0 --port 8000 --proxy-headers --forwarded-allow-ips=<reverse-proxy subnet>`; `mcp-server`, `agent-runtime`, `outbox-relay`: placeholder `command` documented as finalized in KB-P4-01 / KB-P5-04 / KB-P1-18 respectively. Healthchecks on `postgres` (`pg_isready`) and `valkey` (`valkey-cli ping`); `kanban-api` `depends_on: { postgres: { condition: service_healthy } }`.
7. **`deploy/caddy/Caddyfile`:**
   - Global: `servers { protocols h1 h2 h3 }`; site block `{$KB_DOMAIN}` with `tls { protocols tls1.3 }`.
   - `header` block setting `Content-Security-Policy` to the byte-identical value of `kanban.security.headers.CSP_POLICY`, `Strict-Transport-Security "max-age=63072000; includeSubDomains"`, `X-Content-Type-Options nosniff`, `Referrer-Policy no-referrer`, `X-Frame-Options DENY`, `-Server`.
   - `handle /api/*` -> `reverse_proxy kanban-api:8000`.
   - `handle /ws` and `handle /sse*` -> `reverse_proxy kanban-api:8000 { flush_interval -1 }`.
   - `handle /mcp/*` -> `reverse_proxy mcp-server:8000 { flush_interval -1 }`.
   - Fallback `handle`: `root * /srv/www`, `try_files {path} /index.html`, `file_server { precompressed br gzip }`; `@assets path /assets/*` -> `Cache-Control "public, max-age=31536000, immutable"`; `index.html` -> `Cache-Control no-cache`.
   - `/srv/www` is a read-only volume populated from `kanban:runtime-slim` `/opt/kanban/web/dist`.
8. **`scripts/check_compose_networks.py`:** `main(argv) -> int`; runs `docker compose -f docker-compose.yml --profile sandbox config --format json` (or reads `--config-json PATH`), and asserts the exact service -> network sets in item 3, internal flags in item 2, that `mcp-server` is not on `data_net`, only `reverse-proxy` has `ports`, every service has `cap_drop` containing `ALL` and `no-new-privileges:true`, and no `environment` value matches `(?i)(password|secret|kek)=?.{8,}`. Prints one line per violation; exit `1` on any, `0` otherwise, `3` on parse/collector error.

### Mandatory Feature Unit Tests
- **Test File(s):** `scripts/tests/test_check_compose_networks.py` (JSON fixtures; no Docker daemon), `tests/deploy/test_caddyfile.py` (static text assertions)
- **Required Test Cases:**
  1. Positive: the compose JSON produced from the committed `docker-compose.yml` (fixture regenerated by the implementer and committed as `scripts/tests/fixtures/compose_config.json`) yields exit `0`.
  2. Negative/security: fixture where `mcp-server` also joins `data_net` -> exit `1` with a violation naming `mcp-server`; fixture where `data_net.internal` is false -> exit `1`; fixture where `postgres` publishes `5432` -> exit `1`.
  3. Negative/security: fixture with `environment: {POSTGRES_PASSWORD: hunter2hunter2}` -> exit `1`; service missing `cap_drop: [ALL]` -> exit `1`.
  4. Boundary: invalid JSON or collector non-zero exit -> exit `3`; `script-sandbox` present only under profile `sandbox` and on `sandbox_net` only.
  5. Caddyfile: contains `protocols tls1.3`; contains `flush_interval -1` inside the `/ws`, `/sse*`, and `/mcp/*` handlers; contains `precompressed br gzip`; its `Content-Security-Policy` value equals `kanban.security.headers.CSP_POLICY` (imported in the test).
