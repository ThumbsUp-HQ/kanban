### User Story
As a **project member or administrator**, I need **the `views` graph entity table supporting all 5 native layouts (`list`, `board`, `table`, `calendar`, `timeline`), orthogonal 2D `group_by` x `sub_group_by` swimlanes, validated filter DSL JSON, validated Soft/Hard WIP limit JSON, and owner/scope visibility** so that **saved views are first-class Universal Object Graph nodes with database-enforced invariants**.

**Requirement Traceability:** `S6.4` items 2-3 (5 native views, 2D swimlanes, Soft/Hard WIP limits), `S12.1` (`view` in `object_kind` 9 mandatory classes), `S3.4` (`View` object sharing scope), Requirements `#9`, `#13h` | **Dependencies:** `KB-P1-04`, `KB-P1-03`

2. **JSON Validator Functions (`IMMUTABLE PARALLEL SAFE`, defined before `views`):**
   - `validate_view_filters_json(p_doc jsonb) RETURNS boolean`: returns `FALSE` unless `p_doc IS NOT NULL`, `jsonb_typeof(p_doc) = 'object'`, `octet_length(p_doc::text) <= 16384`, and every top-level key in `jsonb_object_keys(p_doc)` belongs to the allowlist `('state_ids', 'state_groups', 'priority_ids', 'assignee_ids', 'label_ids', 'cycle_ids', 'module_ids', 'start_date', 'due_date', 'gate_status', 'search_query')`.
   - `validate_view_wip_limits_json(p_doc jsonb) RETURNS boolean`: returns `FALSE` unless `p_doc IS NOT NULL`, `jsonb_typeof(p_doc) = 'object'`, `octet_length(p_doc::text) <= 8192`, and for every `(k, v)` entry: `k ~ '^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$'`, `jsonb_typeof(v) = 'object'`, keys of `v` are a subset of `('soft', 'hard')`, each present non-null value has `jsonb_typeof = 'number'` with integer value `BETWEEN 1 AND 10000`, and when both `soft` and `hard` are non-null `(v->>'hard')::int >= (v->>'soft')::int`.

3. **`view_layout` Enum & `views` DDL (`p1_10_views.up.sql`):**
   ```sql
   CREATE TYPE view_layout AS ENUM ('list', 'board', 'table', 'calendar', 'timeline');

   CREATE TABLE views (
       id                    UUID PRIMARY KEY,
       object_type           object_kind NOT NULL DEFAULT 'view' CHECK (object_type = 'view'),
       workspace_id          UUID NOT NULL REFERENCES workspaces(id) ON DELETE RESTRICT,
       project_id            UUID REFERENCES projects(id) ON DELETE RESTRICT,
       owner_principal_id    UUID NOT NULL REFERENCES principals(id) ON DELETE RESTRICT,
       visibility            TEXT NOT NULL DEFAULT 'project'
                             CHECK (visibility IN ('private', 'project', 'workspace')),
       name                  TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 200),
       summary_markdown      TEXT NOT NULL DEFAULT '' CHECK (octet_length(summary_markdown) <= 65536),
       summary_sha256        BYTEA GENERATED ALWAYS AS (digest(summary_markdown, 'sha256')) STORED,
       layout                view_layout NOT NULL DEFAULT 'board',
       group_by              TEXT CHECK (group_by IS NULL OR group_by IN
                               ('state', 'priority', 'assignee', 'cycle', 'module', 'label', 'project')),
       sub_group_by          TEXT CHECK (sub_group_by IS NULL OR sub_group_by IN
                               ('assignee', 'priority', 'cycle', 'module', 'label', 'state')),
       filters_json          JSONB NOT NULL DEFAULT '{}'::jsonb
                             CHECK (validate_view_filters_json(filters_json)),
       display_props_json    JSONB NOT NULL DEFAULT '{}'::jsonb
                             CHECK (jsonb_typeof(display_props_json) = 'object'
                                    AND octet_length(display_props_json::text) <= 8192),
       wip_limits_json       JSONB NOT NULL DEFAULT '{}'::jsonb
                             CHECK (validate_view_wip_limits_json(wip_limits_json)),
       sort_rank             TEXT COLLATE "C" NOT NULL DEFAULT 'a0',
       CHECK (visibility <> 'project' OR project_id IS NOT NULL),
       CHECK (group_by IS NULL OR sub_group_by IS NULL OR group_by <> sub_group_by),
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT
   );
   CREATE INDEX views_project_rank_idx ON views (project_id, sort_rank COLLATE "C") WHERE project_id IS NOT NULL;
   CREATE INDEX views_ws_owner_idx ON views (workspace_id, owner_principal_id);
   ```
   *(Note: prose column is named `summary_markdown` + `summary_sha256` STORED, and JSONB columns use `*_json` without `body`/`description`/`content` tokens, preserving the KB-P1-09 schema-wide Markdown-only catalog invariant.)*

4. **Integrity Trigger `views_spine_match_biu` (`BEFORE INSERT OR UPDATE ON views`):**
   - Verifies `objects.workspace_id = NEW.workspace_id` and `objects.project_id IS NOT DISTINCT FROM NEW.project_id` -> else `VIEW_SPINE_MISMATCH`.
   - Verifies `principals.workspace_id = NEW.workspace_id` and `principals.principal_type IN ('USER', 'AGENT', 'SERVICE_PRINCIPAL')` (a `GROUP` cannot be `owner_principal_id`) -> else `VIEW_INVALID_OWNER`.
   - If `NEW.project_id IS NOT NULL`, verifies `projects.workspace_id = NEW.workspace_id` -> else `VIEW_PROJECT_WORKSPACE_MISMATCH`.

5. **Down Migration:** Drops trigger and trigger function, `views`, `view_layout`, `validate_view_wip_limits_json`, `validate_view_filters_json`.
