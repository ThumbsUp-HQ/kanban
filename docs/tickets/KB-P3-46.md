### User Story
As a **user pasting content from web browsers, Jira, Confluence, Google Docs, Word, VS Code, terminals, or screenshots**, I need **a deterministic 5-branch clipboard classifier that strips hidden prompt-injection DOM subtrees before style removal, bypasses noisy IDE syntax-color wrappers, converts rich HTML or raw Markdown cleanly into canonical GFM blocks, uploads binary images as attachments, and offers a `🧼` pill with `Cmd/Ctrl+Z` plain-text fallback** so that **pasting works naturally across every source while neutralizing invisible paste-jacking payloads**.

**Requirement Traceability:** `S5.2` (`autoConvertPaste.ts` 5 branches, Step A hidden-DOM pruner before style strip, Step B `DOMPurify` + `hast-util-to-mdast` -> `remark-gfm`, `🧼` pill literal copy, `Cmd+Z` plain-text fallback), `S3.5` (STRIDE row 1 & 2 hidden-text & paste-jacking defense), `S5.4` (`trusted-types kanban-sanitizer dompurify`), `S6.2` (`🧼` `sanitized` `<EmojiHint>`), requirements `#5`, `#10` | **Dependencies:** `KB-P3-45`, `KB-P2-15`

2. **Step A - Client Hidden-DOM Paste-Jacking Pruner (`hiddenDomPruner.ts`, executes BEFORE `DOMPurify` strips `style`):**
   - Parses `text/html` (capped at `2,097,152` UTF-8 bytes / `2 MiB`) via `DOMParser` (`text/html`) inside an inert document (scripts do not execute, images do not fetch) wrapped by the `kanban-sanitizer` Trusted Types policy.
   - Walks the fragment pre-order and **deletes the entire subtree** (incrementing `prunedHiddenNodes`) whenever an element matches ANY of:
     1. HTML attribute `hidden` present or `aria-hidden="true"`.
     2. Inline `style` matching `display\s*:\s*none`, `visibility\s*:\s*(hidden|collapse)`, `opacity\s*:\s*0(\.0+)?\b` (or parsed float `<= 0.02`), `font-size\s*:\s*0([a-z%]+)?\b` (or `< 1px`).
     3. Zero-box clipping: `(width\s*:\s*0|max-width\s*:\s*0)` combined with `(height\s*:\s*0|max-height\s*:\s*0|overflow\s*:\s*hidden)`, `clip\s*:\s*rect\(\s*0`, or `clip-path\s*:\s*inset\(\s*100%`.
     4. Off-screen positioning: `left`, `top`, or `text-indent` `<= -1000px` (`position: absolute | fixed` or negative `text-indent`).
     5. Near-zero foreground/background contrast (`< 1.15` WCAG relative luminance ratio) when both `color` and `background`/`background-color` (on the node or nearest explicit ancestor) parse as RGB/hex/named colors (e.g. `#ffffff` text on `#fefefe` background).
     6. Non-content elements: `<script>`, `<style>`, `<template>`, `<noscript>`, `<iframe>`, `<object>`, `<embed>`, `<meta>`, and all HTML comment nodes (`Node.COMMENT_NODE`).
   - Strips invisible prompt-injection Unicode characters across all text outputs: `U+200B..U+200F` (zero-width & bidi marks), `U+202A..U+202E`, `U+2060..U+206F`, `U+FEFF`, and `U+E0000..U+E007F` (Unicode Tag block).
3. **5-Branch Clipboard Classifier (`autoConvertPaste.ts`):**
   - **Branch 1 - Image / `.svg` Binary Paste (`clipboardData.files`):** When `files.length > 0` and MIME is in `['image/png', 'image/jpeg', 'image/webp', 'image/avif', 'image/gif', 'image/svg+xml']`:
     - Rejects files `> 26,214,400` bytes (`25 MB`) without network upload, announcing `Attachment exceeds 25 MB limit`.
     - Inserts an optimistic placeholder `[Uploading <filename>...]` tracked by decoration/pos, uploads via `POST /api/v1/projects/{projectId}/attachments` (`KB-P2-15`, `X-CSRF-Token` from `apiFetch`), and replaces the placeholder with `![<sanitizedName>](attachment://<att_id>)`. Rolls back placeholder and announces error on failure.
   - **Branch 2 - IDE Syntax-Highlighted Code Wrapper Bypass (`ideWrapperBypass.ts`):**
     - Matches when `clipboardData.getData('vscode-editor-data')` is present (JSON `mode` mapped to fence language, e.g. `typescript` -> `ts`) OR `text/html` root consists solely of a single `<pre>`/`<div>` containing only `<span>`/`<br>`/`<code>` children with inline `color`/`background` styles and zero semantic block tags (`h1..h6`, `p`, `ul`, `ol`, `table`, `blockquote`, `a`, `img`).
     - Ignores HTML styling noise and inserts `text/plain` (stripped of invisible Unicode) wrapped in a canonical fenced code block ```` ```<lang> ````.
   - **Branch 3 - Rich HTML Paste (`text/html` from browsers, Docs, Confluence, Word, Jira):**
     - Runs Step A (`pruneHiddenDom(rawHtml)`), then Step B: `DOMPurify.sanitize(prunedHtml, { RETURN_TRUSTED_TYPE: true, FORBID_TAGS: ['style', 'script', 'iframe', 'form', 'input'], FORBID_ATTR: ['style', 'onerror', 'onload', 'onclick'] })` -> `hast-util-from-dom` -> `hast-util-to-mdast` (preserving headings `h1..h6`, GFM tables, `[ ]`/`[x]` task inputs, `<pre><code>`, `<blockquote>`, images, and allowlisted links `https://`, `http://`, `mailto:`, `#`, `/`) -> `remark-gfm` + `remark-stringify` (`bullet: '-'`, `fence: '`'`).
   - **Branch 4 - Raw Markdown in `text/plain` (`markdownDensity.ts`):**
     - Evaluated when `text/html` is empty. Parses `text/plain` with `remark-parse` + `remark-gfm`; triggers auto-parse into ProseMirror blocks when `>= 2` structural block tokens exist (headings, lists, blockquotes, task items, thematic breaks) OR `>= 1` fenced code block / ```` ```mermaid ```` / ```` ```svg ```` / GFM pipe table exists. Otherwise falls through to plain-text insertion so single `*` or `#` characters in casual prose are not misinterpreted.
   - **Branch 5 - Plain Text Fallback + Two-Step `Cmd/Ctrl+Z` Undo Contract:**
     - Whenever Branch 2, 3, or 4 converts clipboard text and a non-empty `text/plain` payload exists:
       1. Dispatch transaction 1 inserting sanitized `text/plain` at the current selection, followed by `closeHistory(tr1)` (`prosemirror-history`).
       2. Immediately dispatch transaction 2 replacing that exact inserted range with the converted ProseMirror Markdown slice, followed by `closeHistory(tr2)`.
     - Pressing `Cmd/Ctrl+Z` once undoes transaction 2, leaving the exact `text/plain` paste in the document; pressing `Cmd/Ctrl+Z` a second time undoes transaction 1 cleanly.
4. **`SanitizedPastePill.tsx` (`🧼` `<EmojiHint kind="sanitized">`, `S5.2` & `S6.2`):**
   - Appears in the editor's bottom-right floating status slot for `4000ms` after Branch 2, 3, or 4 conversion (timer pauses while pointer or keyboard focus is inside the pill/tooltip; `Escape` dismisses immediately; zero layout shift).
   - Renders `<EmojiHint kind="sanitized">` (`24x24` `🧼` pill) with visible concise label `Converted to Markdown` and tooltip content starting with the exact S5.2 literal string: `Converted pasted HTML to clean Markdown - Cmd+Z to paste plain text` (appending ` (stripped <N> hidden element(s))` when `prunedHiddenNodes > 0`).
