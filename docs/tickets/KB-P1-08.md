### User Story
As a **project member planning work**, I need **`cycles` and `modules` graph objects plus the issue join tables for modules, assignees (principal or free text), labels (with exclusive-group auto-replace), and subscriptions** so that **issues can be planned into sprints/modules, assigned without granting access to free-text vendors, and labeled without conflicting labels of one group**.

**Requirement Traceability:** `S7.2 8b` (principal XOR `free_text_assignee`), `8f` (`modules_enabled`, `project_module_defaults`), `8g` (`issues.cycle_id`, `upcoming`/`active`/`completed`), `8i` (`exclusive_group` auto-replace), `8l` (`issue_subscriptions`, creator/assignee auto-subscribe), Requirements `#8b #8f #8g #8i #8l #13f #13g` | **Dependencies:** `KB-P1-05`

2. **Objects:**
   ```sql
   CREATE TABLE cycles (
       id            UUID PRIMARY KEY,
       object_type   object_kind NOT NULL DEFAULT 'cycle' CHECK (object_type = 'cycle'),
       workspace_id  UUID NOT NULL,
       project_id    UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       name          TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 200),
       status        TEXT NOT NULL DEFAULT 'upcoming' CHECK (status IN ('upcoming','active','completed')),
       start_date    DATE,
       end_date      DATE,
       CHECK (end_date IS NULL OR start_date IS NULL OR end_date >= start_date),
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT,
       EXCLUDE USING gist (project_id WITH =, daterange(start_date, end_date, '[]') WITH &&)
           WHERE (start_date IS NOT NULL AND end_date IS NOT NULL)
   );
   CREATE UNIQUE INDEX cycles_one_active_per_project ON cycles (project_id) WHERE status = 'active';
   ALTER TABLE issues ADD CONSTRAINT issues_cycle_fk
       FOREIGN KEY (cycle_id) REFERENCES cycles(id) ON DELETE SET NULL;
   CREATE TABLE modules (
       id            UUID PRIMARY KEY,
       object_type   object_kind NOT NULL DEFAULT 'module' CHECK (object_type = 'module'),
       workspace_id  UUID NOT NULL,
       project_id    UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       name          TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 200),
       start_date    DATE,
       target_date   DATE,
       CHECK (target_date IS NULL OR start_date IS NULL OR target_date >= start_date),
       UNIQUE (project_id, name),
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT
   );
   ```
   (`btree_gist` from KB-P1-01 enables the uuid `=` operator inside the `EXCLUDE` constraint.)
3. **Join tables:**
   ```sql
   CREATE TABLE project_module_defaults (
       project_id UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       module_id  UUID NOT NULL REFERENCES modules(id)  ON DELETE CASCADE,
       workspace_id UUID NOT NULL,
       PRIMARY KEY (project_id, module_id));
   CREATE TABLE issue_modules (
       issue_id  UUID NOT NULL REFERENCES issues(id)  ON DELETE CASCADE,
       module_id UUID NOT NULL REFERENCES modules(id) ON DELETE CASCADE,
       workspace_id UUID NOT NULL,
       PRIMARY KEY (issue_id, module_id));
   CREATE TABLE issue_assignees (
       id                  UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id        UUID NOT NULL,
       issue_id            UUID NOT NULL REFERENCES issues(id) ON DELETE CASCADE,
       principal_id        UUID REFERENCES principals(id) ON DELETE RESTRICT,
       free_text_assignee  TEXT CHECK (free_text_assignee IS NULL OR char_length(btrim(free_text_assignee)) BETWEEN 1 AND 120),
       created_at          TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       CHECK (num_nonnulls(principal_id, free_text_assignee) = 1));
   CREATE UNIQUE INDEX issue_assignees_principal_uq ON issue_assignees (issue_id, principal_id) WHERE principal_id IS NOT NULL;
   CREATE UNIQUE INDEX issue_assignees_text_uq ON issue_assignees (issue_id, lower(free_text_assignee)) WHERE free_text_assignee IS NOT NULL;
   CREATE TABLE issue_labels (
       issue_id  UUID NOT NULL REFERENCES issues(id) ON DELETE CASCADE,
       label_id  UUID NOT NULL REFERENCES project_labels(id) ON DELETE CASCADE,
       workspace_id UUID NOT NULL,
       PRIMARY KEY (issue_id, label_id));
   CREATE TABLE issue_subscriptions (
       issue_id      UUID NOT NULL REFERENCES issues(id) ON DELETE CASCADE,
       principal_id  UUID NOT NULL REFERENCES principals(id) ON DELETE CASCADE,
       workspace_id  UUID NOT NULL,
       source        TEXT NOT NULL CHECK (source IN ('MANUAL','CREATOR','ASSIGNEE','MENTION')),
       is_muted      BOOLEAN NOT NULL DEFAULT FALSE,
       created_at    TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       PRIMARY KEY (issue_id, principal_id));
   ```
4. **Triggers:**
   - `cycles_/modules_spine_match_biu`: `objects.workspace_id/project_id` equal row values (`PLANNING_SPINE_MISMATCH`).
   - `issues_cycle_project_biu` (BEFORE INSERT OR UPDATE OF cycle_id ON issues): cycle must belong to `NEW.project_id` (`CYCLE_PROJECT_MISMATCH`).
   - `issue_modules_guard_bi` / `project_module_defaults_guard_bi`: module project equals issue/project; `projects.modules_enabled = FALSE` -> `MODULES_DISABLED` (S7.2 8f).
   - `issues_apply_module_defaults_ai` (AFTER INSERT ON issues): when `modules_enabled`, inserts `issue_modules` rows from `project_module_defaults`.
   - `issue_assignees_guard_bi`: principal must be `principal_type IN ('USER','AGENT')`, `status='ACTIVE'`, same workspace (`ASSIGNEE_INVALID_PRINCIPAL`). Free-text rows grant zero access: they are never read by KB-P1-13 access computation (documented in `COMMENT ON COLUMN issue_assignees.free_text_assignee`).
   - `issue_labels_exclusive_bi` (BEFORE INSERT): label project must equal issue project (`LABEL_PROJECT_MISMATCH`); lock the issue row `FOR UPDATE`; if label has non-NULL `exclusive_group`, `DELETE FROM issue_labels` rows of the same issue whose label has the same `exclusive_group`.
   - `issues_autosubscribe_creator_ai` (AFTER INSERT ON issues): inserts `(issue, created_by_id, 'CREATOR')` `ON CONFLICT DO NOTHING`.
   - `issue_assignees_autosubscribe_ai` (AFTER INSERT, principal rows only): inserts `(issue, principal, 'ASSIGNEE')` `ON CONFLICT DO NOTHING`.
   - All join tables: `workspace_id` set from the parent issue/project by trigger (client value overwritten).
5. **Down migration:** drops triggers/functions, the 5 join tables, `issues_cycle_fk`, `modules`, `cycles`.

### Mandatory Feature Unit Tests
- **Test File(s):** `database/tests/test_p1_08_planning.py`, `database/tests/migrations/test_p1_08_migration.py`
- **Required Test Cases:**
  1. Positive: issue assigned to cycle; deleting the cycle row sets `issues.cycle_id` to NULL.
  2. Positive: with `modules_enabled=TRUE` and 2 default modules, a new issue receives exactly 2 `issue_modules` rows; creator auto-subscribed with `source='CREATOR'`; principal assignee auto-subscribed with `source='ASSIGNEE'`.
  3. Positive (exclusive labels): issue has `type:feature` (group `type`) and `ui` (no group); adding `type:bug` leaves exactly `{type:bug, ui}`.
  4. Negative: assignee row with both `principal_id` and `free_text_assignee` raises `23514`; with neither raises `23514`; free-text row creates no subscription.
  5. Negative/security: assigning a GROUP principal or a principal from another workspace raises `ASSIGNEE_INVALID_PRINCIPAL`; label from another project raises `LABEL_PROJECT_MISMATCH`; cycle from another project raises `CYCLE_PROJECT_MISMATCH`; `issue_modules` insert with `modules_enabled=FALSE` raises `MODULES_DISABLED`.
  6. Boundary: two cycles in one project with overlapping dates raise `23P01`; adjacent non-overlapping ranges accepted; a second `active` cycle raises `23505`; free-text assignee of 120 chars accepted, 121 rejected.
  7. Migration up/down: upgrade `p1_08_planning_joins` -> 7 tables + `issues_cycle_fk` exist; downgrade to `previous_of(...)` -> absent; re-upgrade succeeds.
  - All non-migration tests run under the KB-P0-05 clean-DB `SAVEPOINT` harness; touched-module coverage `>= 95%`.
