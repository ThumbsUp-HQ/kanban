### User Story
As an **AI/LLM systems engineer building permission-filtered RAG**, I need **an RLS-protected `object_embeddings` table with an HNSW index, a hash-pinned local Int8 ONNX `bge-small-en-v1.5` embedder, and an outbox-driven worker that keeps embeddings in sync with canonical Markdown** so that **Sparkle retrieval can run in `<= 18ms` and can only ever return vectors for objects the caller can read**.

**Requirement Traceability:** `S9.3 item 2 (CPU Int8 ONNX bge-small-en-v1.5 ~4ms, object_embeddings, app_rls_reader)`, `S2.2 (pgvector HNSW in standalone)`, `S2.5`, original requirement `#7` | **Dependencies:** `KB-P1-18` (outbox), `KB-P0-12` (`LLMProvider.embed_batch`, `FixtureLLMProvider`)

2. **DDL:**
   ```sql
   CREATE TABLE object_embeddings (
       object_id       UUID NOT NULL,
       object_type     object_kind NOT NULL,
       chunk_index     SMALLINT NOT NULL CHECK (chunk_index BETWEEN 0 AND 63),
       workspace_id    UUID NOT NULL,
       project_id      UUID,
       content_sha256  BYTEA NOT NULL CHECK (octet_length(content_sha256) = 32),
       model_id        TEXT NOT NULL,              -- e.g. 'bge-small-en-v1.5-int8'
       embedding       vector(384) NOT NULL,
       updated_at      TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       PRIMARY KEY (object_id, chunk_index),
       FOREIGN KEY (object_id, object_type) REFERENCES objects(id, object_type) ON DELETE CASCADE
   );
   CREATE INDEX object_embeddings_hnsw ON object_embeddings
       USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64);
   CREATE INDEX object_embeddings_scope ON object_embeddings (workspace_id, project_id);
   ALTER TABLE object_embeddings ENABLE ROW LEVEL SECURITY;
   ALTER TABLE object_embeddings FORCE ROW LEVEL SECURITY;
   ```
   - `SELECT` policy: identical predicate to `objects_select_rls` in S3.3 (`workspace_id` match AND `effective_resource_access` row with `(allow_mask & 1) = 1 AND (deny_mask & 1) = 0` for `app_effective_principal_set()`).
   - `INSERT/UPDATE/DELETE` policy `WITH CHECK`: workspace match AND `current_setting('app.principal_id', true)::uuid` equals the `svc-embedding-indexer` service principal id (looked up via a `STABLE` SQL function `app_embedding_indexer_principal()`).
   - `GRANT SELECT ON object_embeddings TO app_rls_reader`; no write grant to `app_rls_reader`.
3. **`OnnxBgeSmallEmbedder`:**
   - Loads `model_int8.onnx` + `tokenizer.json` from `KANBAN_EMBED_MODEL_DIR` (no runtime download, zero network). Before loading, computes SHA-256 of both files and compares with constants `BGE_SMALL_INT8_ONNX_SHA256` / `BGE_SMALL_TOKENIZER_SHA256` in the module; mismatch -> `EmbedderIntegrityError` (refuse to start).
   - `onnxruntime.InferenceSession(path, providers=["CPUExecutionProvider"], sess_options)` with `intra_op_num_threads=1`, `graph_optimization_level=ORT_ENABLE_ALL`.
   - Truncation at `512` tokens; CLS pooling; L2-normalized `float32[384]`; batch `<= 32`.
   - Inference executed in `asyncio.to_thread` with a bounded semaphore (`2`).
4. **`EmbeddingIndexer`:**
   - Consumes outbox events (KB-P1-18) `issue.*`, `doc.*`, `sticky.*`, `page.*` with `created|updated|deleted`.
   - Reads canonical `*_markdown` under the indexer service-principal RLS context; chunks at `1,500` chars with `200`-char overlap, max `64` chunks; skips re-embedding when `content_sha256` of the chunk is unchanged; deletes rows on `deleted` or when chunk count shrinks.
   - Idempotent per event id; failure of one event does not block the batch; poison event after `5` attempts is logged `EMBEDDING_INDEX_FAILED` and acknowledged (no infinite retry).
   - Content passed to any non-local `ProviderEmbedder` is first run through `kanban/security/scrubber.py` if available (KB-P2-17); local ONNX path needs no scrubbing (no egress).
5. **`dependency-evaluation.md`:** `onnxruntime` (`MIT`), `tokenizers` (`Apache-2.0`), `numpy` (`BSD-3`), `pgvector` Python (`MIT`); model weights `BAAI/bge-small-en-v1.5` license `MIT` with pinned file hashes; alternatives (`sentence-transformers` + `torch` rejected for image size; `fastembed` evaluated); architect + engineer sign-off.

### Mandatory Feature Unit Tests
- **Test File(s):** `database/tests/test_object_embeddings.py`, `agent/tests/embeddings/test_onnx_embedder.py`, `agent/tests/embeddings/test_indexer.py`
- **Cassettes (under `tests/fixtures/ai/`):** `embed_fixture_384_ok.yaml` (FixtureLLMProvider `embed_batch` returning deterministic 384-dim vectors), `embed_fault_timeout.yaml`, `embed_fault_dim_mismatch.yaml` (returns 383-dim vector)
- **Required Test Cases:**
  1. Positive (DB, `SAVEPOINT` harness): indexer inserts 3 chunks for an issue; KNN query `ORDER BY embedding <=> :q LIMIT 4` returns them for a reader with `VIEW`.
  2. Security: principal without `VIEW` on project B gets `0` rows from a KNN query that would otherwise rank B's object first.
  3. Security: `app_rls_reader` `INSERT` -> permission denied; a non-indexer principal under `kanban_app` -> RLS `WITH CHECK` violation.
  4. Security: tampered model file (1 byte changed in a temp copy) -> `EmbedderIntegrityError`; embedder never calls `InferenceSession`.
  5. Positive: `OnnxBgeSmallEmbedder` with `InferenceSession` faked returns L2-normalized vectors (norm `1.0 +/- 1e-6`) and truncates 600-token input to 512.
  6. Idempotency: same event processed twice -> one embedding write; unchanged content -> zero writes.
  7. Fault: `embed_fault_timeout.yaml` -> event retried, after 5 attempts acknowledged with `EMBEDDING_INDEX_FAILED`; `embed_fault_dim_mismatch.yaml` -> rejected, no row written.
  8. Boundary: document producing 65 chunks stores exactly 64; delete event removes all chunks; HNSW index present in `pg_indexes` with `vector_cosine_ops`.
  9. Catalog: `object_embeddings` has `relrowsecurity` and `relforcerowsecurity` TRUE.
- **Coverage:** `>= 95%` line + branch for `agent/embeddings/*.py` and `database/models/embeddings.py`.
