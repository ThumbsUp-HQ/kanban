### User Story
As an **AI/LLM systems engineer**, I need **an `OpenAIProvider` built on `AsyncOpenAI` that always sends `store=False`, enforces strict JSON-Schema structured outputs, and supports vetted custom base URLs (vLLM / Azure / LiteLLM)** so that **high-precision reasoning workloads run with zero data retention and cannot be redirected to an arbitrary endpoint**.

**Requirement Traceability:** `S10.1 (OpenAIProvider row)`, `S10.2`, `S15.2`, `S2.5`, original requirement `#2` | **Dependencies:** `KB-P0-12`, `KB-P5-01` (reuses `registry.py`, `CassetteTransport`, `--http-cassette`)

### Scoped Technical Actions
1. **Target Files:**
   - `agent/providers/openai_provider.py` (new; module name avoids shadowing the `openai` package)
   - `agent/providers/registry.py` (modify: register `openai`)
   - `agent/pyproject.toml` + `uv.lock` (add `openai`, exact pin + hash)
   - `agent/GEMINI.md` (update)
   - `docs/qa/<TICKET_ID>/dependency-evaluation.md` (new)
2. **`OpenAISettings` (Pydantic v2, `frozen=True`, `extra="forbid"`):** `api_key: SecretStr` (plaintext only in memory; the KMS-wrapped at-rest form is owned by KB-P5-05a), `base_url: HttpUrl | None` (default `https://api.openai.com/v1`; must be `https` unless host is loopback `127.0.0.1`/`::1`; userinfo, query and fragment rejected), `base_url_kind: Literal["openai", "azure", "vllm", "litellm"]`, `model_allowlist: tuple[str, ...]` (e.g. `gpt-4o-mini`, `gpt-4.1`, `o3-mini`), `organization: str | None`, `timeout_s: float = 30.0` (bounds `1..300`), `residency_tier: str` (admin-declared, e.g. `openai-zdr-us`).
3. **`OpenAIProvider` implementing `LLMProvider`:**
   - Client: `AsyncOpenAI(api_key=..., base_url=..., max_retries=0, timeout=..., http_client=httpx.AsyncClient(transport=transport, trust_env=False, follow_redirects=False))`. `max_retries=0` because retries/failover belong to the router (KB-P5-04).
   - `stream_complete(req)` -> `chat.completions.create(model, messages, stream=True, store=False, temperature, max_tokens)`; yields typed `StreamChunk`.
   - `generate_structured(req)` -> `chat.completions.create(..., store=False, response_format={"type": "json_schema", "json_schema": {"name": ..., "strict": True, "schema": <Pydantic JSON Schema with additionalProperties=false>}})`; content re-validated locally with Pydantic; `refusal` field set -> `ProviderRefusal`; schema mismatch -> `ProviderSchemaError`.
   - `embed_batch(req)` -> `embeddings.create(model, input)`; batch `<= 64`, each input `<= 8,192` chars.
   - `health_probe()` -> `models.retrieve(model)`; never raises.
   - Every outbound request body MUST contain `"store": false` for chat endpoints - enforced by a single private `_chat_kwargs()` builder that callers cannot bypass, and asserted on the wire by tests.
   - Error mapping: `RateLimitError` -> `ProviderHTTPError(429)`, `APIStatusError(5xx)` -> `ProviderHTTPError(5xx)`, `APITimeoutError` -> `ProviderTimeout`, `APIConnectionError` -> `ProviderUnavailable`; 3xx -> `ProviderProtocolError(code="REDIRECT_REFUSED")`.
   - API key never appears in logs, `repr`, or exception text.
4. **`dependency-evaluation.md`:** package `openai`, license `Apache-2.0`, exact version + hash, transitive deps + licenses, alternatives (raw `httpx` REST client), architect + engineer sign-off.

### Mandatory Feature Unit Tests
- **Test File(s):** `agent/tests/providers/test_openai_provider.py`
- **Cassettes (new, under `tests/fixtures/ai/`):** `openai_stream_ok.yaml`, `openai_structured_ok.yaml`, `openai_structured_refusal.yaml`, `openai_structured_schema_mismatch.yaml`, `openai_embed_ok.yaml`, `openai_fault_429.yaml`, `openai_fault_500.yaml`, `openai_fault_timeout.yaml`, `openai_fault_redirect_307.yaml`
- **Required Test Cases:**
  1. Positive: SSE stream chunks match cassette; recorded request JSON contains `"store": false`.
  2. Positive: structured output parsed; request carries `response_format.json_schema.strict == true` and `additionalProperties: false` at every object level.
  3. Contract parity with `FixtureLLMProvider` for the same scenario.
  4. Security: base URL `http://evil.example/v1` rejected; `https://user:pw@host/v1` rejected; `http://127.0.0.1:8000/v1` accepted for `vllm`.
  5. Security: `HTTPS_PROXY` env ignored; 307 redirect -> `REDIRECT_REFUSED`.
  6. Security: API key absent from `repr`, logs (`caplog`) and exception messages.
  7. Fault injection: `429`, `500`, timeout -> typed errors with zero SDK-internal retries (assert exactly 1 transport call per request).
  8. Negative: refusal -> `ProviderRefusal`; schema mismatch -> `ProviderSchemaError`.
  9. Boundary: model outside allowlist -> `MODEL_NOT_ALLOWED` with zero transport calls; embed batch `65` rejected.
- **Coverage:** `>= 95%` line + branch for `agent/providers/openai_provider.py`; `pytest-socket` enforced.
