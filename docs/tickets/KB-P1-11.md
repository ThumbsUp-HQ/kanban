### User Story
As a **database platform engineer**, I need **the `link_kind` enum, the `object_links` edge table with composite type-pinned `ON DELETE RESTRICT` foreign keys and canonical-key snapshots, and an immutable `link_type_matrix` allowlist enforced on insert** so that **every relationship in the Universal Object Graph connects valid node types, never self-links, and preserves endpoint key snapshots for forensic auditing**.

**Requirement Traceability:** `S12.1` (`link_kind` 13-value enum, `object_links` DDL verbatim), `S7.2 8m` (user-creatable vs system link kinds), `S12.3 item 4` (`TYPE_MATRIX_VIOLATION` baseline allowlist), Requirements `#8m`, `#13` | **Dependencies:** `KB-P1-02`

2. **`link_kind` & `object_links` DDL Verbatim from S12.1:**
   ```sql
   CREATE TYPE link_kind AS ENUM (
       'BLOCKS', 'BLOCKED_BY', 'RELATES_TO', 'DUPLICATES', 'PARENT_OF',
       'ASSIGNED_TO', 'IN_CYCLE', 'IN_MODULE', 'PROMOTED_TO_DOC',
       'VERIFIED_BY_DOC', 'DERIVED_FROM_STICKY', 'EMBEDS_OBJECT', 'GOVERNED_BY_VIEW'
   );

   CREATE TABLE object_links (
       id                  UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id        UUID NOT NULL REFERENCES workspaces(id) ON DELETE RESTRICT,
       source_id           UUID NOT NULL,
       source_type         object_kind NOT NULL,
       target_id           UUID NOT NULL,
       target_type         object_kind NOT NULL,
       link_type           link_kind NOT NULL,
       link_state          TEXT NOT NULL DEFAULT 'ACTIVE'
                           CHECK (link_state IN ('ACTIVE', 'FLAGGED_INVALID')),
       source_key_snapshot TEXT NOT NULL,
       target_key_snapshot TEXT NOT NULL,
       created_by_id       UUID NOT NULL,
       created_at          TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       CHECK (source_id <> target_id),
       UNIQUE (source_id, target_id, link_type),
       FOREIGN KEY (source_id, source_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT,
       FOREIGN KEY (target_id, target_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT
   );
   CREATE INDEX object_links_source_idx ON object_links (source_id, link_state);
   CREATE INDEX object_links_target_idx ON object_links (target_id, link_state);
   CREATE INDEX object_links_ws_state_idx ON object_links (workspace_id, link_state);
   ```

3. **Allowlist Catalog `link_type_matrix`:**
   ```sql
   CREATE TABLE link_type_matrix (
       source_type       object_kind NOT NULL,
       link_type         link_kind   NOT NULL,
       target_type       object_kind NOT NULL,
       is_user_creatable BOOLEAN     NOT NULL DEFAULT FALSE,
       PRIMARY KEY (source_type, link_type, target_type)
   );
   REVOKE INSERT, UPDATE, DELETE ON link_type_matrix FROM kanban_app;
   ```
   Seeded tuples in `p1_11_object_links.up.sql`:
   - `is_user_creatable = TRUE` (S7.2 `8m` user kinds):
     - `('issue', k, 'issue')` for `k IN ('BLOCKS', 'BLOCKED_BY', 'DUPLICATES')`
     - `(s, 'RELATES_TO', t)` for all pairs `s, t IN ('issue', 'sticky', 'doc', 'page', 'cycle', 'module', 'view')`
     - `('issue', 'VERIFIED_BY_DOC', t)` for `t IN ('doc', 'page')`
     - `(s, 'DERIVED_FROM_STICKY', 'sticky')` for `s IN ('issue', 'doc', 'page')`
   - `is_user_creatable = FALSE` (system-managed graph kinds):
     - `('sticky', 'PROMOTED_TO_DOC', 'doc')`
     - `('issue', 'PARENT_OF', 'issue')`, `('doc', 'PARENT_OF', 'page')`, `('page', 'PARENT_OF', 'page')`
     - `('issue', 'ASSIGNED_TO', 'user')`, `('issue', 'IN_CYCLE', 'cycle')`, `('issue', 'IN_MODULE', 'module')`
     - `(s, 'EMBEDS_OBJECT', t)` for `s IN ('issue', 'sticky', 'doc', 'page')` and `t IN ('issue', 'sticky', 'doc', 'page', 'view', 'cycle', 'module')`
     - `(s, 'GOVERNED_BY_VIEW', 'view')` for `s IN ('project', 'issue', 'cycle', 'module')`

4. **Triggers on `object_links`:**
   - `object_links_validate_bi` (`BEFORE INSERT ON object_links`):
     1. Checks `EXISTS (SELECT 1 FROM link_type_matrix WHERE source_type = NEW.source_type AND link_type = NEW.link_type AND target_type = NEW.target_type)` -> else `RAISE EXCEPTION USING ERRCODE = 'P0001', MESSAGE = 'LINK_TYPE_NOT_ALLOWED'`.
     2. Fetches `objects` rows for `NEW.source_id` and `NEW.target_id`; if either missing -> `LINK_ENDPOINT_NOT_FOUND`; if `src.workspace_id <> NEW.workspace_id OR tgt.workspace_id <> NEW.workspace_id` -> `LINK_CROSS_WORKSPACE_FORBIDDEN`.
     3. Forces `NEW.source_key_snapshot := src.canonical_key` and `NEW.target_key_snapshot := tgt.canonical_key` (overwriting any caller-supplied string so snapshots are authoritative at creation time) and `NEW.link_state := 'ACTIVE'`.
   - `object_links_guard_bu` (`BEFORE UPDATE ON object_links`): rejects mutation of any column other than `link_state` with `OBJECT_LINK_IMMUTABLE` (`id`, `workspace_id`, `source_id`, `source_type`, `target_id`, `target_type`, `link_type`, `source_key_snapshot`, `target_key_snapshot`, `created_by_id`, `created_at` are strictly write-once).

5. **Down Migration:** Drops triggers/functions, `object_links`, `link_type_matrix`, `link_kind`.

### Mandatory Feature Unit Tests
- **Test File(s):** `database/tests/test_p1_11_object_links.py`, `database/tests/migrations/test_p1_11_migration.py`
- **Required Test Cases:**
  1. Positive: linking `issue KAN-1 -> BLOCKS -> issue KAN-2` and `sticky STK-1 -> PROMOTED_TO_DOC -> doc DOC-1` succeeds, auto-populates `source_key_snapshot='KAN-1'` and `target_key_snapshot='KAN-2'`, and sets `link_state='ACTIVE'`.
  2. Positive: `UPDATE object_links SET link_state = 'FLAGGED_INVALID'` succeeds while preserving original key snapshots even if an `objects.display_title` changed.
  3. Negative (matrix & self-link): inserting `user -> IN_CYCLE -> doc` (S12.3 example) or `project -> BLOCKS -> issue` raises `LINK_TYPE_NOT_ALLOWED`; self-link `source_id = target_id` raises `23514`; duplicate `(source_id, target_id, link_type)` raises `23505`.
  4. Negative/security: cross-workspace link raises `LINK_CROSS_WORKSPACE_FORBIDDEN`; mismatching `source_type` vs `objects.object_type` raises `23503` (composite FK) or `LINK_TYPE_NOT_ALLOWED`; `DELETE FROM objects` on a linked endpoint raises `23503` (`ON DELETE RESTRICT`); as `kanban_app`, `INSERT INTO link_type_matrix` raises `42501`.
  5. Negative (immutability): `UPDATE object_links SET target_id = ...` or `SET target_key_snapshot = 'FAKE'` raises `OBJECT_LINK_IMMUTABLE`; `link_state = 'DELETED'` raises `23514`.
  6. Boundary: `pg_enum` for `link_kind` contains all 13 labels in exact S12.1 order; `link_type_matrix` marks exactly the 6 S7.2 `8m` user kinds as `is_user_creatable = TRUE` and all 7 system kinds as `FALSE`.
  7. Migration up/down: `MigrationHarness` upgrade `p1_11_object_links` -> tables and enum exist; downgrade to `previous_of(...)` -> absent; re-upgrade succeeds.
  - All non-migration tests run under the KB-P0-05 clean-DB `SAVEPOINT` harness; touched-module coverage `>= 95%`.
