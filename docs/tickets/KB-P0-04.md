### User Story
As a **release owner of an `Apache-2.0` project**, I need **an automated license gate that inspects every installed Python and Node dependency and fails on copyleft licenses unless an explicit, justified allowlist entry exists** so that **no `GPL`, `AGPL`, `SSPL`, or statically linked `LGPL` code can ever enter a build**.

**Requirement Traceability:** `S2.5` (permissive-only supply chain matrix), `S15.4` gate 1 (`pip-licenses` + `license-checker` across `uv.lock` and `pnpm-lock.yaml`), `Apache-2.0` license requirement | **Dependencies:** `KB-P0-01`, `KB-P0-03`

### Scoped Technical Actions
1. **Target Files:** `scripts/license_gate.py`, `license-allowlist.toml`, `pyproject.toml` (dev group adds `pip-licenses`), `uv.lock`, root `package.json` (devDependency `license-checker`), `pnpm-lock.yaml`, `Makefile` (target `license`), `scripts/tests/test_license_gate.py`, `scripts/tests/fixtures/licenses/*.json`
2. **CLI contract:** `uv run python -m scripts.license_gate [--python-json PATH] [--node-json PATH] [--allowlist PATH]`. Without `--*-json`, the script collects data itself by running, with `subprocess.run([...], shell=False, timeout=120, check=False)`:
   - `uv run pip-licenses --format=json --with-system --from=mixed` (environment produced by `uv sync --locked`)
   - `pnpm exec license-checker --json --start .` (after `pnpm install --frozen-lockfile --ignore-scripts`)
   Exit codes: `0` all pass; `1` at least one violation; `3` collector or parse error (fail closed, never `0`).
3. **Precondition:** Root `LICENSE` exists and its text contains `Apache License` and `Version 2.0`; otherwise exit `1` with `LICENSE_MISSING_OR_NOT_APACHE2`.
4. **Classifier `classify(license_expr: str) -> Verdict`** (`Verdict` is an `enum.StrEnum`: `ALLOW`, `DENY`, `UNKNOWN`):
   - Normalize: strip, collapse whitespace, map common long names (`"MIT License"` -> `MIT`, `"BSD License"` -> `BSD`, `"Apache Software License"` -> `Apache-2.0`, `"Python Software Foundation License"` -> `PSF-2.0`, `"Mozilla Public License 2.0 (MPL 2.0)"` -> `MPL-2.0`).
   - Denylist prefixes (case-insensitive): `GPL`, `AGPL`, `SSPL`, `LGPL`, `GNU General Public`, `GNU Affero`, `GNU Lesser`, `Server Side Public`, `RSAL`, `BUSL`, `Commons Clause`.
   - Allowlist: `MIT`, `MIT-0`, `ISC`, `BSD`, `BSD-2-Clause`, `BSD-3-Clause`, `0BSD`, `Apache-2.0`, `PSF-2.0`, `Python-2.0`, `PostgreSQL`, `Zlib`, `Unlicense`, `CC0-1.0`, `BlueOak-1.0.0`, `MPL-2.0` (file-level, per S2.5).
   - SPDX `OR`: `ALLOW` if any alternative is `ALLOW`. SPDX `AND`: `ALLOW` only if all are `ALLOW`; `DENY` if any is `DENY`. Parentheses supported. Empty, `UNKNOWN`, `UNLICENSED`, `Custom`, or unrecognized -> `UNKNOWN`.
   - Gate rule: `DENY` and `UNKNOWN` are both violations unless allowlisted.
5. **Allowlist file `license-allowlist.toml`:**
   ```toml
   # Each exception MUST name ecosystem, package, exact version, license, and justification.
   [[exception]]
   ecosystem = "python"   # or "node"
   package = "example"
   version = "1.2.3"
   license = "LGPL-3.0"
   linkage = "dynamic"    # required when license starts with LGPL; "static" is never accepted
   justification = "Loaded as a separate shared object; not statically linked. Reviewed by <agent> on <date>."
   ```
   Loader rejects (exit `3`) entries missing any field, `justification` shorter than 20 characters, version ranges or wildcards, and `LGPL*` entries whose `linkage != "dynamic"`. `GPL`, `AGPL`, `SSPL` entries are never honored regardless of allowlist (exit `1` with `NON_WAIVABLE_LICENSE`). The committed file contains zero exceptions and only the comment header.
6. **Output:** A deterministic table to stdout, one line per violation: `<ecosystem>\t<package>\t<version>\t<license>\t<DENY|UNKNOWN>`, followed by `SUMMARY python=<n> node=<n> violations=<n>`. Workspace members (`kanban-*`) and the root project are skipped by name.
7. **`Makefile`:** target `license` runs `uv run python -m scripts.license_gate`.

### Mandatory Feature Unit Tests
- **Test File(s):** `scripts/tests/test_license_gate.py` (uses JSON fixtures under `scripts/tests/fixtures/licenses/`; collectors are invoked only through `--python-json` / `--node-json` or a monkeypatched `subprocess.run`, so tests open zero network sockets)
- **Required Test Cases:**
  1. Positive: fixture with `MIT`, `BSD-3-Clause`, `Apache-2.0`, `MIT OR GPL-3.0` returns exit `0`.
  2. Negative/security: fixture containing `AGPL-3.0`, `GPL-2.0-or-later`, `SSPL-1.0` each produce exit `1` and a violation line; an allowlist entry for the `GPL` package still yields exit `1` with `NON_WAIVABLE_LICENSE`.
  3. Negative: `LGPL-3.0` package fails without allowlist; passes with a valid `linkage = "dynamic"` entry; allowlist entry with `linkage = "static"` causes exit `3`.
  4. Boundary: `UNKNOWN`/empty license string fails; `Apache-2.0 AND MIT` passes; `MIT AND GPL-3.0` fails; parenthesized `(MIT OR Apache-2.0) AND BSD-3-Clause` passes.
  5. Fail-closed: collector subprocess returns non-zero or emits invalid JSON -> exit `3`; missing `LICENSE` -> exit `1` with `LICENSE_MISSING_OR_NOT_APACHE2`.
  6. Boundary: allowlist with `justification` of 19 characters or `version = "1.*"` -> exit `3`.
