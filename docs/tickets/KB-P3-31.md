### User Story
As a **user scanning breathable cards, headers and property rails**, I need **every semantic status emoji to be a crisp 24x24 `<EmojiHint>` pill whose hover, focus or tap reveals a rich, copyable elaboration popover with zero flicker** so that **the UI stays uncluttered (no verbose inline status text) while full technical detail (principal names, hashes, SLA windows, verdicts) is one hover, one Tab, or one tap away for mouse, keyboard, screen-reader and touch users alike**.

**Requirement Traceability:** `S6.2` (timings, `24px x 24px`, `tabIndex`, `aria-describedby`, 21-emoji table), `S6.1` (`--text-body`, `--leading-prose`), requirements `#9`, `#15`, `#1` (`🛡️` pill) | **Dependencies:** `KB-P3-30`

3. **Timing engine (`hintTiming.ts`, framework-free, injectable clock):**
   - Constants: `HOVER_OPEN_DELAY_MS = 180`, `NEIGHBOR_WARMUP_WINDOW_MS = 400`, `FOCUS_OPEN_DELAY_MS = 0`, `BRIDGE_GRACE_MS = 120`.
   - `createHintController({ now, setTimer, clearTimer })` returns `{ pointerEnterTrigger(id), pointerLeaveTrigger(id), pointerEnterPopup(id), pointerLeavePopup(id), focus(id), blur(id), escape(), tap(id), subscribe(listener) }` with state `{ openId: string | null }`.
   - Rules: pointer enter opens after `180ms` unless the last close happened `< 400ms` ago, then opens at `0ms` (neighbor warmup). Keyboard focus opens at `0ms`. Pointer leave starts a `120ms` bridge; entering the popup within the bridge cancels the close. `escape()` closes immediately and emits `restoreFocus`. Only one hint open at a time globally (opening one closes the other, which counts as a close for warmup). Leaving the trigger before `180ms` cancels the pending open.
4. **`<EmojiHint>` component API and DOM:**
   ```tsx
   interface EmojiHintProps {
     kind: EmojiKey;
     content?: React.ReactNode | (() => React.ReactNode); // default = registry defaultHint; function form is lazily evaluated on open
     label?: string;                  // accessible name override (e.g. "Access: Project + 2")
     variant?: 'tooltip' | 'interactive';
     onActivate?: () => void;         // click/Enter action (e.g. open Access Inspector)
     activateLabel?: string;          // text for the touch action button, e.g. "Open Access Inspector"
     testId?: string;
   }
   ```
   - Trigger: `<button type="button" className="emoji-hint" aria-describedby={popupId}>`; inner `<span aria-hidden="true">{glyph}</span>`; accessible name via `aria-label={label ?? ariaLabel}`. Box: `width/height: var(--emoji-pill)` (24px), `border-radius: var(--radius-md)`, transparent background, `--bg-hover` on hover, focus-visible ring from KB-P3-30 `base.css`. Minimum hit area `var(--tap-min)` (44px) on `(pointer: coarse)` via `::before` pseudo-element without changing the 24px visual size or layout.
   - `variant="tooltip"` popup: `role="tooltip"`, `id={popupId}`, text selectable (`user-select: text`), copy with `Cmd/Ctrl+C` works because the popup stays open while pointer is inside it.
   - `variant="interactive"` popup: `role="dialog"`, `aria-label={ariaLabel}`, non-modal (no focus trap). Trigger gets `aria-expanded` and `aria-controls`. `Tab` from the open trigger moves focus to the first focusable element in the popup; `Shift+Tab` from the first returns to the trigger; `Escape` closes and returns focus to the trigger.
   - Activation: mouse click or `Enter`/`Space` calls `onActivate` when provided; otherwise toggles the popup (sticky open until Escape, outside click, or blur out of trigger+popup).
   - Touch (`pointerType === 'touch'`): first tap opens the popup (does NOT call `onActivate`); if `onActivate` exists the popup renders a button with text `activateLabel` that calls it. Tap outside closes.
   - Popup styling (`EmojiHint.css`): `max-width: var(--hint-max-w)` (360px), `padding: var(--hint-pad)` (12px 14px), `font-size: var(--text-body)`, `line-height: var(--leading-prose)`, `background: var(--bg-surface-raised)`, `border: 1px solid var(--border-subtle)`, `border-radius: var(--radius-lg)`, soft shadow, `z-index: 1000`. Fade `120ms` disabled under `prefers-reduced-motion`.
5. **Portal and positioning:** `HintPortal` renders into a single `<div id="kb-hint-root">` appended to `document.body` once. `positionHint(triggerRect, popupSize, viewport)` is a pure function returning `{ top, left, placement: 'top' | 'bottom' }`: prefer `bottom` with an `8px` offset, flip to `top` if the bottom edge would exceed `viewport.height - 8`, clamp `left` into `[8, viewport.width - popupWidth - 8]`. Position applied via CSSOM (`el.style.top = ...`), never via an injected `<style>` element or a `style` attribute string (CSP `style-src 'self'`). Repositions on `scroll` (capture) and `resize`.
6. **Security invariants:** `content` is rendered as React children only (never `dangerouslySetInnerHTML`); string content containing `<script>` renders as literal text. Popup ids are generated with `useId()` (no user input in ids).
7. **`EmojiStory.tsx` (`/__dev/emoji`):** A responsive grid (cards with `padding: var(--card-pad)`, gap `var(--card-gap)`) showing all 21 registry emojis, each with its key, domain and an `<EmojiHint>` using rich sample content: `access` -> `Project: Platform Core` / `14 users, 2 groups, 2 🤖 agents, 1 🔒 deny rule` / `Click to open Access Inspector`; `gateApproved` -> `Gate sec-review (cli: agy -p) approved in 812ms` / `verdict sha256: 9f2c...e41a` (copyable); `priorityUrgent` -> `Urgent - SLA 4h - sort weight 1 - press P to change`; `externalAssignee` -> the literal S7.2 8b text. One interactive sample (`access`, `onActivate` logs `inspector-opened` into a visible `data-testid="activation-log"`).
