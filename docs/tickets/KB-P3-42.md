### User Story
As a **project member or Project Administrator editing an issue inside the `320px` right properties rail (Drawer or Full Screen)**, I need **all 8 Plane-parity property rows (`State`, hybrid `Assignees` with `🏷️` external pills, customizable `Priority` `🔥/⚡/🔹/💤`, `Created by` with `🔄` provenance and admin override, `Start`/`Due` dates, conditional `Modules` completely unmounted when disabled, `Cycle`, `Parent` with `🔒` restricted masking, and `Labels` with exclusive groups)** so that **every property updates optimistically in `38px` breathable rows while enforcing anti-enumeration, DAG cycle limits, and `AAL2` provenance controls**.

**Requirement Traceability:** `S7.1` (`320px` properties rail wireframe lines 529-545, footnote line 554), `S7.2 8b` (hybrid assignees: `VIEW`-only autocomplete + `🏷️` free-text dashed pill), `S7.2 8c` (per-project priorities), `S7.2 8d` (`Created by` immutable for members, `PROJECT_ADMIN`/`SERVER_ADMIN` override + `🔄` provenance), `S7.2 8e` (`due_date >= start_date`, overdue suppressed when `completed`/`cancelled`), `S7.2 8f` (`Modules` row `100%` unmounted when `projects.modules_enabled = FALSE`), `S7.2 8g` (`Cycle`), `S7.2 8h` (`Parent` `max_depth <= 6`, cycle rejection, `🔒 Restricted Parent Issue` masking, sub-issues rollup), `S7.2 8i` (`Labels` `exclusive_group` replacement + inline create), `S6.1` (`--prop-row-h: 38px`), `S6.2` (`🏷️`, `🔄`, `🔒`, `🤖`, `🔥/⚡/🔹/💤`), requirements `#8b`-`#8i`, `#1`, `#9i`, `#15` | **Dependencies:** `KB-P3-41` (`IssueSurface` + `slotRegistry.ts`), `KB-P3-01b` (states/priorities/labels), `KB-P3-03` (assignees API), `KB-P3-04` (provenance API), `KB-P3-10a` (cycles API), `KB-P3-10b` (modules API)

2. **Breathable rail geometry (`PropertiesRail.tsx`, `S6.1` & `S7.1`):**
   - Renders inside `<aside class="surface__rail" aria-label="Properties">` (`width: 320px` desktop, full-width stacked below `880px` container per `KB-P3-41`, `padding: var(--space-6)` `24px`).
   - Every `.prop-row` is a 2-column grid (`112px minmax(0, 1fr)`, `column-gap: var(--space-3)` `12px`, `min-height: var(--prop-row-h)` = `38px` exact, NEVER shrunk at any breakpoint). Read-only mode when caller lacks `'EDIT'` in `issue.capabilities` disables controls without hiding values.
3. **Exact row contracts (`8b` - `8i`):**
   - **State & Priority (`8c`):** `State` groups options by `backlog | unstarted | started | completed | cancelled` (`PATCH /api/v1/issues/{key}` `{ state_id }`, disabled if caller lacks `'TRANSITION'` capability). `Priority` reads `GET /api/v1/projects/{projectKey}/priorities` (supports custom project priorities like `🧯 Blocker` in addition to seeded `Urgent 🔥`, `High ⚡`, `Medium 🔹`, `Low 💤`, `None`), updating via `PATCH { priority: slug }`.
   - **Hybrid Assignees (`8b`, `KB-P3-03`):**
     - Combobox queries `GET /api/v1/projects/{projectKey}/assignee-suggestions?q=<q>&limit=10` (debounced `120ms`, `q` length `1..64`). Renders `@handle` (`USER`) and `🤖 handle` (`AGENT`, wrapped with `<EmojiHint kind="agent">`) options; selecting calls `POST /api/v1/issues/{key}/assignees` `{ principal: handle }`.
     - Typing any text `1..120` chars not matching an option exposes explicit option `Add external label: "<trimmed>" (no access or notifications)` -> calls `POST .../assignees` `{ free_text }`.
     - Free-text assignees render with `.assignee-pill--external` (`border: 1px dashed var(--border-strong)`) containing `<EmojiHint kind="externalAssignee" />` (`🏷️`, hover text exact: `"External free-text label - grants zero access and sends zero notifications"`), text, and remove `×` button (`DELETE .../assignees/{id}`). Enforces max `20` total / `10` free-text client-side and surfaces `422 ASSIGNEE_LIMIT` / `409 ASSIGNEE_EXISTS`.
   - **Created by & Admin Provenance (`8d`, `KB-P3-04`):**
     - Standard members see immutable `@handle` (or `1 External Collaborator` when `provenance.created_by.redacted === true`).
     - When `issue.provenance.overridden === true`, renders `<EmojiHint kind="creatorOverride" />` (`🔄`) next to creator with exact popover lines: `"Originally created by @<orig> - overridden to @<current> by @<modifier> on <ISO timestamp>. Reason: <reason>"` (redacted principals shown as `"1 External Collaborator"`, never handles).
     - ONLY when caller holds `ADMIN` in `project.capabilities` (or `me.is_server_admin`), renders a subtle `Change...` button opening `OverrideCreatorModal`: `VIEW`-filtered user picker + mandatory `reason` textarea (`10..500` trimmed chars) -> `PATCH /api/v1/issues/{key}/created-by`. On `403 AAL2_REQUIRED`, invokes `SecondFactorStep` (`KB-P3-35` if present, else inline TOTP/Passkey step-up prompt) and retries once.
   - **Start date & Due date (`8e`):** native/accessible ISO `YYYY-MM-DD` date inputs (`PATCH { start_date, due_date }`). Rejects `due_date < start_date` inline (`role="alert"`: `"Due date cannot be earlier than start date."`) before network call. Renders localized overdue pill next to `Due date` ONLY when `due_date < today && !['completed', 'cancelled'].includes(issue.state.group)`.
   - **Conditional Modules (`8f`, `KB-P3-10b`):** When `project.modules_enabled === false`, `DatesCycleModulesRows` returns `null` for the `Modules` row (`document.querySelector('[data-prop="modules"]') === null` - `100%` unmounted from DOM, not `display: none`). When `true`, fetches `GET /api/v1/projects/{projectKey}/modules` and updates `PUT /api/v1/issues/{key}/modules` `{ module_ids }` (max `10`).
   - **Cycle (`8g`, `KB-P3-10a`):** single-select from `GET /api/v1/projects/{projectKey}/cycles`, showing cycle `status` badge (`active` / `upcoming` / `completed`) and `(completed_count/issue_count)` + `Clear` option (`PATCH { cycle_id }`).
   - **Parent & Sub-issues Rollup (`8h`, `KB-P3-02`):**
     - When `issue.parent?.restricted === true`, renders non-interactive chip with `<EmojiHint kind="restricted" content="Parent issue is in a restricted scope outside your visibility." />` (`🔒`) and literal text `"Restricted Parent Issue"` (zero key, id, or link).
     - Otherwise renders `<IssueKeyLink>` `[KAN-100 Auth Epic]` + `Change` / `Clear` combobox (`PATCH { parent: key | null }`). Maps `409 PARENT_CYCLE` -> `"Cannot set parent: this would create a parent cycle."` and `409 PARENT_DEPTH_EXCEEDED` -> `"Cannot set parent: maximum hierarchy depth (6) exceeded."`.
     - Also exports/renders `SubIssuesRollup` (`Sub-issues (2/3 Done)  67%  [+ Add]` per `S7.1` lines 539-541) when `issue.sub_issues` is non-empty or `+ Add` is clicked.
   - **Labels (`8i`, `KB-P3-01b` + `KB-P3-02`):** multi-select from `GET /api/v1/projects/{projectKey}/labels`. Selecting a label with `exclusive_group: "type"` automatically replaces any existing label on the issue sharing `exclusive_group === "type"` in the optimistic `PATCH { label_ids }` payload and announces `"Replaced <old> with <new> (exclusive group: type)"`. Authorized `EDIT` callers get inline `+ Create label "<query>"` (`POST /api/v1/projects/{projectKey}/labels`).

- **Required Test Cases:**
  1. Positive (all 8 rows): renders `State`, `Assignees`, `Priority`, `Created by`, `Start date`, `Due date`, `Modules` (when enabled), `Cycle`, `Parent`, `Labels` in `S7.1` order; changing `State` or `Priority` fires optimistic `PATCH` and updates cache.
  2. Hybrid Assignees (`8b`): suggestions call `GET .../assignee-suggestions` and render `@adam` + `🤖 codex`; adding free-text `"Vendor: NCC Group"` renders `.assignee-pill--external` with `🏷️` `<EmojiHint>` exact text `"External free-text label - grants zero access and sends zero notifications"`; `21st` assignee or `11th` free-text is blocked with limit error.
  3. Created-by Provenance (`8d`): standard `EDIT` user sees no `Change...` button; `ADMIN` user sees `Change...`, rejects `9`-char reason, submits `15`-char reason to `PATCH .../created-by`, and `🔄` `<EmojiHint>` displays original creator, modifier, timestamp, and reason (masking `redacted: true` principals as `"1 External Collaborator"`).
  4. Conditional `Modules` unmount (`8f`): when `project.modules_enabled === false`, `queryByText('Modules')` and `container.querySelector('[data-prop="modules"]')` are both `null` and `GET .../modules` is NEVER called.
  5. Parent masking, DAG errors & Exclusive Labels (`8h`, `8i`): `parent: { restricted: true, label: "🔒 Restricted Parent Issue" }` renders `🔒` `<EmojiHint>` + `"Restricted Parent Issue"` with zero `<a>` links; `409 PARENT_CYCLE` and `409 PARENT_DEPTH_EXCEEDED` render exact `role="alert"` messages; selecting `type:bug` removes `type:feature` (`exclusive_group: "type"`) in `label_ids`.
  6. Dates & Security (`8e`): `due_date = "2026-11-10"` with `start_date = "2026-11-11"` shows alert and sends `0` requests; overdue badge disappears when state group becomes `completed`; hostile label/module/free-text `<img src=x onerror=alert(1)>` renders literal text.
