### User Story
As a **project member capturing quick notes on the Project Overview tab**, I need **6-color Markdown Stickies with server-computed complexity signals, a non-annoying `>= 1.5x` length snooze, and a single-transaction `promote-to-doc` endpoint that copies every direct ACL row verbatim** so that **growing scratchpads graduate cleanly into permanent Docs with zero accidental privilege widening**.

**Requirement Traceability:** Spec S8.1 (6-palette Stickies on Project Overview & Workspace Stickies tab); S8.2 (all 5 promotion triggers, snooze `>= 1.5x`, atomic `POST /api/v1/stickies/{id}/promote-to-doc`, verbatim `resource_acl_entries` copy, `PROMOTED_TO_DOC` link, Promoted Doc Stub + `[Unarchive Copy]`); S12.2 (`stickies`); S3.4 (`access_manifest`); requirements `#11`, `#5`, `#13b`, `#1` | **Dependencies:** `KB-P3-14`, `KB-P3-07`

### Scoped Technical Actions
1. **Target Files:** `kanban/api/v1/stickies.py`, `kanban/api/v1/schemas/stickies.py`, `kanban/services/stickies.py`, `kanban/services/sticky_heuristic.py`, `kanban/services/activity.py` (append event types).
2. **Promotion Complexity Heuristic (`kanban/services/sticky_heuristic.py`):**
   - `evaluate_sticky_promotion(body_markdown: str, snoozed_at_length: int | None, promoted_to_doc_id: UUID | None) -> PromotionAssessment`:
     - If `promoted_to_doc_id is not None`: `recommended = False`, `triggers = []`, `snoozed = False`.
     - Raw triggers (all evaluated outside fenced code blocks except trigger 4's fence checks; any 1 fires `raw_triggered = True`):
       1. `char_length`: `len(body_markdown) > 600` (Unicode code-point count matching PostgreSQL `char_length(body_markdown)`).
       2. `line_count`: `(body_markdown.count("\n") + (1 if body_markdown else 0)) > 10`.
       3. `headings`: ATX heading count (`^#{1,6}\s+\S`) `>= 2`.
       4. `structured_block`: contains a GFM table (header pipe row + delimiter row matching `^\s*\|?(\s*:?-{3,}:?\s*\|)+\s*:?-{3,}:?\s*\|?\s*$`), a ` ```mermaid ` fence, an inline/image `.svg` reference, or any fenced code block (` ``` ` / `~~~`) with `> 6` inner lines.
       5. `outbound_links`: Markdown links `[text](url)` + autolinks `<https://...>` + `[KEY-123]` issue refs count `>= 3`.
     - Snooze gate (`S8.2`): when `snoozed_at_length is not None`, `snooze_cleared` is `len(body_markdown) * 2 >= snoozed_at_length * 3` (exact integer check for `>= 1.5x` length, and `len(body_markdown) > 0` when `snoozed_at_length == 0`). `recommended = raw_triggered and (snoozed_at_length is None or snooze_cleared)`.
     - Persists `stickies.promotion_recommended = recommended` on every create/patch/snooze.
3. **Endpoints:**

   | Method + Path | Capability | Success | Errors |
   | :-- | :-- | :-- | :-- |
   | `GET /api/v1/projects/{project_ref}/stickies?include_promoted=true` | `VIEW` on project | `200` ordered by `sort_rank COLLATE "C"` | `404` |
   | `POST /api/v1/projects/{project_ref}/stickies` | `EDIT` on project | `201` + `ETag` | `404`, `403`, `422` |
   | `GET /api/v1/stickies?cursor=&limit=` | workspace `VIEW` (RLS filtered across projects + workspace stickies) | `200` | `422 INVALID_CURSOR` |
   | `GET /api/v1/stickies/{sticky_id}` | `VIEW` | `200` + `ETag`; `304` on `If-None-Match` | `404` |
   | `PATCH /api/v1/stickies/{sticky_id}` | `EDIT` | `200` + new `ETag` | `404`, `403`, `409 STICKY_PROMOTED_READONLY`, `412`, `428`, `422` |
   | `DELETE /api/v1/stickies/{sticky_id}` | `DELETE` | `200` (soft-trash `objects.deleted_at`) | `404`, `403` |
   | `POST /api/v1/stickies/{sticky_id}/snooze-promotion` | `EDIT` | `200` | `404`, `403`, `409 ALREADY_PROMOTED` |
   | `POST /api/v1/stickies/{sticky_id}/promote-to-doc` | `EDIT` on sticky (and target parent doc/page if specified) | `201` | `404`, `403`, `409 ALREADY_PROMOTED`, `422` |
   | `POST /api/v1/stickies/{sticky_id}/unarchive-copy` | `EDIT` | `201` new unpromoted sticky | `404`, `403`, `409 NOT_PROMOTED` |

   - Validation & ETag:
     - `color_token`: enum `amber | mint | sky | lavender | coral | slate` (default `amber`; invalid -> `422`).
     - `body_markdown`: normalized via `normalize_to_markdown()` (`KB-P2-13`), max `65536` bytes (`422 STICKY_TOO_LARGE`). `PATCH` modifying `body_markdown` requires `If-Match` (`428` / `412`); promoted stickies reject `body_markdown` edits with `409 STICKY_PROMOTED_READONLY`.
   - **Atomic `POST /api/v1/stickies/{sticky_id}/promote-to-doc` (`S8.2`):**
     - Request: `{"title": "Auth Studio Notes", "parent_doc_id": null, "parent_page_id": null}` (`title` optional: if omitted, derived from first ATX heading or first non-empty line truncated to `120` chars, fallback `"Untitled Sticky"`).
     - Single PostgreSQL transaction (`SELECT ... FOR UPDATE` on `stickies`):
       1. If `sticky.promoted_to_doc_id IS NOT NULL` -> `409 ALREADY_PROMOTED`.
       2. If `parent_doc_id` is `null`, creates a new `Doc` (in the exact same `workspace_id` and `project_id` as `sticky`) + initial root `Page` holding `sticky.body_markdown`. If `parent_doc_id` is set, verifies `parent_doc.project_id IS NOT DISTINCT FROM sticky.project_id` (else `422 CROSS_SCOPE_PROMOTION_FORBIDDEN` so project inheritance cannot widen!) and creates a `Page` under `parent_doc_id` / `parent_page_id` while linking `promoted_to_doc_id = parent_doc_id`.
       3. **Verbatim ACL Copy:** queries all direct `resource_acl_entries` rows where `object_id = sticky.id` (`ALLOW` and `DENY` bitmasks across all principal types) and inserts identical `(principal_id, effect, capability_mask)` rows onto the created `Doc` (when new) and `Page`, triggering `effective_resource_access` refresh (`KB-P1-13`). Zero ACL rows are dropped or widened.
       4. Inserts `object_links(source_id=sticky.id, source_type='sticky', target_id=doc.id, target_type='doc', link_type='PROMOTED_TO_DOC')`.
       5. Sets `sticky.promoted_to_doc_id = doc.id` and `sticky.promotion_recommended = FALSE`.
     - Sticky serializer after promotion returns `"is_promoted_stub": true`, `"promoted_to_doc": {"id": "...", "canonical_key": "docs/...", "title": "..."}` (or `"restricted": true` if target doc later became unreadable to viewer) so the UI renders the compact `[📄 Open Doc] [Unarchive Copy]` stub (`S8.2`).
   - **`POST .../unarchive-copy`:** clones a promoted sticky's `body_markdown`, `color_token`, and direct `resource_acl_entries` verbatim into a fresh unpromoted sticky (`promoted_to_doc_id = NULL`), writing `DERIVED_FROM_STICKY` or `STICKY_UNARCHIVED_COPY` activity.
4. **Activity events emitted (category `HISTORY`):** `STICKY_CREATED`, `STICKY_UPDATED`, `STICKY_RECOLORED {from, to}`, `STICKY_PROMOTION_SNOOZED {at_length}`, `STICKY_PROMOTED_TO_DOC {doc_id, page_id, copied_acl_count}`, `STICKY_UNARCHIVED_COPY {new_sticky_id}`, `STICKY_TRASHED`.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/services/test_sticky_heuristic.py`, `kanban/tests/api/test_stickies.py`
- **Required Test Cases:**
  1. All 5 heuristic triggers: independently verify `601` chars (`600` -> `False`), `11` lines (`10` -> `False`), `2` headings (`#` inside code fence ignored), GFM table / ` ```mermaid ` / 7-line code fence (6-line fence -> `False`), and `3` outbound links (`2` -> `False`).
  2. Snooze `>= 1.5x` math: sticky of `620` chars (`promotion_recommended == True`) -> `POST .../snooze-promotion` sets `promotion_snoozed_at_length = 620` and `promotion_recommended == False`; growth to `929` chars keeps `False`; growth to `930` chars (`620 * 1.5 == 930`) flips `promotion_recommended == True`.
  3. Atomic promotion & verbatim ACL proof: attach 1 direct `ALLOW (VIEW|EDIT)` for `@maya` and 1 explicit `DENY (VIEW)` for `Contractors` group on the sticky; call `promote-to-doc`; assert `docs`, `pages`, and `object_links(PROMOTED_TO_DOC)` exist, `(principal_id, effect, capability_mask)` on new `Doc` and `Page` match the sticky's ACL rows 1:1, `Contractors` member gets `404` on the new Doc, and second `promote-to-doc` returns `409 ALREADY_PROMOTED`.
  4. Rollback atomicity & cross-scope guard: promoting into a `parent_doc_id` in another project returns `422 CROSS_SCOPE_PROMOTION_FORBIDDEN` with `0` rows created; `PATCH` body on promoted stub returns `409 STICKY_PROMOTED_READONLY`; `unarchive-copy` creates an editable clone preserving the `DENY` ACL.
  5. Boundaries & sanitization: `color_token="red"` -> `422`; `65536` bytes accepted, `65537` -> `422 STICKY_TOO_LARGE`; hidden DOM `<div style="font-size:0">evil</div>` pruned on write; stale `If-Match` -> `412`.
