### User Story
As a **security engineer hardening uploaded `.svg` attachments and diagrams**, I need **a strict server-side XML/SVG allowlist sanitizer that blocks XXE/DTDs at parse time, retains only pure vector geometry elements and safe presentation attributes, strips `<script>`, `<foreignObject>`, `<style>`, `<image>`, SMIL `<animate*>`, `on*` handlers, and external `href`/`url()` references, and validates `<use href="#id">` as an acyclic local DAG (`depth <= 4`, total expanded nodes `<= 500`)** so that **stored XSS, external SSRF/beacon leaks, CSS exfiltration, and `<use>` billion-laughs CPU/GPU bombs are neutralized before storage**.

**Requirement Traceability:** `S5.4` row "Uploaded `.svg` Attachments & Fenced ```` ```svg ```` Blocks" (geometry allowlist, strip `<script>`, `<foreignObject>`, `<iframe>`, `<image>`, `<style>`, SMIL `<animate*>`, `on*`, external `href`s; `<use href="#id">` acyclic local DAG `depth <= 4`, expansion `<= 500` nodes), `S3.5` row "Hostile Media", `S2.5` (permissive license matrix; note: `roxmltree` in S2.5/S5.4 is a Rust crate without an official PyPI package, so Python implements the identical non-entity XML tree boundary via `defusedxml` `PSF-2.0`), requirement `#10` | **Dependencies:** `KB-P2-13` (`kanban/content/` package + `unicode_guard`)

### Scoped Technical Actions
1. **Target Files:**
   - `kanban/content/svg_sanitizer.py` (`SvgSanitizeError`, `SvgSanitizeReport`, `sanitize_svg`, `sanitize_svg_with_report`)
   - `kanban/content/svg_dag.py` (`validate_svg_use_dag`)
   - `kanban/pyproject.toml` (add pinned `defusedxml`, `PSF-2.0`)
2. **Pre-Parse Framing & Entity/DTD Firewall (`svg_sanitizer.py`):**
   - Size cap: `1 <= len(raw_bytes) <= max_bytes` (default `2,097,152` bytes = `2 MiB`; empty or oversize -> `SvgSanitizeError("SVG_SIZE_INVALID")`).
   - Encoding guard: reject UTF-16 / UTF-32 / UTF-7 BOMs; decode strictly as UTF-8 (`UnicodeDecodeError` -> `SvgSanitizeError("SVG_INVALID_UTF8")`), strip `U+FEFF` leading BOM and zero-width/Plane-14 tag chars (`KB-P2-13` `unicode_guard`).
   - Pre-parse byte/token reject: case-insensitive scan rejecting `<!DOCTYPE`, `<!ENTITY`, `<![CDATA[` inside `<!`, and `<?xml-stylesheet` BEFORE XML parsing (`SvgSanitizeError("SVG_DTD_OR_ENTITY_FORBIDDEN")`), followed by `defusedxml.ElementTree.fromstring(text, forbid_dtd=True, forbid_entities=True, forbid_external=True)` (malformed XML -> `SvgSanitizeError("SVG_MALFORMED_XML")`).
   - Structural input bounds: root local-name must be `svg` in namespace `http://www.w3.org/2000/svg` (or unnamespaced `<svg>` normalized to `xmlns="http://www.w3.org/2000/svg"`); max XML nesting depth `<= 64`, max raw elements `<= 5,000` (`SvgSanitizeError("SVG_COMPLEXITY_EXCEEDED")`).
3. **Element & Attribute Allowlist (`S5.4` line 398):**
   - `ALLOWED_SVG_ELEMENTS`: `frozenset({"svg", "g", "path", "rect", "circle", "ellipse", "line", "polyline", "polygon", "text", "tspan", "defs", "symbol", "use", "linearGradient", "radialGradient", "stop", "clipPath", "marker", "title", "desc"})`.
   - Any element outside `ALLOWED_SVG_ELEMENTS` (explicitly including `script`, `foreignObject`, `iframe`, `frame`, `object`, `embed`, `image`, `feImage`, `filter`, `style`, `a`, `link`, `meta`, `audio`, `video`, `canvas`, `animate`, `animateMotion`, `animateTransform`, `animateColor`, `set`, `mpath`, `discard`, `handler`, `switch`) has its **entire subtree removed** and increments `stripped_elements`.
   - `ALLOWED_SVG_ATTRS`: geometry/presentation allowlist (`id`, `viewBox`, `preserveAspectRatio`, `width`, `height`, `x`, `y`, `x1`, `y1`, `x2`, `y2`, `cx`, `cy`, `r`, `rx`, `ry`, `d`, `points`, `transform`, `gradientUnits`, `gradientTransform`, `spreadMethod`, `offset`, `stop-color`, `stop-opacity`, `clipPathUnits`, `markerUnits`, `markerWidth`, `markerHeight`, `refX`, `refY`, `orient`, `fill`, `fill-opacity`, `fill-rule`, `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`, `stroke-miterlimit`, `stroke-dasharray`, `stroke-dashoffset`, `stroke-opacity`, `opacity`, `color`, `font-family`, `font-size`, `font-weight`, `font-style`, `text-anchor`, `dominant-baseline`, `dx`, `dy`, `clip-path`, `marker-start`, `marker-mid`, `marker-end`, `href`).
   - Attribute sanitization rules:
     - Strip every `on*` event handler, `style` attribute, `xml:base`, `xmlns:xlink` (after normalizing `xlink:href` -> `href`), and any attribute in a foreign namespace.
     - `id`: allowed only when matching `^[A-Za-z_][A-Za-z0-9_.-]{0,127}$` and unique within the document (duplicate IDs rejected with `SvgSanitizeError("SVG_DUPLICATE_ID")` to prevent `<use>` shadow ambiguity).
     - `href` (including normalized `xlink:href`): permitted ONLY on `{"use", "linearGradient", "radialGradient"}` and ONLY when matching `^#[A-Za-z_][A-Za-z0-9_.-]{0,127}$` whose target `id` exists in the sanitized document; any external/data/javascript/relative-path `href` is stripped (`stripped_attrs += 1`).
     - Paint/reference attributes (`fill`, `stroke`, `clip-path`, `marker-start`, `marker-mid`, `marker-end`): reject/strip any `url(...)` value unless it is strictly `url(#<existing_local_id>)` with zero quotes/whitespace tricks or external URI; reject `expression(`, `javascript:`, `@import`, `image-set(`.
     - `width` / `height` / `viewBox`: numeric / `%` / `px` validation capping root viewport coordinates so absurd canvas sizes (`> 32768`) are rejected (`SVG_DIMENSIONS_INVALID`).
4. **`<use>` & Gradient Local Acyclic DAG Validator (`svg_dag.py`):**
   - Constructs reference graph over sanitized tree where an element `E` referencing `#target_id` (via `href` on `<use>`, `<linearGradient>`, `<radialGradient>`, or `url(#target_id)` on `<clipPath>`/`<marker>`) adds a reference edge `E -> T`, AND every parent-child containment adds structural traversal.
   - **Self/Ancestor Cycle Guard:** if target `T` is an ancestor of `<use>` (or reachable back to `T` through a mix of containment and `href` edges, e.g. `<g id="a"><use href="#a"/></g>` or `a -> b -> a`), raise `SvgSanitizeError("SVG_USE_CYCLE")`.
   - **Depth Guard (`S5.4`):** compute maximum `<use>` reference chain depth; if `depth > 4`, raise `SvgSanitizeError("SVG_USE_DEPTH_EXCEEDED")`.
   - **Total Expansion Guard (`S5.4`):** compute exact rendered node expansion via memoized bottom-up DAG count (`cost(node) = 1 + sum(cost(child))`, and for `<use href="#T">`, `cost(use_node) = 1 + cost(T)`); if `cost(root_svg) > 500`, raise `SvgSanitizeError("SVG_EXPANSION_LIMIT_EXCEEDED")`.
5. **Canonical Output:** serializes clean `ElementTree` as UTF-8 `<svg xmlns="http://www.w3.org/2000/svg" ...>...</svg>` with `xml_declaration=False` and deterministic attribute order.
6. **Security invariants asserted:** (a) zero external network requests, scripts, styles, foreignObjects, or animations can exist in output SVG; (b) XML entities/DTDs fail closed before parser expansion; (c) `<use>` cycles, chains `> 4`, and expansions `> 500` nodes fail closed with typed error codes.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/content/test_svg_sanitizer.py`, `kanban/tests/content/test_svg_use_dag.py`
- **Hostile Corpus:** `kanban/tests/content/corpus/hostile_svgs.json`
- **Required Test Cases:**
  1. Positive clean diagram: architecture/Mermaid-style SVG using `<svg>`, `<g>`, `<defs>`, `<linearGradient>`, `<clipPath>`, `<marker>`, `<rect>`, `<path>`, `<circle>`, `<text>`, `<tspan>`, and valid local `<use href="#node-box"/>` (`depth=1`, expansion `< 50`) sanitizes cleanly and re-parses as valid XML.
  2. Security (active content strip): SVGs containing `<script>alert(1)</script>`, `<foreignObject><body onload=alert(1)></body></foreignObject>`, `<iframe>`, `<style>@import url(https://evil.example/x.css);</style>`, `<animate attributeName="href" to="javascript:alert(1)"/>`, `<set>`, `<a href="javascript:alert(1)"><rect/></a>`, and `<rect onclick="alert(1)" onload="x"/>` have every hostile element/attribute stripped while preserving sibling `<rect>` geometry.
  3. Security (external SSRF / tracking pixel): `<image href="https://169.254.169.254/latest/meta-data"/>`, `<use xlink:href="https://evil.example/sprite.svg#x"/>`, `<use href="data:image/svg+xml;base64,..."/>`, and `<rect fill="url(https://evil.example/p#g)"/>` strip `<image>` and external `href`/`fill` completely (`0` occurrences of `http`, `169.254`, or `data:` in output).
  4. Security (XXE & XML billion laughs): SVG with `<!DOCTYPE svg [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>` or quadratic `<!ENTITY lol9 ...>` fails closed with `SVG_DTD_OR_ENTITY_FORBIDDEN`.
  5. Security (`<use>` cycle): direct self-reference `<g id="a"><use href="#a"/></g>` and mutual cycle `<g id="a"><use href="#b"/></g><g id="b"><use href="#a"/></g>` raise `SvgSanitizeError("SVG_USE_CYCLE")`.
  6. Boundary (`<use>` depth cap `<= 4`): chain `u1 -> u2 -> u3 -> u4 -> rect` (`depth=4`) succeeds; adding `u0 -> u1` (`depth=5`) raises `SvgSanitizeError("SVG_USE_DEPTH_EXCEEDED")`.
  7. Boundary (`<use>` expansion cap `<= 500`): DAG of `depth=4` where each layer instantiates `5` copies of the next (`1 + 5 + 25 + 125 + 625 > 500` expanded nodes from `< 30` raw XML lines - SVG `<use>` billion-laughs!) raises `SvgSanitizeError("SVG_EXPANSION_LIMIT_EXCEEDED")`; an SVG expanding to exactly `500` nodes succeeds; `501` raises.
  8. Boundary (size, encoding & duplicate IDs): `2,097,152`-byte valid SVG or `2,097,153`-byte SVG -> oversize raises `SVG_SIZE_INVALID`; UTF-16 BOM -> `SVG_INVALID_UTF8`; two `<g id="dup">` elements -> `SVG_DUPLICATE_ID`; non-SVG `<html/>` root -> rejected.
