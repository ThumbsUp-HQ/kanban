### User Story
As a **project lead planning milestones in `/projects/:projectKey/issues?layout=calendar` or `?layout=timeline`**, I need **a month due-date Calendar grid and a Timeline (Gantt) split view rendering `start_date -> due_date` bars, SVG `BLOCKS` dependency arrows, and drag/resize date rescheduling** so that **schedule bottlenecks and dependency chains are immediately visible and adjustable with optimistic updates and strict `due_date >= start_date` validation**.

**Requirement Traceability:** `S6.4 item 2` (`Calendar` and `Timeline / Gantt` with `start_date -> due_date` bars + `BLOCKS` arrows), `S7.2 8e` (`DATE` `due_date >= start_date` invariant, overdue styling suppressed for `completed`/`cancelled`), `S7.2 8m` (`BLOCKS` typed `object_links`, restricted target masking), `S6.1` (`--list-row-h: 46px`, `--card-gap`, `--font-mono`), `S6.2` (`<EmojiHint>` priority & `🕸️⚠️` broken-link hints), `S5.4` (CSP `style-src 'self'`), requirements `#8e`, `#8m`, `#9j`, `#15` | **Dependencies:** `KB-P3-38` (`viewRegistry.tsx` + shared view styles), `KB-P3-07` (`object_links` `BLOCKS` graph + restricted masking), `KB-P3-02` (`PATCH /api/v1/issues/{issue_ref}` with `start_date` / `due_date`)

   - `kanban/web/src/features/timeline/timelineGeometry.ts` (pure bar X/width calculator, `BLOCKS` path router, pointer delta -> `YYYY-MM-DD` snapper enforcing `due_date >= start_date`)
   - `kanban/web/src/features/timeline/scheduleMutation.ts` (`useRescheduleIssue()` optimistic `PATCH /api/v1/issues/{issue_ref}` helper)
   - `kanban/web/src/features/timeline/calendarTimeline.css`

2. **Timezone-safe date math (`calendarGrid.ts`, `timelineGeometry.ts`):**
   - `start_date` and `due_date` are ISO calendar `DATE` strings (`YYYY-MM-DD`, `S12.2` lines 833-834). All arithmetic operates on integer UTC epoch days (`Date.UTC(y, m - 1, d) / 86_400_000`) so `2026-11-18` renders on November 18 in every browser timezone (`UTC-12` through `UTC+14`).
3. **Month `CalendarView` (`?layout=calendar`):**
   - Toolbar (`margin-bottom: var(--space-4)` `16px`): `Previous month`, `.mono` `<Month YYYY>` heading, `Next month`, `Today` button, and `Unscheduled (<N>)` toggle button listing issues with `due_date === null`.
   - 7-column CSS grid (`min-height: 124px` per day cell desktop/tablet; on mobile `<= 767px`, switches cleanly to a 7-day compact week strip selector above an agenda list of `46px` `--list-row-h` rows for the selected date so touch targets stay `>= 44px` without 55px cramped columns).
   - Each day cell lists up to `3` due-date issue pills (`padding: var(--space-1) var(--space-2)`, `.mono` key + priority `<EmojiHint>` + truncated summary, `?peek=<KEY>` on click) plus a `+N more` popover button (`role="dialog"`, non-modal) when `> 3` issues share a date. Overdue highlight applies ONLY when `due_date < today && state.group !== 'completed' && state.group !== 'cancelled'`.
   - Dragging an issue pill (or an `Unscheduled` item) onto a day cell (plus keyboard `Alt+ArrowLeft/Right/Up/Down` by `+/-1` or `+/-7` days) calls `useRescheduleIssue`: updates `due_date` optimistically; if existing `start_date > new_due_date`, shifts `start_date` by the same delta when moving a scheduled range or clamps `start_date = new_due_date` so `due_date >= start_date` (`S7.2 8e`) is never violated.
4. **`TimelineView` / Gantt (`?layout=timeline`):**
   - Toolbar: zoom radiogroup `Day` (`36px/day`), `Week` (`16px/day`, default), `Quarter` (`6px/day`), `Today` scroll-into-view button, and toggle `Show BLOCKS arrows` (default `on`).
   - Split grid: left sticky pane (`280px` desktop/tablet; collapsible to `132px` key-only rail on mobile `<= 767px`) with `46px` (`--list-row-h`) rows aligned 1:1 in vertical scroll with the right timeline canvas. Issues lacking both `start_date` and `due_date` show a `Click track to schedule` ghost prompt on their row. Single-date issues (`due_date` only or `start_date` only) render a `20px` milestone diamond at that date.
   - Scheduled bars (`start_date`..`due_date` inclusive): rendered inside an `<svg>` or CSSOM-positioned track (`height: 28px` centered inside the `46px` row, `border-radius: var(--radius-md)`), showing `.mono` `<KEY>` + label, `⏳🤖`/`🛑🤖` `<EmojiHint>` badge adjacent when gated, and 3 pointer interactions:
     - **Body drag**: shifts both `start_date` and `due_date` by `deltaDays` (`PATCH { start_date, due_date }`).
     - **Left handle resize**: adjusts `start_date` clamped to `<= due_date`.
     - **Right handle resize**: adjusts `due_date` clamped to `>= start_date`.
     - Keyboard parity on focused bar: `ArrowLeft`/`ArrowRight` shifts range `+/-1` day, `Shift+ArrowLeft`/`Shift+ArrowRight` extends/shrinks `due_date` (`due_date >= start_date` enforced), committing on `Enter` (or reverting on `Escape`).
   - **`BLOCKS` dependency arrows (`TimelineSvgOverlay.tsx`):**
     - Reads `BLOCKS` edges between visible issues (from issue list `outbound_blocks` summary if provided by `KB-P3-11`, falling back to `GET /api/v1/objects/{key}/links` cached under `qk` for visible scheduled rows, capped at `200` arrows).
     - Draws `<path d="M x1 y1 L ...">` from source bar right edge `(dueX, rowCenterY)` to target bar left edge `(startX, targetRowCenterY)` using SVG presentation attributes (`d`, `class`, `marker-end`), ZERO inline `style="..."` attributes (`CSP style-src 'self'`).
     - Dependency conflict highlight: when blocker `A.due_date > blocked B.start_date`, path uses `.gantt-arrow--conflict` (`--warn-fg` dashed stroke). If a link has `link_state === 'FLAGGED_INVALID'`, renders a `🕸️⚠️` `<EmojiHint kind="brokenLink">` pill on the source row; restricted endpoints (`restricted: true`) never draw an arrow or expose any target key.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/web/src/features/calendar/calendarGrid.test.ts`, `kanban/web/src/features/calendar/CalendarView.test.tsx`, `kanban/web/src/features/timeline/timelineGeometry.test.ts`, `kanban/web/src/features/timeline/TimelineView.test.tsx`, `kanban/web/src/features/timeline/scheduleMutation.test.tsx`
- **Required Test Cases:**
  1. Positive (`calendarGrid` & `CalendarView`): November 2026 produces exact 42-day grid independent of timezone; `KAN-142` (`due_date: "2026-11-18"`) appears in cell `2026-11-18`; `+N more` opens when 5 issues share one date; dropping an unscheduled issue onto `2026-11-20` calls `PATCH /api/v1/issues/{key}` with `{ due_date: "2026-11-20" }`.
  2. Positive (`timelineGeometry` & `TimelineView`): `start_date: "2026-11-11"` to `due_date: "2026-11-18"` at `16px/day` (`Week` scale) computes width `8 * 16 = 128px` (8 inclusive days); `KAN-100 BLOCKS KAN-142` renders an `<svg>` `<path>` connecting row `KAN-100` to row `KAN-142`; conflict class `.gantt-arrow--conflict` applies when blocker ends after blocked starts.
  3. Boundary (`due_date >= start_date` invariant): dragging left resize handle past `due_date` clamps `start_date === due_date` and never sends `due_date < start_date`; dragging right handle left of `start_date` clamps `due_date === start_date`; leap-day `2028-02-28` + `1` day yields `2028-02-29`.
  4. Negative / security: restricted link target (`{ restricted: true, label: "🔒 Restricted Object" }`) renders zero arrow paths and leaks no id/key; `FLAGGED_INVALID` link renders `🕸️⚠️` `<EmojiHint kind="brokenLink">`; server `412` or `422` on `PATCH` rolls bar/pill back to its exact prior dates and announces rollback; zero elements in rendered DOM carry a `style="..."` HTML attribute string before CSSOM mount.
  5. Keyboard & responsive: focused Gantt bar `ArrowRight` + `Enter` shifts both dates `+1` day; mobile `CalendarView` renders week strip + `46px` agenda rows.
