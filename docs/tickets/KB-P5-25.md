### User Story
As a **developer or reviewer dragging work items across gated workflow columns**, I need **non-blocking provisional `⏳🤖` card/drawer states with a live elapsed timer, smooth `240ms` snap-back with a `🛑🤖` veto badge and 1-click jump to the audit comment on rejection/timeout, and `✅🤖` verdict-hash badges on approval driven by realtime events** so that **slow AI/CLI transition gates (`agy -p`, `codex -p`, `gemini`, `ollama`) never freeze the board UI and every gate outcome is immediately legible via `<EmojiHint>` hover elaboration**.

**Requirement Traceability:** `S1.3` item 2 (non-blocking provisional `⏳🤖` state, `240ms` smooth snap-back with `🛑🤖` veto badge and comment on reject), `S6.2` (`⏳🤖`, `🛑🤖`, `✅🤖` rows in the 21-emoji `<EmojiHint>` table, `120ms` copyable hover bridge), `S6.3` (board wireframe `⏳🤖 In Review 1`, `KANBA-8 ⏳🤖`, `🤖 agy -p`), `S7.1` (drawer `Activity [All] [Comments] [History] [🤖 Gates (N)]`, `✅🤖 Gate sec-review (cli: agy -p) approved transition`), `S14.1` (`202 Accepted` sequence) | Original requirements `#9`, `#15`, `#8j` | **Dependencies:** `KB-P5-18`, `KB-P3-37`, `KB-P3-44`

### Scoped Technical Actions
1. **Target Files:**
   - `kanban/web/src/features/gates/GateStatusPill.tsx` (`⏳🤖`, `🛑🤖`, `✅🤖` `<EmojiHint>` pills + live `1s` elapsed timer hook `useElapsedGateTimer`)
   - `kanban/web/src/features/gates/useGateRealtimeSync.ts` (subscribes to `KB-P5-18` WebSocket/SSE events `workflow.gate.pending|approved|rejected|timed_out|cancelled` and patches TanStack Query caches for board/list issues, open drawer issue, and activity feed)
   - `kanban/web/src/features/gates/useCardSnapBackAnimation.ts` (`240ms` FLIP transform animation from provisional target lane back to `from_state` lane; `0ms` instant snap under `prefers-reduced-motion: reduce`)
   - `kanban/web/src/features/gates/GateActivityRow.tsx` (renders `GATE_APPROVED`, `GATE_REJECTED`, `GATE_ABORTED_STALE`, `GATE_FAIL_OPEN_WARN` rows in the Drawer `🤖 Gates` tab with 1-click jump to `#comment-<id>`)
   - `kanban/web/src/features/gates/gates.css` (spatial & motion tokens from `tokens.css` only)
   - Modify board card/column header components (`KB-P3-37`) and drawer state header + Activity `🤖 Gates` tab (`KB-P3-44`) to mount `GateStatusPill`, `useGateRealtimeSync`, and `GateActivityRow`.
2. **Provisional `202` Transition & `⏳🤖` Pending UX:**
   - When `POST /api/v1/issues/{issue_key}/transitions` (from board drag-drop or drawer State select) returns `202 {status: "pending_agent_gate", execution_id, active_agent, hook_name, harness_kind}` (or when `issue.pending_gate != null` on initial load / `workflow.gate.pending` arrives):
     - Card renders in the provisional target column with a calm dashed border token (`--border-accent-subtle`), remains clickable to open the Drawer (zero full-page spinner, zero UI freeze), and blocks only a second concurrent state drag on that single card (`aria-disabled="true"` on state drag handle with tooltip `Transition gate in progress`).
     - Column header displays `⏳🤖` count indicator alongside column count when `>= 1` card in that column is held in `pending_gate` (`S6.3`).
     - `<EmojiHint emoji="⏳🤖">` popover content (`S6.2`):
       - Line 1: `Gate: <hook_name> (<harness_label>)` (e.g., `cli: agy -p`, `codex -p`, `gemini`, `ollama`).
       - Line 2: Live elapsed timer `Elapsed: 00:14` ticking every `1,000ms` via `started_at` + monotonic offset (pauses timer intervals when document is hidden; cleans up interval on unmount) + `:ro repo mounted` indicator when applicable.
       - Action button (shown to invoking user or `PROJECT_ADMIN`): `Cancel gate` -> `DELETE /api/v1/transitions/{execution_id}` (`KB-P5-18`).
3. **Reject / Timeout `240ms` Snap-Back & `🛑🤖` Veto Badge:**
   - On `workflow.gate.rejected` or `workflow.gate.timed_out`:
     - Records card bounding rect in target column, updates cached issue state back to `from_state`, and runs FLIP `transform: translate3d(dx, dy, 0)` -> `translate3d(0, 0, 0)` over **`240ms` `cubic-bezier(0.2, 0, 0, 1)`** (strictly `transform`/`opacity` GPU properties so main-thread frame stays `< 12ms`; skipped to `0ms` when `window.matchMedia('(prefers-reduced-motion: reduce)').matches`).
     - Attaches `<EmojiHint emoji="🛑🤖">` veto pill on the snapped-back card and Drawer header (`latest_gate_verdict.decision === "reject"`):
       - Line 1: `Vetoed by <hook_name> (<agent_slug>)` + relative/ISO timestamp.
       - Line 2-3: 2-line `reason_preview` (`<= 280` chars from `KB-P5-18`, rendered as plain text nodes - zero raw HTML).
       - Action link: `View full gate review comment ->` opening the Drawer scrolled and focused on `#comment-<veto_comment_id>` (or the `🤖 Gates` tab) and announcing the veto via `aria-live="polite"`.
4. **Approve Commit & `✅🤖` Verdict Badge:**
   - On `workflow.gate.approved`: clears provisional dashed border, increments target column count, and displays `<EmojiHint emoji="✅🤖">` on the Drawer state row and `🤖 Gates` Activity tab (`S7.1`: `✅🤖 Gate <hook_name> (<harness_label>) approved transition`):
     - Popover content (`S6.2`): approving hook/agent name, execution `latency_ms` (`e.g. 1,420 ms`), and full `verdict_sha256` hex in `--font-mono` selectable/copyable across the `120ms` `<EmojiHint>` interactive hover bridge.
   - On `workflow.gate.cancelled` (user cancel or `STALE_SNAPSHOT` TOCTOU abort): snaps card back (`240ms`) and displays calm inline toast `Transition cancelled (ticket changed while gate was running)` when `reason === "STALE_SNAPSHOT"`.

  3. Positive (`✅🤖` approve + copyable hash): emitting `workflow.gate.approved` commits `KAN-8` in `Done`, renders `✅🤖` in Drawer + `🤖 Gates (2)` tab count, and keeps popover open across the `120ms` hover bridge so `verdict_sha256` hex is selectable.

Accessibility & reduced motion: with `prefers-reduced-motion: reduce`, snap-back runs in `0ms` (no transform animation); keyboard `Tab` onto `⏳🤖` / `🛑🤖` / `✅🤖` opens popover in `0ms` and `Escape` dismisses (`S6.2`); `aria-live="polite"` announces `Gate forensic-code-check vetoed transition KAN-8`.

  6. Boundary: `STALE_SNAPSHOT` cancellation snaps card back and shows stale-snapshot message; duplicate identical `workflow.gate.approved` WebSocket frame is idempotent (no duplicate activity entry or flicker).
