### User Story
As an **architect or engineer reading and authoring system diagrams in tickets, comments, stickies, and docs**, I need **fenced ```` ```mermaid ```` blocks to render inside an isolated `worker-src 'self'` Web Worker via `beautiful-mermaid` with strict directive/HTML stripping, `64 KB` / `400`-node / `1,000`-edge caps, a `1,500 ms` `worker.terminate()` watchdog fallback, live Light/Dark CSS variable sync, and `<img src="blob:...">` output inside `<MediaViewport>`** so that **diagrams render cleanly under `style-src 'self'` with zero `<foreignObject>` XSS surface and zero main-thread hangs**.

**Requirement Traceability:** `S5.3` (directive & resource firewall `<= 64 KB`, `<= 400` nodes, `<= 1,000` edges, isolated Web Worker + `1,500 ms` `worker.terminate()` fallback, live theme sync `--bg-surface`/`--fg-primary`/`--border-strong`/`--accent-primary`, `createSafeSvgBlobUrl()` -> `<img src="blob:..." loading="lazy" decoding="async">` inside `<MediaViewport>`), `S5.4` (`worker-src 'self'`, `img-src 'self' blob:`), `S3.5` (Hostile Media row), requirements `#5`, `#10` | **Dependencies:** `KB-P3-45`, `KB-P3-48`

### Scoped Technical Actions
1. **Target Files:**
   - `kanban/web/src/editor/mermaid/mermaidFirewall.ts` (directive/callback/HTML scrubber + `64 KB` / `400` nodes / `1,000` edges validator)
   - `kanban/web/src/editor/mermaid/mermaidTheme.ts` (reads resolved semantic CSS tokens `--bg-surface`, `--fg-primary`, `--border-strong`, `--accent-primary`)
   - `kanban/web/src/editor/mermaid/mermaid.worker.ts` (dedicated module Web Worker running `mermaidFirewall` + `beautiful-mermaid`)
   - `kanban/web/src/editor/mermaid/mermaidClient.ts` (worker pool/dispatcher + `1,500 ms` watchdog `worker.terminate()` + lazy respawn)
   - `kanban/web/src/editor/mermaid/MermaidBlockView.tsx` + `MermaidBlockView.css` (ProseMirror `code_block` nodeView for `lang === 'mermaid'` mounting `<MediaViewport>` or source fallback)
   - Edits: `kanban/web/src/editor/MarkdownEditor.tsx` (register `MermaidBlockView` via `editorSurfaceFactory`), `kanban/web/src/dev/EditorStory.tsx` (sample diagrams, theme-flip trigger, and timeout simulation toggle for E2E)
2. **Directive & Resource Firewall (`mermaidFirewall.ts`):**
   - Constants exported verbatim: `MAX_MERMAID_BYTES = 65536`, `MAX_MERMAID_NODES = 400`, `MAX_MERMAID_EDGES = 1000`, `MERMAID_WATCHDOG_MS = 1500`.
   - `sanitizeAndValidateMermaid(rawSource: string): MermaidFirewallResult`:
     1. Rejects UTF-8 byte length `> 65536` (`{ ok: false, code: 'SOURCE_TOO_LARGE' }`).
     2. Strips all `%%{...}%%` directives (including `%%{init: ...}%%` theme/securityLevel overrides) and records `strippedDirectives`.
     3. Strips interactive `click <id> ...`, `href "..."`, and `call ...()` callback statements line-by-line (defeating `click A href "javascript:..."`).
     4. Strips CSS `@import` rules and raw HTML tags (`<script>`, `<iframe>`, `<object>`, `<foreignObject>`, `<img ...>`, `<a ...>`, `<div>`, `<span>`, `style=...`) inside node/edge labels while preserving quoted punctuation like `["Label (Extra Info)"]`.
     5. Verifies the first non-comment diagram header token is in the supported allowlist: `flowchart`, `graph`, `sequenceDiagram`, `stateDiagram-v2`, `stateDiagram`, `classDiagram`, `erDiagram`, `xychart-beta`; unsupported headers return `{ ok: false, code: 'UNSUPPORTED_DIAGRAM_TYPE' }`.
     6. Counts declared/referenced node identifiers and edge/message operators (`-->`, `---`, `-.->`, `==>`, `->>`, `-->>`, `--|>`, `||--o{`, etc.); returns `{ ok: false, code: 'NODE_LIMIT_EXCEEDED' }` if `nodeCount > 400` and `{ ok: false, code: 'EDGE_LIMIT_EXCEEDED' }` if `edgeCount > 1000`.
   - Executed both on the main thread (fast fail before serialization over `postMessage`) AND inside `mermaid.worker.ts` (defense-in-depth if worker is called directly).
3. **Isolated Web Worker & `1,500 ms` Watchdog (`mermaid.worker.ts`, `mermaidClient.ts`):**
   - Spawned strictly as `new Worker(new URL('./mermaid.worker.ts', import.meta.url), { type: 'module' })` so Vite emits a same-origin `.js` chunk compliant with `worker-src 'self'; script-src 'self'`.
   - Worker calls `beautiful-mermaid` pure TypeScript SVG renderer (zero DOM, zero `<foreignObject>` HTML) using the passed theme palette `{ bgSurface, fgPrimary, borderStrong, accentPrimary }` and returns `{ requestId, ok: true, svg: string }` or `{ requestId, ok: false, code, message }`.
   - `MermaidWorkerClient` (`mermaidClient.ts`, injectable worker factory + timer for deterministic unit tests):
     - Enforces `MERMAID_WATCHDOG_MS = 1500` per render job. If the timer fires before a response arrives, it immediately invokes `worker.terminate()`, clears the broken worker instance (next job spawns a clean worker), and resolves `{ ok: false, code: 'RENDER_TIMEOUT' }`.
     - Deduplicates concurrent identical `(sanitizedSource, themeKey)` requests and caches the last `64` rendered SVG strings in an LRU cache.
4. **Live Theme Sync, Safe `blob:` `<img>` & Fallback UX (`mermaidTheme.ts`, `MermaidBlockView.tsx`):**
   - `readMermaidThemeTokens()` reads `--bg-surface`, `--fg-primary`, `--border-strong`, and `--accent-primary` from `getComputedStyle(document.documentElement)`; `MermaidBlockView` re-renders automatically when `useTheme().resolvedTheme` (`light` <-> `dark`) changes.
   - Passes worker SVG string through `createSafeSvgBlobUrl(svg)` (`KB-P3-48`), revoking the prior `blob:` URL on update and unmount via `revoke()`, and renders `<MediaViewport kind="mermaid" blobUrl={blobUrl} rawSource={rawSource} downloadFilename="diagram.svg" alt="Mermaid diagram">` which mounts `<img src="blob:..." loading="lazy" decoding="async">` (zero inline `<svg>` in document DOM).
   - Provides a compact `Edit Mermaid` / `Preview` toggle pill on editable surfaces (`sourceSlice` preserved until edited). When firewall validation, syntax parsing, or the `1500ms` watchdog fails, renders a calm non-crashing fallback header (`Diagram rendered as source: <human reason>`) above the syntax-highlighted monospace ```` ```mermaid ```` source block.

### Mandatory Feature Unit Tests
- **Test File(s):**
  - `kanban/web/src/editor/mermaid/mermaidFirewall.test.ts`
  - `kanban/web/src/editor/mermaid/mermaidClient.test.ts`
  - `kanban/web/src/editor/mermaid/MermaidBlockView.test.tsx`
- **Required Test Cases:**
  1. **Positive (Supported Diagrams & Theme Sync):** Valid `flowchart TD`, `sequenceDiagram`, `stateDiagram-v2`, `classDiagram`, `erDiagram`, and `xychart-beta` inputs pass `sanitizeAndValidateMermaid`, render SVG via `beautiful-mermaid` with resolved light tokens, pass `createSafeSvgBlobUrl`, mount `<img src="blob:..." loading="lazy" decoding="async">` inside `<MediaViewport>` (assert `container.querySelector('svg') === null`), and re-render with dark tokens + revoke prior `blob:` URL when theme switches to `dark`.
  2. **Security (Directive, Click & HTML Stripping):** Input containing `%%{init: {'securityLevel': 'loose'}}%%`, `click A href "javascript:alert(1)"`, `@import url("https://evil.test/x.css")`, and `A["<script>alert(1)</script><foreignObject><b>x</b></foreignObject>Auth"]` strips all directives, `click`/`href` callbacks, `@import`, and HTML tags before reaching `beautiful-mermaid`.
  3. **Boundary Caps (`64 KB`, `400` Nodes, `1,000` Edges):**
     - `65,536`-byte diagram passes; `65,537`-byte diagram fails with `SOURCE_TOO_LARGE`.
     - `400`-node graph passes; `401`-node graph fails with `NODE_LIMIT_EXCEEDED`.
     - `1,000`-edge graph passes; `1,001`-edge graph fails with `EDGE_LIMIT_EXCEEDED`.
  4. **Watchdog Timeout (`1,500 ms` `worker.terminate()`):** With a fake worker that hangs without posting a message, advancing fake timers to `1499ms` keeps state pending; at `1500ms` `worker.terminate()` is called exactly once, `MermaidBlockView` renders the monospace source fallback (`Diagram rendered as source: exceeded 1,500ms render budget`), and a subsequent valid diagram spawns a fresh worker and succeeds.
  5. **Syntax Error & Unsupported Type Fallback:** Invalid Mermaid syntax or unsupported `gantt` / `mindmap` header resolves cleanly to monospace source fallback without throwing unhandled rejections or console errors.
  6. **Memory Hygiene:** Unmounting `MermaidBlockView` calls `URL.revokeObjectURL` for the active `blob:` URL and cancels any pending worker callback.
- Coverage on touched files under `kanban/web/src/editor/mermaid/` `>= 95%` lines/functions/branches/statements.
