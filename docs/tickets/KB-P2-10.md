### User Story
As a **Server Administrator configuring workspace sign-in**, I need **AAL2-protected `/api/v1/admin/auth-cards` endpoints to create, update, enable/disable, fractionally reorder (`COLLATE "C"`), live-probe, and delete authentication cards without ever exposing stored secrets, alongside a public `/api/v1/auth/cards` endpoint returning only enabled login button metadata** so that **both the Admin Auth Studio UI and `/mcp/admin manage_auth_cards` can manage multi-card authentication safely**.

**Requirement Traceability:** `S4.1` (`auth_provider_cards` schema, envelope-encrypted secrets never returned, `sort_rank COLLATE "C"`, `last_health_status`), `S4.3` (Multi-Card Login Screen ordering, Admin Auth Studio, `LOCKOUT_PREVENTED`), requirement `#6` | **Dependencies:** `KB-P2-09` (`LOCKOUT_PREVENTED` safeguards), `KB-P2-06` (OIDC config + discovery probe + `/start`), `KB-P2-07` (LDAP config + TLS/bind probe), `KB-P2-05a` (`require_admin_aal2`)

### Scoped Technical Actions
1. **Target Files:**
   - `database/migrations/versions/<rev>_auth_card_admin_ops.py` (extend `kb_auth` with `card_list_enabled_public` including `id`, `card_admin_set_enabled`, `card_admin_reorder`, `card_admin_set_health`, `card_admin_delete`)
   - `kanban/util/__init__.py`, `kanban/util/fractional_rank.py` (`midpoint_rank`, `initial_ranks`, `needs_rebalance` using ASCII base-62 `0-9A-Za-z` under `COLLATE "C"`, reusable by `KB-P3-12`)
   - `kanban/auth/cards/handshake.py` (`probe_auth_card_handshake`)
   - `kanban/auth/cards/service.py` (`AuthCardAdminService`)
   - `kanban/api/v1/auth_cards_public.py` (`GET /api/v1/auth/cards`, `GET /api/v1/auth/cards/{slug}/start`)
   - `kanban/api/v1/admin/auth_cards.py` (`/api/v1/admin/auth-cards*` routes, all wired with `Depends(require_admin_aal2)` + `SERVER_ADMIN` check)
   - `kanban/auth/cards/schemas.py` (extend `AuthCardPublic` with `id: UUID` and add `AuthCardCreate`, `AuthCardUpdate`, `AuthCardReorderRequest`, `AuthCardDeleteRequest`, `HandshakeProbeResult`)
2. **Public Endpoints (`auth_cards_public.py`, unauthenticated):**
   - `GET /api/v1/auth/cards`: calls `kb_auth.card_list_enabled_public()`, returning `{"cards": [{"id", "slug", "provider_kind", "display_name", "button_subtext", "icon_preset"}]}` strictly for rows where `is_enabled = TRUE`, ordered by `sort_rank COLLATE "C" ASC, id ASC`. Response schema `extra="forbid"` omits `public_config`, `allowed_email_domains`, `auto_provision_users`, `last_health_status`, `dek_kid`, `encrypted_secret_blob`, and `wrapped_dek`.
   - `GET /api/v1/auth/cards/{slug}/start`: convenience alias mapping `?next=` -> `return_to` and delegating to `OidcFlow.start` (`KB-P2-06`) for enabled `OIDC`/`OAUTH2` cards (`404 NOT_FOUND` if disabled or non-OIDC/OAuth2).
3. **`COLLATE "C"` Fractional Indexing (`kanban/util/fractional_rank.py`):**
   - Alphabet `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz` (`62` chars in strict ASCII byte order matching PostgreSQL `COLLATE "C"`).
   - `midpoint_rank(prev: str | None, nxt: str | None) -> str`: validates `prev < nxt` in byte order (`ValueError` if `prev >= nxt` or trailing `'0'`), computes lexicographic midpoint `prev < mid < nxt` with zero trailing `'0'` so infinite insertions remain subdivisible.
   - `POST /api/v1/admin/auth-cards/{card_ref}/reorder {after: str | None}` (`card_ref` accepts `slug` or `UUID`; `after` = `""` or `null` places card first, otherwise immediately after the card matching `after` slug/UUID): updates `1` row via `kb_auth.card_admin_reorder`; if computed rank exceeds `32` chars (`needs_rebalance`), atomically re-spaces all cards in the workspace with even 4-char ranks preserving exact order.
4. **Admin CRUD, Toggle & Delete (`admin/auth_cards.py` + `service.py`):**
   - Every route requires `require_admin_aal2` (`KB-P2-05a`), role `SERVER_ADMIN` (`403 INSUFFICIENT_CAPABILITY` for `PROJECT_ADMIN`-only callers), and CSRF (`X-CSRF-Token` on unsafe methods).
   - `GET /api/v1/admin/auth-cards` -> `{"cards": [AuthCardAdmin, ...]}` ordered by `sort_rank COLLATE "C"`.
   - `GET /api/v1/admin/auth-cards/{card_ref}` -> `AuthCardAdmin` (`404 NOT_FOUND` if absent in workspace).
   - `POST /api/v1/admin/auth-cards` -> validates `public_config` per `provider_kind` (`OidcCardConfig` from `KB-P2-06`, `LdapCardConfig` from `KB-P2-07`, or `{}` for `LOCAL_ADMIN`; max `1` `LOCAL_ADMIN` card per workspace -> `409 LOCAL_ADMIN_CARD_EXISTS`); validates `allowed_email_domains` (`<= 50` normalized hostnames); seals write-only `secret` (`client_secret`, `private_key_pem`, or `bind_dn_password`) with `seal_card_secret` (`KB-P2-03`) and zeroes plaintext buffer; appends `AUTH_CARD_CREATED` activity (no secret values).
   - `PATCH /api/v1/admin/auth-cards/{card_ref}` -> updates metadata, `public_config`, `allowed_email_domains`, `auto_provision_users`, optional write-only `secret` replacement, and optional `is_enabled`; resets `last_health_status = 'UNVERIFIED'` whenever `public_config` or `secret` changes; appends `AUTH_CARD_UPDATED`.
   - `POST /api/v1/admin/auth-cards/{card_ref}/enable` and `.../disable` -> toggles `is_enabled` via `kb_auth.card_admin_set_enabled`, catching `KB-P2-09` `LockoutPreventedError` -> `409 LOCKOUT_PREVENTED` (with `layer`: `db_trigger` or `handshake_probe_15m`), appending `AUTH_CARD_ENABLED` / `AUTH_CARD_DISABLED`.
   - `DELETE /api/v1/admin/auth-cards/{card_ref}` with body `{confirm_slug: str}` -> requires `confirm_slug == card.slug` (`422 CONFIRM_PHRASE_MISMATCH` otherwise), catches `LockoutPreventedError` -> `409 LOCKOUT_PREVENTED`, appends `AUTH_CARD_DELETED`.
5. **Live Test-Handshake (`POST /api/v1/admin/auth-cards/{card_ref}/test-handshake`, `handshake.py`):**
   - Bounded by `asyncio.timeout(8.0)`:
     - `OIDC`: runs `fetch_discovery` + `JwksCache` fetch (`KB-P2-06`), verifying `issuer` byte-for-byte match and valid signing keys.
     - `OAUTH2`: verifies `authorization_endpoint` and `token_endpoint` TLS handshake / non-5xx reachability with `follow_redirects=False` and SSRF host validation.
     - `LDAP`: connects via `LdapTlsHardClient` (`KB-P2-07`), verifies TLS 1.2+ / StartTLS + CA PEM + SPKI pin, and if `service_bind_dn` is set, executes service `BindRequest` + `UnbindRequest`.
     - `LOCAL_ADMIN`: verifies `KeyMaterial` `auth_pepper` + dummy Argon2id round-trip.
   - Updates `last_health_status` (`"OK"` or `"FAILED:<ERROR_CODE>"`, never raw provider bodies or stack traces; does NOT touch `last_admin_handshake_at` per `KB-P2-09`), appends `AUTH_CARD_HANDSHAKE_TESTED`, and returns `200 HandshakeProbeResult(ok: bool, status: str, latency_ms: int, error_code: str | None)`.
6. **Security invariants asserted:** (a) public `/api/v1/auth/cards` leaks zero IdP URLs, client IDs, email domains, or disabled cards; (b) no admin response or activity record ever contains `secret`, `client_secret`, `private_key_pem`, `bind_dn_password`, `encrypted_secret_blob`, or `wrapped_dek`; (c) every `/api/v1/admin/auth-cards*` route passes `assert_admin_routes_protected(app)` (`KB-P2-05a`); (d) `COLLATE "C"` ordering in PostgreSQL matches Python byte order across 100+ interleaved moves.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/util/test_fractional_rank.py`, `kanban/tests/auth/test_auth_cards_admin_api.py`, `kanban/tests/auth/test_auth_cards_public_api.py`
- **Required Test Cases:**
  1. Positive CRUD & public projection: create OIDC, LDAP, and OAuth2 cards with secrets, enable OIDC + LDAP (keep OAuth2 disabled) -> `GET /api/v1/auth/cards` returns only enabled cards in exact `sort_rank` order with only `{id, slug, provider_kind, display_name, button_subtext, icon_preset}`.
  2. Security (zero config/secret leakage): inspect raw JSON of `GET /api/v1/auth/cards`, `GET /api/v1/admin/auth-cards`, `POST`, `PATCH`, and `activity_records` for canary secret `s3cr3t-canary-p2-10` and `issuer` URL; canary is `0` hits everywhere, and `issuer` / `client_id` / `allowed_email_domains` are `0` hits on public `/api/v1/auth/cards`.
  3. Fractional rank (`COLLATE "C"`): 200 random move-to-front, move-to-end, and move-between operations in DB; after every move, `SELECT slug FROM auth_provider_cards ORDER BY sort_rank COLLATE "C"` matches expected list and updates `1` row until rank length `> 32` triggers rebalance while preserving exact order. Note case check: `'Z' < 'a'` holds identically in Python and PG `COLLATE "C"`.
  4. Handshake probe: OIDC card against `fake_idp` -> `ok=True`, `last_health_status="OK"`; `fake_idp` with mismatched issuer -> `ok=False`, `error_code="ISSUER_MISMATCH"`, `last_health_status="FAILED:ISSUER_MISMATCH"`; LDAP card with mismatched SPKI pin -> `ok=False`, `error_code="SPKI_PIN_MISMATCH"`; modifying `public_config` via `PATCH` resets `last_health_status` to `"UNVERIFIED"`.
  5. Lockout enforcement over HTTP: disabling sole admin-capable card returns `409 LOCKOUT_PREVENTED` with `layer="db_trigger"`; disabling `LOCAL_ADMIN` without recent external admin login returns `409 LOCKOUT_PREVENTED` with `layer="handshake_probe_15m"` (even after running synthetic `/test-handshake`!).
  6. Delete confirmation: `DELETE` with wrong or missing `confirm_slug` -> `422 CONFIRM_PHRASE_MISMATCH`; matching `confirm_slug` on unused disabled card -> `204` / `200`.
  7. AuthZ & AAL2 wall: unauthenticated -> `401`; `AAL1` `SERVER_ADMIN` -> `403 AAL2_REQUIRED`; `AAL2` `PROJECT_ADMIN` (not `SERVER_ADMIN`) -> `403 INSUFFICIENT_CAPABILITY`; `assert_admin_routes_protected(app)` returns `[]`.
  8. Validation boundaries: `51` `allowed_email_domains` -> `422`; second `LOCAL_ADMIN` card in workspace -> `409 LOCAL_ADMIN_CARD_EXISTS`; invalid OIDC `http://` URL -> `422`.
