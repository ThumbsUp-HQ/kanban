### User Story
As a **security-conscious engineer inspecting uploaded architecture `.svg` files, raster screenshots, and external Markdown images**, I need **client-side `createSafeSvgBlobUrl()` (`DOMPurify` SVG profile + `<use>` DAG bomb guard -> `<img src="blob:...">`), an interactive `<MediaViewport>` (`10% - 800%` pan/zoom, Lightbox, `🌓` contrast backdrop toggle, Copy Raw Source, Download), and a `🌐` proxied external-image badge** so that **every vector and raster asset is inspectable at pixel detail with zero inline-SVG XSS, zero layout shift, and zero direct browser IP/cookie leakage to third-party hosts**.

**Requirement Traceability:** `S5.4` (`createSafeSvgBlobUrl()`, `DOMPurify` `{ svg: true, svgFilters: false }`, `<use href="#id">` acyclic DAG `depth <= 4` & expansion `<= 500` nodes, `<img src="blob:...">` inside `<MediaViewport>` `max-height: 520px`, Lightbox `10% - 800%` cursor-centered zoom & pan, `🌓` backdrop toggle, Copy Raw Source, Download, `🌐` badge via `/api/v1/media-proxy`, `📴` air-gap offline placeholder), `S3.5` (Hostile Media row), `S6.2` (`🌓` `mediaBackdrop` + `EXTENDED_EMOJI_REGISTRY.externalMedia` `🌐`), requirements `#5`, `#10` | **Dependencies:** `KB-P3-45`, `KB-P3-31`, `KB-P2-16`

2. **Client Safe SVG Sanitizer (`safeSvg.ts`):**
   - Constants: `MAX_CLIENT_SVG_BYTES = 2097152` (`2 MiB`), `MAX_SVG_USE_DEPTH = 4`, `MAX_SVG_EXPANDED_NODES = 500`.
   - Allowed SVG tags (exact `S5.4` set + structural stops): `svg`, `g`, `path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `text`, `tspan`, `defs`, `linearGradient`, `radialGradient`, `stop`, `clipPath`, `marker`, `use`, `title`, `desc`.
   - `createSafeSvgBlobUrl(rawSvg: string): SafeSvgResult`:
     1. Rejects UTF-8 byte length `> 2,097,152` (`SVG_TOO_LARGE`).
     2. Sanitizes via `DOMPurify.sanitize(rawSvg, { USE_PROFILES: { svg: true, svgFilters: false }, ALLOWED_TAGS, FORBID_TAGS: ['script', 'foreignObject', 'iframe', 'image', 'style', 'animate', 'animateTransform', 'animateMotion', 'set', 'feImage', 'filter'], FORBID_ATTR: ['style'] })` using the `dompurify` Trusted Types policy (`S5.4`).
     3. Walks the sanitized XML DOM (`DOMParser` `image/svg+xml`): rejects parse errors (`<parsererror>`); strips any remaining `on*` attribute; strips any `href` or `xlink:href` attribute whose value does not match `/^#[A-Za-z0-9_.:-]+$/` (blocking external fetches inside SVG).
     4. **`<use>` Acyclic Local DAG Guard (`S5.4`):** Builds the reference graph from every `<use href="#id">`. Rejects cycles (`A -> B -> A` -> `SVG_USE_CYCLE`), DAG depth `> 4` (`SVG_USE_MAX_DEPTH`), or total transitive expanded DOM node count `> 500` (`SVG_EXPANSION_LIMIT_EXCEEDED`).
     5. Serializes with `XMLSerializer`, enforces `xmlns="http://www.w3.org/2000/svg"` on `<svg>`, creates `new Blob([serialized], { type: 'image/svg+xml;charset=utf-8' })`, and returns `{ ok: true, blobUrl: URL.createObjectURL(blob), cleanSvg: serialized, revoke: () => URL.revokeObjectURL(blobUrl) }`.
3. **External Media Proxy & Air-Gap Resolver (`mediaUrlResolver.ts`):**
   - `attachment://<id>` resolves via short-lived signed attachment metadata (`GET /api/v1/attachments/{id}/url` or pre-hydrated map).
   - External `https://...` / `http://...` URLs NEVER render raw in `<img src="...">` (enforced by CSP `img-src 'self' blob: data:image/png data:image/webp`). Instead:
     - When `systemStatus.air_gap_mode === true`, returns `{ kind: 'airgap-blocked', originalHost }` which renders a calm placeholder card (`📴 External image blocked in Air-Gap Local-Only Mode (<host>)`) with zero network calls.
     - Otherwise calls `/api/v1/media-proxy/sign?u=...` (or uses pre-signed `/api/v1/media-proxy?u=...&sig=<HMAC>` URL from server normalizer `KB-P2-16`) and flags `isExternalProxied: true` so `<MediaViewport>` renders `<EmojiHint kind="externalMedia">` (`🌐`, hover text exact: `Proxied anonymously via Kanban Media Shield`).
4. **`<MediaViewport>` & `<MediaLightbox>` (`MediaViewport.tsx`, `MediaLightbox.tsx`, `panZoomMath.ts`):**
   - Inline box: `max-height: 520px`, `border: 1px solid var(--border-subtle)`, `border-radius: var(--radius-lg)`, responsive aspect-ratio skeleton placeholder preventing layout shift before `img.onLoad`.
   - Renders strictly `<img src={src} alt={alt} loading="lazy" decoding="async">` (for `.svg` attachments, fenced ```` ```svg ````, and Mermaid outputs, `src` is always `blob:...`; zero inline `<svg>` in document DOM).
   - **Pan & Zoom (`10% - 800%`, `panZoomMath.ts`):**
     - `MIN_ZOOM = 0.10` (`10%`), `MAX_ZOOM = 8.00` (`800%`), `ZOOM_STEP = 1.25`.
     - Cursor-centered `Ctrl/Cmd + Wheel` zoom, two-finger touch pinch-zoom, `-` / `100%` / `+` buttons, and pointer-capture drag pan. Transform applied strictly via CSSOM (`imgRef.current.style.transform = \`translate3d(${tx}px, ${ty}px, 0) scale(${scale})\``) - zero `style="..."` attribute strings (`style-src 'self'`).
   - **Controls Bar:**
     - `🌓` `<EmojiHint kind="mediaBackdrop" variant="interactive">` cycling canvas backdrop classes `.media-bg--theme` -> `.media-bg--light` -> `.media-bg--dark` -> `.media-bg--checkerboard` (CSS repeating-conic-gradient in `MediaViewport.css`) without changing the global app theme (solving dark-stroke SVGs in dark mode per `S5.4`).
     - `🌐` `<EmojiHint kind="externalMedia">` badge when `isExternalProxied === true`; `Alt` badge showing accessible `alt` text on hover/focus.
     - `Copy Raw Source` button (shown when `rawSource` is provided for SVG / Mermaid; copies via `navigator.clipboard.writeText` and announces `Copied source`).
     - `Download` button (`<a download={safeFilename} href={src}>` with filename sanitized to `/^[a-zA-Z0-9._-]+$/`).
     - `Expand` button (or clicking the image) opens `MediaLightbox` (`role="dialog" aria-modal="true"`, full-viewport scrim, focus trapped, `Escape` closes and restores focus to trigger, preserves backdrop selection).

     - Strips `<script>`, `<foreignObject>`, `<iframe>`, `<image href="https://evil.test/track.png">`, `<style>@import ...</style>`, `<animate attributeName="href" to="javascript:...">`, `onload="alert(1)"`, and `<use href="https://evil.test/x.svg#a">`.
     - Rejects `<use>` self/mutual cycle (`#a -> #b -> #a` -> `SVG_USE_CYCLE`), chain depth `5` (`#1 -> #2 -> #3 -> #4 -> #5` -> `SVG_USE_MAX_DEPTH`, while depth `4` passes), and exponential `<use>` billion-laughs expanding to `501` nodes (`SVG_EXPANSION_LIMIT_EXCEEDED`, while `500` nodes passes).
     - Rejects `2,097,153`-byte SVG (`SVG_TOO_LARGE`).
  2. **Pan/Zoom Math (`panZoomMath.ts`):** Clamps zoom cleanly at `0.10` (`10%`) and `8.00` (`800%`); cursor-centered zoom at focal point `(200, 150)` keeps world coordinate under cursor invariant within `0.01px`; `reset()` restores `{ scale: 1, tx: 0, ty: 0 }`.
  3. **External Media Proxy & Air-Gap (`mediaUrlResolver.ts`):** `https://cdn.example.com/arch.png` never passes raw URL to `<img>`; resolves to `/api/v1/media-proxy?...` with `isExternalProxied: true`; when `air_gap_mode: true`, returns `airgap-blocked` with `0` network calls.
  4. **`<MediaViewport>` & `<MediaLightbox>` Interaction:**
     - Renders `<img src="blob:...">` (zero `<svg>` elements inside `.media-viewport`); clicking `🌓` cycles `theme -> light -> dark -> checkerboard` without mutating `document.documentElement.dataset.theme`.
     - Clicking `+` updates readout to `125%` via CSSOM `transform` (assert `img.getAttribute('style')` was not server/JSX string-injected before CSSOM transform); `Copy Raw Source` writes exact clean SVG to clipboard; clicking image opens `MediaLightbox` (`role="dialog"`), `Escape` closes and returns focus to trigger; unmount revokes `blob:` URL.
  5. **Emoji Registry Extension:** `EXTENDED_EMOJI_REGISTRY.externalMedia` glyph is `🌐` and hint equals `Proxied anonymously via Kanban Media Shield`.
