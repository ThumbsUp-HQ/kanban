### User Story
As a **project member or reviewer collaborating on an issue**, I need **the 4-tab Activity feed (`All`, `Comments`, `History`, `🤖 Gates`) and a canonical-Markdown Comment composer with depth-1 threaded replies, 8-emoji reactions, copyable `#comment-<uuid>` permalinks, and access-checked `@mention` warnings** so that **human discussion, immutable ledger history, and workflow gate verdicts live in one breathable stream while mentioning a colleague without access warns explicitly and never silently widens ACLs**.

**Requirement Traceability:** `S7.1` (activity tabs, gate row, creator-override row, and comment composer wireframe lines 544-552), `S7.2 8j` (4 filter tabs `All`, `Comments`, `History`, `🤖 Agent / Workflow Gates` over hash-chained `activity_records`), `S7.2 8k` (canonical `body_markdown`, threaded replies, reactions, `#comment-<uuid>` permalinks, access-checked `@mention` autocomplete + warning without ACL widening), `S6.1` (`--prose-pad`, `--section-gap`, `--text-body`, `--leading-prose`), `S6.2` (`⏳🤖`, `🛑🤖`, `✅🤖`, `🔄`, `🤖`), `S5.1` (canonical Markdown only), `S3.4` (no cross-scope user enumeration), requirements `#8j`, `#8k`, `#5`, `#1`, `#9i`, `#15` | **Dependencies:** `KB-P3-41` (`IssueSurface` `activity` slot), `KB-P3-13` (4-tab activity feed API), `KB-P3-05` (threaded comments, reactions, `409 MENTION_ACCESS_WARNING` API), `KB-P3-03` (`VIEW`-filtered `assignee-suggestions` reused for `@mention` autocomplete)

3. **Threaded Comments, Reactions & `#comment-<uuid>` Permalinks (`CommentCard.tsx`, `S7.2 8k`, `KB-P3-05`):**
   - Top-level `<article id="comment-<uuid>" class="comment-card">` (`padding: var(--card-pad)` `16px 18px`, `row-gap: var(--space-3)` `12px`, prose `font-size: var(--text-body)` `15px`, `line-height: var(--leading-prose)` `1.73`). Replies (`depth = 1`) render indented `var(--space-6)` (`24px`) with a `Reply` button on top-level comments only (`parent_comment_id` always points to the top-level comment so depth never exceeds `1`).
   - Soft-deleted comments (`comment.deleted === true`) render muted placeholder `"Comment deleted"` with zero body text while preserving any existing child replies.
   - **Permalink (`#comment-<uuid>`):** clicking the `#` timestamp/permalink button copies `window.location.origin + comment.permalink` and updates `location.hash = '#comment-' + comment.id` via `navigate(..., { replace: true })` (zero `IssueSurface` remount!). When `location.hash` matches `#comment-<uuid>`, `ActivitySection` switches to `All` (if currently on `History` or `Gates`), scrolls the comment into view, and applies `.comment-card--targeted` highlight ring.
   - **Reactions bar:** supports ONLY the frozen 8-emoji allowlist from `KB-P3-05`: `['👍', '👎', '😄', '🎉', '😕', '❤️', '🚀', '👀']`. Clicking an active reaction pill (`aria-pressed="true"`) calls `DELETE /api/v1/comments/{id}/reactions/{encodeURIComponent(emoji)}`; clicking inactive or `+😊` picker option calls `PUT /api/v1/comments/{id}/reactions/{encodeURIComponent(emoji)}` optimistically.
   - **Edit & Delete:** author sees `Edit` (loads `body_markdown` into inline `CommentComposer`, sends `PATCH /api/v1/comments/{id}` with `If-Match: <etag>`; on `412` keeps user's draft intact and displays `role="alert"` `"This comment was edited elsewhere. Copy your changes and reload."`). Author or Project `ADMIN` sees `Delete` with inline confirmation (`DELETE /api/v1/comments/{id}`).
4. **Comment Composer & Safe `@mention` Warning (`CommentComposer.tsx`, `S7.1`, `S7.2 8k`, `KB-P3-05`):**
   - Breathable composer box (`padding: var(--space-4)` `16px`, `border-radius: var(--radius-lg)`): `<textarea aria-label="Write a comment">` (`placeholder="Write a comment... (Markdown, HTML, Mermaid, SVG auto-clean)"`, `1..262144` UTF-8 bytes) + formatting toolbar buttons `[B]`, `[I]`, `[Code]`, `[Link]`, `[📎 Media/SVG]` (inserts Markdown/triggers attachment callback when available), `[📊 Mermaid]` (inserts fenced ```` ```mermaid ```` template), and primary `Comment` submit button (`Cmd/Ctrl+Enter` shortcut).
   - **Access-checked `@mention` autocomplete:** typing `@<prefix>` outside fenced/inline code queries `GET /api/v1/projects/{projectKey}/assignee-suggestions?q=<prefix>&limit=10` (`KB-P3-03`), guaranteeing zero cross-project user enumeration.
   - **`409 MENTION_ACCESS_WARNING` gate (zero silent ACL widening):** if the user manually types `@maya` where `maya` is a workspace co-viewer lacking `VIEW` on this issue, `POST` (or `PATCH`) returns `409` with `code: 'MENTION_ACCESS_WARNING'` and `unauthorized_mentions: [{ handle, principal_id }]`. `CommentComposer` preserves the draft, focuses an inline `role="alert"` warning bar:
     - Literal text: `"@maya cannot view this issue. Posting will NOT grant access or send a notification to @maya."` (pluralized when multiple handles are listed).
     - Two actions: `Edit comment` (returns focus to textarea) and `Post without granting access` (resubmits once with `acknowledge_mentions: unauthorized_mentions.map(m => m.principal_id)`). The UI NEVER offers a one-click "Grant access and post" button here so ACL changes remain deliberate in the Access Inspector (`KB-P3-49`).
