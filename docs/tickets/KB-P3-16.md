### User Story
As a **collaborating user whose browser connects over `/ws` or `/sse`**, I need **authenticated channel subscriptions fanned out through `RealtimeBroker` where every outbound event is re-verified against `effective_resource_access` at delivery time and resumable via `Last-Event-ID`** so that **live board moves, comments, and `⏳🤖`/`✅🤖`/`🛑🤖` gate updates stream immediately while mid-session ACL revocations cut off delivery with zero leakage**.

**Requirement Traceability:** Spec S2.2 (`PgNotifyBroker` in standalone); S2.3 (Caddy unbuffered `/ws` & `Last-Event-ID` `/sse`, Uvicorn draining); S2.4 (`ValkeyBroker` fanout); S3.3 (`FORCE RLS` / `effective_resource_access`); S3.4 (principal redaction, indistinguishable `NOT_FOUND`); requirements `#1`, `#3`, `#9j` | **Dependencies:** `KB-P1-18`, `KB-P2-02`, `KB-P2-11`, `KB-P0-10`

### Scoped Technical Actions
1. **Target Files:** `kanban/realtime/__init__.py`, `kanban/realtime/hub.py`, `kanban/realtime/rls_filter.py`, `kanban/realtime/replay.py`, `kanban/api/ws.py`, `kanban/api/sse.py`, `kanban/app.py` (replace `/ws` and `/sse` placeholders from `KB-P0-10` and wire lifespan drain).
2. **Authentication & Handshake Hardening (`kanban/api/ws.py`, `kanban/api/sse.py`):**
   - Authenticate via `__Host-` session cookie (`KB-P2-02`) at handshake/connect:
     - `/ws`: enforce strict `Origin` allowlist matching configured `PUBLIC_BASE_URL` (or `localhost` in standalone loopback); mismatch closes with WebSocket code `4403` (`ORIGIN_MISMATCH`) before `accept()`. Missing/expired session closes with `4401` (`UNAUTHENTICATED`).
     - `/sse`: `GET /sse?channels=project:0193...,issue:0193...` with optional `Last-Event-ID` header; unauthenticated returns HTTP `401`. Sets `Content-Type: text/event-stream; charset=utf-8`, `Cache-Control: no-store`, `X-Accel-Buffering: no`.
   - Connection caps: max `16` concurrent realtime connections per `(workspace_id, principal_id)` (`429` on `/sse`, close `4429` on `/ws`); max `64` subscribed channels per connection; max inbound `/ws` frame size `4096` bytes (`4413` on violation).
   - Heartbeat & session revocation: `25s` server `ping` / SSE `: heartbeat\n\n` comment; re-checks session idle/absolute expiry every `60s`; subscribes internally to `security.session_revoked` and `security.principal_deactivated` broker events and closes matching sockets within `<= 250ms` (`4401`).
3. **Channel Protocol & Anti-Enumeration Subscription Check (`kanban/realtime/hub.py`):**
   - Supported channel patterns: `workspace:{uuid}`, `project:{uuid}`, `issue:{uuid}`, `doc:{uuid}`.
   - Client `/ws` frames (`extra="forbid"`):
     - `{"op": "subscribe", "req_id": "1", "channels": ["project:0193..."], "last_event_id": "1042"}`
     - `{"op": "unsubscribe", "req_id": "2", "channels": ["project:0193..."]}`
     - `{"op": "pong"}`
   - Initial subscription check evaluates `VIEW` capability in `effective_resource_access` for the session's `(principal_id, workspace_id)`. Both nonexistent UUIDs and unreadable objects return the exact same frame `{"type": "subscribe_error", "req_id": "1", "channel": "...", "code": "NOT_FOUND"}` (zero enumeration).
4. **Per-Event Delivery-Time RLS & Redaction Filter (`kanban/realtime/rls_filter.py`):**
   - Subscription state at connect time is **never** trusted alone: before fanning out an `OutboxEvent(seq_id, workspace_id, channel, object_id, event_type, actor_principal_id, payload)` to the set of locally subscribed connections `C`, `authorize_event_recipients(session, event, candidate_principals)` runs **one** batched query against `effective_resource_access` (`WHERE object_id = :object_id AND principal_id = ANY(:closure_principals)`) verifying `(allow_mask & 1) = 1 AND (deny_mask & 1) = 0` on `event.object_id` (and `event.workspace_id == conn.workspace_id`).
   - If a subscribed connection's principal no longer holds `VIEW` on `event.object_id` (e.g., an explicit `DENY VIEW` ACL was just granted):
     - If the subscription was `issue:{object_id}` or `doc:{object_id}`, drop the connection's channel subscription and send `{"type": "channel.revoked", "channel": "..."}` with **zero** event payload fields.
     - If the subscription was `project:{project_id}` and the event targets a restricted issue inside that project, silently omit delivery to that connection.
   - Out-of-boundary `actor` metadata in `payload` is redacted per recipient visibility boundary (`{"redacted": true, "label": "1 External Collaborator"}`, `S3.4`).
5. **Resume & Replay (`kanban/realtime/replay.py`):**
   - Every delivered message carries monotonic `event_id = str(outbox_events.seq_id)`.
   - When `Last-Event-ID` (`/sse` header) or `last_event_id` (`/ws` subscribe frame) is supplied:
     - Queries `outbox_events` where `seq_id > :last_seq` for the requested channels within the retention window (`max 500` events and `created_at >= clock_timestamp() - interval '15 minutes'`).
     - If `:last_seq` predates the earliest retained `seq_id` (or exceeds `500` missed rows), emits `{"type": "resync_required", "latest_event_id": "..."}` (SSE `event: resync_required`) instead of partial history.
     - Every replayed event passes through the **current** `authorize_event_recipients` check so events from before an ACL revocation cannot be harvested via replay.
   - Graceful shutdown: ASGI lifespan exit sends `{"type": "server.draining", "retry_ms": 1000}` and closes all active `/ws` (`1001`) and `/sse` streams cleanly within `3s`.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/realtime/test_ws_hub.py`, `kanban/tests/realtime/test_sse_resume.py`, `kanban/tests/realtime/test_rls_event_filter.py`
- **Required Test Cases:**
  1. Positive fanout: connect two authenticated `/ws` clients to `project:<KAN_id>`; insert/publish an issue move outbox event via `PgNotifyBroker` (`@pytest.mark.committed_db`); both clients receive the event with matching `event_id` within `500ms`.
  2. Mid-session ACL revocation (critical security): client `@maya` subscribes to `project:<KAN_id>` and `issue:<KAN_1_id>`; admin adds `DENY VIEW` for `@maya` on `KAN-1`; subsequent `ISSUE_DESCRIPTION_CHANGED` on `KAN-1` is **never** delivered to `@maya` on `project:<KAN_id>`, and `@maya` receives only `channel.revoked` on `issue:<KAN_1_id>` with zero description/hash fields.
  3. Replay & anti-harvesting (`test_sse_resume.py`): emit events `101..105`; `@maya` reconnects to `/sse` with `Last-Event-ID: 102` and receives `103..105`; if `@maya` lost `VIEW` on the issue of event `104` before reconnecting, replay delivers only `103` and `105`; `Last-Event-ID: 1` outside the 500-event window emits `event: resync_required`.
  4. Handshake & session security: unauthenticated `/ws` closes `4401`, `/sse` returns `401`; cross-origin `Origin: https://evil.example` on `/ws` closes `4403`; subscribing to unreadable `project:<SEC_id>` returns `subscribe_error` identical to random UUID; revoking session immediately closes open `/ws` with `4401`.
  5. Boundaries: 65th channel on one socket rejected with `CHANNEL_LIMIT_EXCEEDED`; 17th concurrent connection for one user returns `429` / `4429`; `5000`-byte inbound frame closes `4413`; lifespan shutdown emits `server.draining`.
