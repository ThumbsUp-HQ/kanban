### User Story
As a **security architect**, I need **a single `create_app()` ASGI factory that mounts `/api`, `/ws`, `/sse`, `/mcp/{agent,docs,admin}` placeholders, serves the pre-compressed SPA with correct encoding negotiation and fallback, and stamps every response with the exact S5.4 Content-Security-Policy and hardening headers** so that **the standalone `:8080` server and later phases inherit one hardened HTTP surface**.

**Requirement Traceability:** `S2.3` (Uvicorn + `PrecompressedSPAStaticApp`, single `:8080` port serving `/api/*`, `/ws`, `/sse`, `/mcp/{agent,docs,admin}`, `.br`/`.gz`), `S5.4` (production CSP header), `S3.5` (standalone misconfiguration), Requirement `#3`, `#10` | **Dependencies:** `KB-P0-01`, `KB-P0-03`

### Scoped Technical Actions
1. **Target Files:** `kanban/app.py`, `kanban/settings.py`, `kanban/web_static.py`, `kanban/security/__init__.py`, `kanban/security/headers.py`, `kanban/pyproject.toml` (deps), `uv.lock`, `kanban/tests/test_app.py`, `kanban/tests/test_web_static.py`, `kanban/tests/test_security_headers.py`, `kanban/GEMINI.md` (update contracts)
2. **Settings (`kanban/settings.py`, `pydantic-settings`, prefix `KB_`):** `deployment_mode: Literal["standalone", "production"] = "production"`, `web_dist: Path` (env `KB_WEB_DIST`, default `kanban/web/dist`), `standalone_cleartext_hosts: frozenset[str] = {"localhost", "127.0.0.1", "[::1]"}` (env `KB_STANDALONE_CLEARTEXT_HOSTS` adds entries), `hsts_max_age: int = 63072000`.
3. **Factory `create_app(settings: Settings | None = None) -> FastAPI`:** `docs_url=None`, `redoc_url=None`, `openapi_url="/api/openapi.json"`.
   - `/api`: `APIRouter` with `GET /api/v1/health` -> `200 {"status": "ok"}`. Unknown `/api/*` -> `404` `application/problem+json` `{"type":"about:blank","title":"Not Found","status":404}`.
   - `/ws`: WebSocket route that accepts nothing: closes with code `1008` before `accept()`.
   - `/sse`: `GET` -> `501` problem JSON `title: "Not Implemented"`.
   - `/mcp/agent`, `/mcp/docs`, `/mcp/admin` (and subpaths): `501` problem JSON. `kanban` MUST NOT import `mcp` (import-linter layers contract); the real MCP mounts are composed outside `kanban/` in a later phase.
   - Everything else: `PrecompressedSPAStaticApp` mounted at `/`.
4. **`PrecompressedSPAStaticApp(dist_dir: Path)` (pure ASGI app, `kanban/web_static.py`):**
   - Only `GET` and `HEAD`; others -> `405` with `Allow: GET, HEAD`.
   - Path safety: percent-decode once; reject (`404`) paths containing `\x00`, backslash, or any `..` segment; resolve with `Path.resolve(strict=True)` and require the result to be inside `dist_dir.resolve()` (symlink escape -> `404`).
   - Encoding negotiation: parse `Accept-Encoding` with q-values; prefer `br` (q>0) if `<file>.br` exists, else `gzip` if `<file>.gz` exists, else identity. Set `Content-Encoding` accordingly, `Vary: Accept-Encoding` on every static response, `Content-Type` from the original extension (`mimetypes` with an explicit map for `.js` -> `text/javascript; charset=utf-8`, `.css`, `.html`, `.svg` -> `image/svg+xml`, `.json`, `.wasm` -> `application/wasm`, `.woff2` -> `font/woff2`), `Content-Length` of the served variant, strong `ETag` = `"<sha256-hex-16>-<encoding>"`, `If-None-Match` -> `304`.
   - Caching: paths under `/assets/` -> `Cache-Control: public, max-age=31536000, immutable`; `index.html` -> `Cache-Control: no-cache`.
   - SPA fallback: if the file does not exist AND the last path segment has no `.` AND the path does not start with `/api`, `/ws`, `/sse`, `/mcp` -> serve `index.html` (negotiated) with `200`. Otherwise `404` plain text `Not Found`.
   - Files are read in `64 KiB` chunks; any single file `> 50 MiB` -> `404` (no unbounded reads).
5. **Security headers middleware (`kanban/security/headers.py`, pure ASGI, applied to every HTTP response including errors and static files):**
   - `CSP_POLICY: Final[str]` equal to the S5.4 header joined with single spaces:
     `default-src 'none'; script-src 'self'; worker-src 'self'; style-src 'self'; img-src 'self' blob: data:image/png data:image/webp; font-src 'self'; connect-src 'self' wss:; media-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'; require-trusted-types-for 'script'; trusted-types kanban-sanitizer dompurify;`
   - `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`, `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Resource-Policy: same-origin`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`.
   - `Strict-Transport-Security: max-age=63072000; includeSubDomains` only when `deployment_mode == "production"`; never in standalone.
   - Existing headers with the same names set by inner apps are replaced, never duplicated.
6. **Standalone cleartext block:** when `deployment_mode == "standalone"` and the request scheme is `http`, compare the `Host` header hostname (port stripped, IPv6 brackets kept, lowercase) against `standalone_cleartext_hosts`. Not in the set -> `403` `application/problem+json` `{"type":"about:blank","title":"CLEARTEXT_HTTP_BLOCKED","status":403,"detail":"Standalone mode serves cleartext HTTP only to localhost. Put a TLS reverse proxy in front or add the host to KB_STANDALONE_CLEARTEXT_HOSTS."}`. Missing `Host` -> `400`. Client IP is not used because Docker's `-p` bridge presents the gateway address, not loopback.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/test_app.py`, `kanban/tests/test_web_static.py`, `kanban/tests/test_security_headers.py` (all via `httpx.AsyncClient(transport=httpx.ASGITransport(app))` and `starlette.testclient.TestClient` for WebSocket; static fixtures built in `tmp_path`)
- **Required Test Cases:**
  1. Positive: `GET /api/v1/health` -> `200 {"status":"ok"}`; `GET /mcp/agent` -> `501` problem JSON; `GET /sse` -> `501`; WebSocket connect to `/ws` is closed with `1008`; `GET /api/nope` -> `404` `application/problem+json`.
  2. Positive static: with `app.js`, `app.js.br`, `app.js.gz` in `assets/`, `Accept-Encoding: br, gzip` -> body equals `.br` bytes, `Content-Encoding: br`, `Vary: Accept-Encoding`, `Content-Type: text/javascript; charset=utf-8`, immutable cache header; `Accept-Encoding: gzip` -> gzip; `br;q=0, gzip` -> gzip; no header -> identity; `If-None-Match` with the returned ETag -> `304`.
  3. SPA fallback: `GET /projects/KAN/board` -> `200` `index.html` with `Cache-Control: no-cache`; `GET /assets/missing.js` -> `404`; `GET /api/v2/x` -> problem `404` (no fallback).
  4. Negative/security: `GET /../pyproject.toml`, `GET /%2e%2e/secret`, `GET /assets/%00.js`, `GET /assets\\x.js`, and a symlink inside `dist` pointing outside -> all `404`; `POST /` -> `405` with `Allow: GET, HEAD`.
  5. Headers: every response from cases 1-4 (including `404`, `405`, `501`) carries `Content-Security-Policy` exactly equal to `CSP_POLICY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`; HSTS present in production mode and absent in standalone mode; an inner app that sets its own `X-Frame-Options: SAMEORIGIN` ends with a single `DENY`.
  6. Boundary standalone cleartext: `Host: localhost:8080`, `127.0.0.1:8080`, `[::1]:8080` -> allowed; `Host: 192.168.1.20:8080` -> `403` `CLEARTEXT_HTTP_BLOCKED`; same host listed in `KB_STANDALONE_CLEARTEXT_HOSTS` -> allowed; missing `Host` -> `400`; production mode never blocks.
  7. Boundary: a `50 MiB + 1` byte file -> `404`; `HEAD` returns headers and empty body with correct `Content-Length`.
