### User Story
As a **power user triaging dozens of issues across Board and List views**, I need **a calm Filter & Display bar (saved views, filter chips, 2D `Group x Sub-Group` horizontal swimlanes), an `X` / `Shift+Click` floating multi-select bulk action bar, a quick-create modal (`C`), and the complete single-key shortcut map (`C, /, [, J/K/H/L, S, P, A, I, L, M, D, X`)** so that **I can slice, group, create, and batch-update work items entirely from the keyboard while keeping `Modules` facets and shortcuts completely absent when `modules_enabled = false`**.

**Requirement Traceability:** `S6.3` (`Filter: [Active]  Group: [State v]  Sub-group: [None v]  Display [Tune]` bar, line 492), `S6.4 item 2` (2D `Group By x Sub-Group By` swimlanes across `State`, `Assignee`, `Priority`, `Cycle`, `Module`, `Label`), `S6.4 item 3` (`X` / `Shift+Click` floating bulk bar: `State`, `Priority`, `Assignees`, `Labels`, `Cycle`, `Module`, `Archive`, `Delete`), `S6.4 item 4` & `S1.3 item 3` (`Cmd/Ctrl+K`, `C`, `/`, `[`, `J/K/H/L`, `Enter`/`Space`, `Cmd+Shift+F`, `S`, `P`, `A`, `I`, `L`, `M`, `D`, `X`), `S7.2 8f` (`Modules` facet, swimlane axis, bulk action, and `M` shortcut unmounted/inert when `projects.modules_enabled = FALSE`), requirements `#9j`, `#15`, `#8f` | **Dependencies:** `KB-P3-37` (`BoardView` + Pragmatic DnD), `KB-P3-38` (`ListView`/`TableView` + `viewsApi.ts`), `KB-P3-09a` (archive rule), `KB-P3-09b` (delete preview + trash)

   - `kanban/web/src/features/views/QuickCreateIssueModal.tsx` (handles `C` shortcut and `kb:create-issue` CustomEvent dispatched by `KB-P3-34` Sidebar/CommandPalette and `+ New work item` buttons)

   - `kanban/web/src/features/views/useIssueKeyboardMap.ts` (registers all single-key shortcuts via `KB-P3-34` `registerShortcut`, manages 2D roving `focusedKey` across lanes/rows and `Shift+Click` range selection)

   - Edit: `kanban/web/src/features/views/viewRegistry.tsx` (mount `FilterDisplayBar`, 2D `SwimlaneBoardGrid` when `layout === 'board' && subGroupBy !== 'none'`, `BulkActionBar`, `QuickCreateIssueModal`, and `useIssueKeyboardMap` inside `IssuesWorkspaceRoute`)
2. **Filter & Display bar (`FilterDisplayBar.tsx`, `S6.3`, `S6.4 item 2`, `S7.2 8f`):**
   - Breathable toolbar row (`min-height: 44px`, `margin-bottom: var(--space-5)` `20px`, `gap: var(--space-3)` `12px`):
     - `Filter` button (`/` focuses its search input) supporting facets: `State` (`Active` preset = `backlog|unstarted|started`), `Priority`, `Assignee` (restricted strictly to project `VIEW` suggestions from `KB-P3-03` plus `Unassigned`), `Label`, `Cycle`, `Module` (COMPLETELY OMITTED when `project.modules_enabled === false`), `Due date` (`Overdue`, `Due this week`, `No due date`), and `Gate status` (`⏳🤖 Pending`, `🛑🤖 Vetoed`, `✅🤖 Approved`). Active facets render removable chips + `Clear all`.
     - `Group` selector (`state | priority | assignee | cycle | module | label | none`) and `Sub-group` selector (`none | assignee | priority | cycle | module | label`, automatically excluding the active `Group` axis and excluding `module` when `modules_enabled === false`).
     - `Display [Tune]` popover toggling visible card/row properties and `Save as view` (`POST/PATCH /api/v1/projects/{project_ref}/views`).
3. **2D `Group x Sub-Group` Swimlanes (`SwimlaneBoardGrid.tsx`, `S6.4 item 2`):**
   - Sticky column headers (`324px` `--board-col-w`, `20px` `--board-col-gap`) stay aligned across collapsible horizontal swimlane bands (`padding-block: var(--space-4)` `16px`, band gap `var(--space-6)` `24px`).
   - Dragging a card across `(column, swimlane)` cells updates both the column axis (e.g. `state_id` + `board_rank` via `KB-P3-37`) and the swimlane axis (e.g. `priority`, `cycle_id`, or primary `assignee`) optimistically, rolling back cleanly on API error. Swimlanes whose axis is multi-value (`Label`, `Module`) add the target group value and remove the source group value on cross-lane drop.
4. **Multi-select & floating `BulkActionBar` (`S6.4 item 3`):**
   - Pressing `X` toggles selection on `focusedKey`; clicking a row/card checkbox toggles one item; `Shift+Click` (or `Shift+X` after `J`/`K`) selects the contiguous visible range between `anchorKey` and target key (`max 100` items per batch; attempting `> 100` announces `"Bulk selection is capped at 100 work items"`).
   - Floating bar (`position: fixed; bottom: var(--space-6); left: 50%` centered via CSS class `transform: translateX(-50%)`, `role="toolbar"`, `aria-label="Bulk actions"`): `<N> selected` count, `Clear (Esc)`, and action buttons `State`, `Priority`, `Assignees`, `Labels`, `Cycle`, `Module` (unmounted when `modules_enabled === false`), `Archive`, `Delete`.
   - `Archive` is disabled with tooltip/inline reason `"Only completed or canceled work items can be archived"` whenever ANY selected issue has `state.group` outside `('completed', 'cancelled')` (`S7.2 8p`).
   - `Delete` fetches `GET .../delete-preview` per selected issue (or batch preview), aggregates total `sub_issues_unparented` and `inbound_links_flagged` into one confirmation modal, and executes `DELETE` with each item's `Kb-Blast-Hash`. Partial failures report exact failed keys and preserve those keys in selection.
5. **Complete single-key shortcut map (`useIssueKeyboardMap.ts`, `S6.4 item 4`, `S1.3 item 3`):**
   - Uses `KB-P3-34` `registerShortcut` (ignored inside `input`, `textarea`, `select`, `[contenteditable]`, IME composition, or when a modal dialog is open; `[` and `Cmd/Ctrl+K` remain owned by `KB-P3-34`; `Cmd/Ctrl+Shift+F` owned by `KB-P3-41`):
     - `C` -> opens `QuickCreateIssueModal` (pre-fills active lane/group state and project `default_module_ids` when `modules_enabled === true`).
     - `/` -> opens `FilterDisplayBar` facet search and calls `preventDefault()` so `/` is not typed into the input.
     - `J` / `K` -> moves `focusedKey` down / up within the current list or board column (wrapping across grouped list sections).
     - `H` / `L` -> moves `focusedKey` left / right across Board columns (no-op in 1D `List` view).
     - `Enter` / `Space` -> opens `?peek=<focusedKey>` in `IssueSurface` (`KB-P3-41`).
     - `X` -> toggles `focusedKey` in `selectedIds`.
     - `S` / `P` / `A` / `L` / `M` / `D` -> opens `QuickFieldPopover` anchored to the focused card/row for `State` (`S`), `Priority` (`P`), `Assignee` (`A`), `Labels` (`L`), `Module` (`M` - strict no-op when `project.modules_enabled === false`), or `Due date` (`D`); `I` assigns/unassigns current user `me` optimistically (`S1.3 item 3`).
     - `Escape` -> closes open `QuickFieldPopover` first, else clears `selectedIds` when non-empty.
