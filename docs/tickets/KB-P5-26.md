### User Story
As a **project member promoting a rough Sticky scratchpad into a permanent specification Doc**, I need **an optional AI structuring preview endpoint that outlines headings, preserves Mermaid/code blocks, and requires explicit user confirmation before committing via the lossless ACL-preserving promotion transaction, plus `uv run kanban-agent validate-sticky-promo`** so that **AI never silently rewrites notes or widens sharing ACLs and I can benchmark/validate Sticky structuring locally from the CLI**.

**Requirement Traceability:** `S8.2` (Sticky -> Doc promotion, atomic ACL-preserving `promote-to-doc`, `PROMOTED_TO_DOC` link), `S10.1` (structured generation across `gemini`, `ollama`, `openai`, `fixture`), `S15.2` (`FixtureLLMProvider` cassettes), `S15.3` example 3 (`uv run kanban-agent validate-sticky-promo --provider gemini --model gemini-2.5-flash --sticky-file ./examples/stickies/rough-auth-notes.md`, report items 1-4, exit codes `0`/`2`) | Original requirements `#11`, `#2` | **Dependencies:** `KB-P3-15`, `KB-P5-04`, `KB-P5-05a`, `KB-P2-13`, `KB-P2-17`, `KB-P0-13`

   - `agent/GEMINI.md`, `kanban/GEMINI.md` (update)
2. **Structured Proposal Schema (`agent/sticky_promo/schemas.py`):**
   - `StickyDocProposal` (Pydantic v2, `extra="forbid"`, `strict=True`):
     - `schema: Literal["kb-sticky-doc-proposal/v1"]`
     - `proposed_title: str` (`1..200` chars, single line, plain text)
     - `summary_markdown: str` (`1..1000` chars)
     - `sections: list[DocSection]` (`1..20` items; each `{heading: str (1..140 chars), level: Literal[2, 3], body_markdown: str (1..65536 chars)}`)
     - `extracted_action_items: list[str]` (`0..25` items, `1..280` chars each)
   - `render_canonical_doc_markdown(proposal) -> str`: assembles `# <proposed_title>`, summary blockquote, `##`/`###` sections, and optional `## Open Action Items` checklist, then passes the full string through the `KB-P2-13` canonical Markdown normalizer (stripping any HTML/unsafe URIs).
3. **AI Structuring Pipeline (`agent/sticky_promo/structurer.py`):**
   - Input sticky `body_markdown` capped at `131,072` bytes (`STICKY_TOO_LARGE` above cap).
   - **Step 1 - Outbound Secret Scrubber First:** Runs `KB-P2-17` `outbound_secret_scrubber`; if secrets (`sk-*`, `ghp_*`, `AKIA*`, `kb_*`, PEM private keys) are detected, redacts them before socket/provider dispatch and records `redacted_secrets_count`.
   - **Step 2 - Spotlight Isolation:** Wraps untrusted sticky Markdown inside randomized `<<<UNTRUSTED_STICKY_DATA_<hex> >>>` delimiters (`zero-width` / Unicode tag chars `U+E0000..U+E007F` stripped) with system instructions treating delimited text strictly as source notes, never commands.
   - **Step 3 - Router + Budget Call:** Reserves estimated tokens via `BudgetEnforcer` (`KB-P5-05a`), calls `ProviderRouter.generate_structured(..., response_model=StickyDocProposal)` (`KB-P5-04`) enforcing `air_gap_mode` and residency tier, settles actual usage.
   - **Step 4 - Lossless Fenced-Block Integrity Check (`verify_fenced_blocks_preserved`):** Extracts SHA-256 hashes of every fenced `mermaid` and code block in the scrubbed input sticky and verifies all of them appear in `rendered_markdown` (if the model dropped or mangled a Mermaid/code block, returns `warnings: ["FENCED_BLOCK_MODIFIED"]` and offers deterministic append/fallback so diagrams are never silently lost).
4. **Read-Only Preview API & User-Confirmed Promotion (`kanban/api/v1/sticky_promo_ai.py`):**
   - `POST /api/v1/stickies/{sticky_id}/promote-preview`:
     - Requires caller holds `VIEW` and `EDIT` on `{sticky_id}` under PostgreSQL RLS (`404` if unreadable, `403` if viewer-only).
     - Executes **zero** writes to `docs`, `pages`, `stickies`, `object_links`, or `resource_acl_entries` (verified by row-count test; only `ai_token_ledgers` settles budget).
     - Returns `200 {proposal, rendered_markdown, original_sha256, warnings, acl_preview}` where `acl_preview` reads the sticky's current `access_manifest` (`KB-P2-11`) and states the exact direct `resource_acl_entries` count that will be copied verbatim upon confirmation (`zero privilege widening`).
   - Extends `POST /api/v1/stickies/{sticky_id}/promote-to-doc` (`KB-P3-15`) with optional body fields `{title?: str, structured_body_markdown?: str, expected_sticky_sha256?: str}`: when user confirms the preview, runs `KB-P2-13` canonical Markdown sanitizer on `structured_body_markdown`, verifies `expected_sticky_sha256` against `stickies.body_sha256` (`409 STICKY_MODIFIED_SINCE_PREVIEW` on mismatch), and commits inside the existing single PG transaction from `KB-P3-15` (copying `resource_acl_entries` verbatim + writing `PROMOTED_TO_DOC` link + marking sticky as promoted stub).
5. **CLI `kanban-agent validate-sticky-promo` (`S15.3` Example 3):**
   - Flags: `--provider {gemini,ollama,openai,fixture}`, `--model TEXT`, `--sticky-file PATH` (required), `--acl-fixture PATH` (optional JSON of direct ACL entries to preview ACL preservation), `--cassette PATH`, `--http-cassette PATH`, `--air-gap`, `--report {text,json}` (default `text`), `--verbose-tools`.
   - Prints all 4 S15.3 report sections: (1) scrubbed spotlighted prompt + redaction count, (2) tool/pipeline trace (`scrubber`, `generate_structured`, `fenced_block_check`, `acl_preservation_check`), (3) TTFT + wall-clock latency + token count, (4) schema validation status (`kb-sticky-doc-proposal/v1` + rendered Markdown outline preview). Exit `0` valid, `2` schema/policy error (`ProviderSchemaError`, `AIR_GAP_EGRESS_DENIED`, `FENCED_BLOCK_MODIFIED` when `--strict-blocks`), `1` runtime error.
