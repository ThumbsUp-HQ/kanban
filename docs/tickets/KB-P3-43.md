### User Story
As a **project member working on an issue inside the Ticket Drawer or Full Screen**, I need **the `[🔔 Subscribe]`, `[🔗]` Link/Graph, and `[⋯]` Overflow actions (`Make a copy` checklist dialog, `Open in full screen`, rule-explained `Archive`, and blast-radius `Delete` confirmation modal) plus `Cmd/Ctrl+Shift+C` Markdown link copy** so that **every lifecycle and graph action in `S7.1` / `S7.2 8l-8q` is explicit, reversible or blast-radius-verified, and never leaks restricted linked objects**.

**Requirement Traceability:** `S7.1` (`[🔔 Subscribe] [🔗] [⋯]` header & overflow menu lines 527, 546-552), `S7.2 8l` (`issue_subscriptions` 1-click toggle + per-event mute), `S7.2 8m` (`[🔗]` canonical URL, `Cmd+Shift+C` `[KAN-142](url)`, typed `object_links`, restricted target masking, `🕸️⚠️` `FLAGGED_INVALID`), `S7.2 8n` (`Make a copy` `[Copy] ...` + 3-item checklist), `S7.2 8o` (`Open in full screen` menu action preserving zero-remount), `S7.2 8p` (`Archive` enabled ONLY for `completed`/`cancelled`, else disabled with exact inline reason `"Only completed or canceled work items can be archived"`), `S7.2 8q` (`Delete` modal showing `"N sub-issues unparented, M inbound object_links flagged"` + `Kb-Blast-Hash` + 30-day soft-trash notice), `S6.2` (`🔒`, `🕸️⚠️`), requirements `#8l`-`#8q`, `#13`, `#1` | **Dependencies:** `KB-P3-41` (`IssueSurface` header slots), `KB-P3-06` (subscriptions API), `KB-P3-07` (links + canonical URL API), `KB-P3-08` (copy API), `KB-P3-09a` (archive API), `KB-P3-09b` (delete-preview + delete API)

   - `kanban/web/src/features/drawer-actions/SubscribeAction.tsx` (mounts into `issueSurfaceSlots.subscribe`: 1-click `🔔 Subscribe` / `Subscribed` toggle + split chevron for per-event mute checkboxes)
   - `kanban/web/src/features/drawer-actions/LinkGraphAction.tsx` (mounts into `issueSurfaceSlots.link`: `🔗` popover copying canonical URL or `[KEY](url)`, `Cmd/Ctrl+Shift+C` shortcut, and typed `object_links` manager)
   - `kanban/web/src/features/drawer-actions/IssueOverflowMenu.tsx` (mounts into `issueSurfaceSlots.overflow`: accessible `role="menu"` with `📑 Make a copy`, `↗ Open in full screen` / `Return to side panel`, rule-explained `🗄️ Archive` / `Unarchive`, and `🗑️ Delete...`)
   - `kanban/web/src/features/drawer-actions/MakeCopyDialog.tsx` (`POST /api/v1/issues/{key}/copy` checklist dialog)
   - `kanban/web/src/features/drawer-actions/DeleteBlastRadiusModal.tsx` (`GET .../delete-preview` + `DELETE` with `Kb-Blast-Hash` modal)
   - `kanban/web/src/features/drawer-actions/actionsApi.ts` (typed wrappers + query keys `qk.subscription(key)`, `qk.objectLinks(key)`, `qk.canonicalUrl(key)`)
   - `kanban/web/src/features/drawer-actions/drawerActions.css`
   - Edits: `kanban/web/src/features/drawer/slotRegistry.ts` (register `subscribe: SubscribeAction`, `link: LinkGraphAction`, `overflow: IssueOverflowMenu`), `kanban/web/src/api/queryKeys.ts` (append `subscription`, `objectLinks`, `canonicalUrl` keys if absent)
   - E2E fixtures added: `kanban/web/e2e/fixtures/subscription-kan-142.json`, `kanban/web/e2e/fixtures/links-kan-142.json`, `kanban/web/e2e/fixtures/delete-preview-kan-142.json`
2. **`SubscribeAction` (`8l`, `KB-P3-06`):**
   - Queries `GET /api/v1/issues/{key}/subscription` (`{ subscribed, muted_event_types, source }`).
   - Primary click toggles `PUT /api/v1/issues/{key}/subscription` <-> `DELETE /api/v1/issues/{key}/subscription` optimistically (`aria-pressed={subscribed}`, visible label `Subscribe` / `Subscribed`).
   - Adjacent `Mute events` disclosure button (enabled when `subscribed === true`) opens a popover listing the 7 mutable event types from `KB-P3-06` (`COMMENT_CREATED`, `ISSUE_STATE_CHANGED`, `ISSUE_FIELD_CHANGED`, `ISSUE_DESCRIPTION_CHANGED`, `ISSUE_LABELS_CHANGED`, `ASSIGNEE_ADDED`, `ASSIGNEE_REMOVED`) with human labels; toggling calls `PATCH .../subscription` `{ muted_event_types }`.
3. **`LinkGraphAction` & `Cmd/Ctrl+Shift+C` (`8m`, `KB-P3-07`):**
   - Fetching `GET /api/v1/objects/{key}/canonical-url` provides server-authoritative `{ url, markdown }` (never synthesized from untrusted headers).
   - Clicking `[🔗]` opens a popover with:
     - `Copy canonical URL` button (`navigator.clipboard.writeText(url)`) and `Copy Markdown [KEY](url)` button (`Cmd/Ctrl+Shift+C` also triggers Markdown copy whenever `IssueSurface` is open for `issue`, announcing `"Copied [KAN-142](...) to clipboard"` via `announce()`).
     - **Linked Objects list (`GET /api/v1/objects/{key}/links`):** groups `outbound` and `inbound` links by `link_type`. Readable endpoints render `.mono` key + title; unreadable endpoints (`restricted: true`) render `<EmojiHint kind="restricted" content="Linked object is outside your visibility boundary." />` (`🔒`) + literal `"Restricted Object"` with zero id/key/href; links with `link_state === 'FLAGGED_INVALID'` render `<EmojiHint kind="brokenLink" content="Flagged by Object Link Auditor - target deleted, archived, or ACL-severed." />` (`🕸️⚠️`). Authorized `'LINK'` callers can add a link (`BLOCKS`, `BLOCKED_BY`, `RELATES_TO`, `DUPLICATES`, `VERIFIED_BY_DOC`, `DERIVED_FROM_STICKY` + target ref `1..64` chars -> `POST /api/v1/objects/{key}/links`) and delete outbound links (`DELETE /api/v1/links/{id}`).
4. **`IssueOverflowMenu` (`[⋯]`, `8n`, `8o`, `8p`, `8q`):**
   - Accessible menu button (`aria-haspopup="menu"`, `aria-expanded`, `ArrowDown/Up/Home/End/Escape` keyboard navigation) rendering 4 items in `S7.1` order:
     1. `📑 Make a copy` (hidden/disabled if caller lacks `'EDIT'`; opens `MakeCopyDialog`).
     2. `↗ Open in full screen` (or `Return to side panel` when `mode === 'full'`; invokes `toggleFullScreen()` from `KB-P3-41` preserving `data-mount-id`).
     3. `🗄️ Archive` (or `🗄️ Unarchive` when `issue.archived_at !== null`):
        - Enabled ONLY when `issue.archive_eligibility?.allowed === true` (i.e. `issue.state.group === 'completed' || issue.state.group === 'cancelled'`).
        - When disallowed, rendered with `aria-disabled="true"` (kept focusable in `ArrowDown` cycle for screen-reader discoverability) AND displays the exact visible inline sub-label from `S7.2 8p` / `KB-P3-09a`: `"Only completed or canceled work items can be archived"`.
        - When allowed, click calls `POST /api/v1/issues/{key}/archive`, shows banner `"Archived" + Unarchive button`, and invalidates `qk.issues`.
     4. `🗑️ Delete...` (rendered only when caller holds `'DELETE'` capability; opens `DeleteBlastRadiusModal`).
5. **`MakeCopyDialog` (`8n`, `KB-P3-08`):**
   - Modal `role="dialog"` `aria-modal="true"` showing preview title `[Copy] <summary>` (clamped to `500` code points) and 3 checkboxes (all default unchecked matching `KB-P3-08`):
     - `Include sub-issues` (`include_sub_issues`)
     - `Include attachments` (`include_attachments`)
     - `Link as RELATES_TO` (`link_as_relates_to`)
   - Notes `"Created by will be set to @<me.handle>"`. On `201`, closes dialog, navigates `?peek=<new_copy_key>` (or full-screen route if currently in `full` mode), and if `skipped.restricted_sub_issues > 0` announces `"Copied to <copy_key> (<N> restricted sub-issue(s) skipped)"` without naming any skipped keys. Surfaces `422 COPY_TOO_LARGE` inline.
6. **`DeleteBlastRadiusModal` (`8q`, `KB-P3-09b`):**
   - On open, calls `GET /api/v1/issues/{key}/delete-preview` and displays:
     - Exact blast-radius summary text (`"{sub_issues_unparented} sub-issues unparented, {inbound_links_flagged} inbound object_links flagged"` plus counts of `outbound_links`, `comments`, `attachments`).
     - Soft-trash retention notice: `"Moved to trash for {retention_days} days before permanent audited purge."`
     - Destructive `Move <KEY> to trash` button (disabled while preview is loading) sending `DELETE /api/v1/issues/{key}` with header `Kb-Blast-Hash: <preview.blast_hash>` (extend `apiFetch` headers option cleanly if needed, keeping CSRF intact).
   - On `412 BLAST_RADIUS_CHANGED`: does NOT close modal; replaces displayed counts and `blast_hash` with `problem.current_preview` and shows `role="alert"` `"Blast radius changed since you opened this dialog. Review the updated counts and confirm again."`. On `200`, closes modal and closes `IssueSurface`, announcing `"<KEY> moved to trash (restorable for <retention_days> days)"`.
