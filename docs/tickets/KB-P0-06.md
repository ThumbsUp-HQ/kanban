### User Story
As a **maintainer who must never leave `main` broken**, I need **a GitHub Actions workflow that runs lint/type, Python tests with `--cov-fail-under=95`, web tests with `vitest` coverage, the license gate, and Docker builds of both image targets, always uploading logs, plus documented Dash `status` / `wait` / `logs` usage** so that **every push produces publicly verifiable proof and failures are diagnosable from uploaded logs**.

**Requirement Traceability:** `S15.4` gates 1, 2, 5 (license gate, `>= 95%` coverage + zero warnings, Dash CI/CD verification), `S15.1` item 4 (exact coverage commands) | **Dependencies:** `KB-P0-02`, `KB-P0-03`, `KB-P0-04`, `KB-P0-05`, `KB-P0-07` (the manifest lists only the first four; `KB-P0-07` is required because the `docker-build` job builds the `Dockerfile` it introduces)

### Scoped Technical Actions
1. **Target Files:** `.github/workflows/ci.yml`, `docs/CI.md`, `scripts/ci/run_and_log.sh`, `pyproject.toml` (dev group adds pinned `pyyaml`), `uv.lock`, `scripts/tests/test_ci_workflow.py`, `scripts/tests/test_run_and_log.py`
2. **Workflow `ci.yml`:**
   - `on: push` (all branches) and `pull_request`; `concurrency: { group: ci-${{ github.ref }}, cancel-in-progress: true }`.
   - Top-level `permissions: { contents: read }`. No `pull_request_target`. No secrets referenced in any job.
   - Every `uses:` reference is pinned to a full 40-character commit SHA with a trailing `# vX.Y.Z` comment (e.g. `actions/checkout`, `actions/setup-node`, `astral-sh/setup-uv`, `pnpm/action-setup`, `actions/upload-artifact`, `docker/setup-buildx-action`).
   - `timeout-minutes` set on every job (`<= 20`).
3. **Jobs (exact ids):**
   - `lint-type`: `uv sync --locked`; `make check`.
   - `python-tests`: `install -d -m 0700 /tmp/kb-pgsock`; `docker compose -f docker-compose.test.yml up -d --wait`; `uv run pytest -n auto --cov=database --cov=kanban --cov=mcp --cov=agent --cov=scripts --cov-branch --cov-report=term-missing --cov-report=xml --cov-fail-under=95 --junitxml=reports/pytest.xml`.
   - `web-tests`: `pnpm install --frozen-lockfile --ignore-scripts`; `pnpm --dir kanban/web typecheck`; `pnpm --dir kanban/web lint`; `pnpm --dir kanban/web test:unit --coverage`; `pnpm --dir kanban/web build`.
   - `license-gate`: `uv sync --locked`; `pnpm install --frozen-lockfile --ignore-scripts`; `make license`.
   - `docker-build`: `docker buildx build --target runtime-slim -t kanban:runtime-slim --load .` and `docker buildx build --target standalone -t kanban:standalone --load .`; then `docker image ls kanban` captured to log.
4. **Always-upload logs:** Every command step runs through `scripts/ci/run_and_log.sh <logname> -- <command...>` which executes the command with `set -o pipefail`, tees combined stdout/stderr to `ci-logs/<job>/<logname>.log`, writes the exit code to `ci-logs/<job>/<logname>.exit`, and exits with the command's exit code. Each job ends with:
   ```yaml
   - if: always()
     uses: actions/upload-artifact@<sha> # v4.x
     with: { name: ci-logs-${{ github.job }}, path: ci-logs/, retention-days: 14, if-no-files-found: error }
   ```
   `python-tests` additionally uploads `reports/` (`coverage.xml`, `pytest.xml`) with `if: always()`.
5. **`scripts/ci/run_and_log.sh`:** POSIX `bash`, `set -euo pipefail`, quotes all arguments, no `eval`, refuses log names not matching `^[a-z0-9-]+$` (exit `64`).
6. **`docs/CI.md`:** Sections `## Jobs` (table of job id -> commands), `## Reading Logs` (artifact names), `## Dash Verification` documenting, with exact invocations, the Dash MCP flow from `https://dash.hackedyour.info/llms.txt`: `status` after push, `wait` until the run completes (never manual `sleep` polling), `logs` on failure; and the rule that a red `main` halts all other work until fixed (AGENTS.md Broken Build Taboo).
7. **Remote:** The workflow must run on the project's GitHub repository. If no GitHub remote exists, the implementer stops and reports `BLOCKED: no GitHub remote` to the agent manager instead of simulating a run.

### Mandatory Feature Unit Tests
- **Test File(s):** `scripts/tests/test_ci_workflow.py`, `scripts/tests/test_run_and_log.py`
- **Required Test Cases:**
  1. Positive: `test_ci_workflow.py` parses `.github/workflows/ci.yml` with `yaml.safe_load` and asserts the 5 job ids exist, top-level `permissions == {"contents": "read"}`, and every job has `timeout-minutes <= 20`.
  2. Negative/security: every `uses:` value in every step matches `^[^@]+@[0-9a-f]{40}$`; no step references `secrets.`; the event list does not contain `pull_request_target`.
  3. Positive: every job's last step has `if: always()` and uses `actions/upload-artifact`.
  4. Boundary: `python-tests` command contains `--cov-fail-under=95`; `web-tests` contains `test:unit --coverage`.
  5. `test_run_and_log.py`: `run_and_log.sh ok -- true` exits `0` and writes `ok.exit` containing `0`; `run_and_log.sh bad -- false` exits `1` and writes `1`; log name `../x` exits `64` and writes nothing outside the log dir.
