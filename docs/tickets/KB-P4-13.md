### User Story
As a **workflow gate runner spawning an untrusted `agy -p`, `codex -p`, or SDK transition interceptor**, I need **short-lived ephemeral `kb_agt_eph_*` tokens bound to `(execution_id, Invoker ∩ Agent ∩ Project)` with `TTL <= 120s`, `max_calls <= 25`, and hard allowlisting to at most the 4 read-only lookup tools (`search_tickets`, `read_ticket`, `search_knowledge`, `read_doc`)** so that **a transition gate can inspect related tickets and specs inside its target project without ever mutating state, reading sibling projects, or recursively triggering transitions**.

**Requirement Traceability:** Spec S14.3 item 2 (`ephemeral_bearer_env: KANBAN_EPHEMERAL_MCP_TOKEN`) & item 3 bullet 3 (`kb_agt_eph_*`, `(execution_id, Invoker ∩ Agent ∩ Project)`, `TTL <= 120s`, `max_calls <= 25`, 4 read-only tools); S11.1 (`/mcp/agent` ephemeral token note); S3.2 (OBO intersection); requirements `#2`, `#12`, `#1` | **Dependencies:** `KB-P4-04`, `KB-P4-08`, `KB-P4-02a`, `KB-P2-11`

### Scoped Technical Actions
1. **Target Files:** `database/migrations/versions/<rev>_mcp_ephemeral_tokens.py`, `database/models/mcp_ephemeral_token.py`, `kanban/security/ephemeral_mcp_tokens.py`, `kanban/api/internal/mcp_ephemeral.py`, `database/session.py` & `kanban/security/permissions.py` (enforce `app.ephemeral_project_id` confinement), `mcp/auth.py` (activate reserved `kb_agt_eph_` slot from `KB-P4-02a`).
2. **DDL `mcp_ephemeral_tokens` (`FORCE RLS` workspace policy):**
   ```sql
   CREATE TABLE mcp_ephemeral_tokens (
       id                      UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id            UUID NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
       execution_id            UUID NOT NULL, -- Bound to workflow_transition_executions.id in Phase 5
       invoking_principal_id   UUID NOT NULL REFERENCES principals(id) ON DELETE CASCADE,
       agent_principal_id      UUID NOT NULL REFERENCES principals(id) ON DELETE CASCADE,
       project_id              UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
       token_sha256            BYTEA NOT NULL UNIQUE CHECK (octet_length(token_sha256) = 32),
       allowed_tools           TEXT[] NOT NULL
                               CHECK (cardinality(allowed_tools) BETWEEN 1 AND 4
                                      AND allowed_tools <@ ARRAY['search_tickets','read_ticket','search_knowledge','read_doc']::text[]),
       max_calls               SMALLINT NOT NULL DEFAULT 25 CHECK (max_calls BETWEEN 1 AND 25),
       calls_used              SMALLINT NOT NULL DEFAULT 0 CHECK (calls_used >= 0 AND calls_used <= max_calls),
       created_at              TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       expires_at              TIMESTAMPTZ NOT NULL,
       revoked_at              TIMESTAMPTZ,
       CHECK (expires_at > created_at AND expires_at <= created_at + interval '120 seconds')
   );
   CREATE INDEX mcp_eph_execution_idx ON mcp_ephemeral_tokens (execution_id) WHERE revoked_at IS NULL;
   ```
   `execution_id` is typed `UUID NOT NULL` without a Phase 5 table FK so Phase 4 runs standalone; `KB-P5-18` / `KB-P5-19a` passes `workflow_transition_executions.id` and calls revoke immediately when a gate finishes or times out.
3. **Mint, Consume & Revoke Service (`kanban/security/ephemeral_mcp_tokens.py` & `kanban/api/internal/mcp_ephemeral.py`):**
   - Token format: `kb_agt_eph_<base64url(os.urandom(32)) without padding>` (plaintext returned once over internal mTLS, never persisted or logged).
   - Internal mTLS endpoints (restricted to `agent-runtime` / `kanban-api` service principal client cert; `mcp-gateway` may only call `introspect`/`consume`, **never** `mint`):
     - `POST /internal/v1/mcp/ephemeral-tokens` `{workspace_id, execution_id, invoking_principal_id, agent_principal_id, project_id, allowed_tools?, ttl_seconds<=120, max_calls<=25}` -> `201 {token, expires_at, max_calls, allowed_tools}`. Rejects `ttl_seconds > 120`, `max_calls > 25`, or any tool outside the 4-tool read set with `422`. Verifies `agent_principal_id` has `principal_type = 'AGENT'` and both `invoking_principal_id` and `agent_principal_id` belong to `workspace_id`.
     - `POST /internal/v1/mcp/ephemeral-tokens/by-execution/{execution_id}/revoke` -> sets `revoked_at = clock_timestamp()` on all active tokens for `execution_id` (`200 {revoked_count}`).
   - Atomic introspection & call-budget consumption (`POST /internal/v1/mcp/introspect`, extending `KB-P4-02a`):
     - Accepts `{token, surface, consume_call: bool, tool_name: str | None}`.
     - Surface check: `kb_agt_eph_*` is valid ONLY on `surface IN ('agent', 'docs')`; `surface == 'admin'` returns `{active: false, reason: "SURFACE_KEY_MISMATCH"}`.
     - When `consume_call=false` (`initialize`, `tools/list`): verifies `revoked_at IS NULL AND expires_at > clock_timestamp() AND calls_used < max_calls` and both principals remain `active`, returning `allowed_tools` filtered to the surface (`agent` -> `{'search_tickets','read_ticket'} ∩ allowed_tools`; `docs` -> `{'search_knowledge','read_doc'} ∩ allowed_tools`).
     - When `consume_call=true` (`tools/call`): verifies `tool_name = ANY(allowed_tools)` (else `{active: false, reason: "EPHEMERAL_TOOL_FORBIDDEN"}`) and executes a single atomic `UPDATE mcp_ephemeral_tokens SET calls_used = calls_used + 1 WHERE token_sha256 = $1 AND revoked_at IS NULL AND expires_at > clock_timestamp() AND calls_used < max_calls RETURNING ...`. Zero rows updated -> `{active: false, reason: "EPHEMERAL_CALL_BUDGET_EXCEEDED" | "TOKEN_EXPIRED_OR_REVOKED"}`.
4. **Triple Intersection `Invoker ∩ Agent ∩ Project` (`database/session.py`, `kanban/security/permissions.py`, `mcp/auth.py`):**
   - `mcp/auth.py` **bypasses the 15s positive introspection cache** for `kb_agt_eph_*` so every `tools/call` hits atomic `calls_used + 1` enforcement and sub-millisecond `revoke` takes effect immediately (`0s` stale window).
   - `tools/list` on `/mcp/agent` with a `kb_agt_eph_*` token returns ONLY `search_tickets` and `read_ticket` (subset of `allowed_tools`), omitting all 6 write/transition tools (`create_ticket`, `update_ticket`, `begin_work`, `transition_ticket`, `complete_work`, `add_comment`, `link_objects`); on `/mcp/docs` returns ONLY `search_knowledge` and `read_doc`.
   - When `kanban-api` authenticates an upstream request bearing a `kb_agt_eph_*` subject token, `get_rls_session` sets `SET LOCAL app.principal_id = :invoking_principal_id`, `SET LOCAL app.agent_principal_id = :agent_principal_id`, `SET LOCAL app.token_scopes = 'agent:read,docs:read'`, `SET LOCAL app.ephemeral_project_id = :project_id`, and `SET LOCAL TRANSACTION READ ONLY`!
   - RLS / `app_effective_access` and `permissions.py` enforce:
     1. OBO intersection: object must grant `VIEW` to **both** `invoking_principal_id` AND `agent_principal_id` (`EffectivePerms(Invoker) ∩ AgentGrant(Agent)`).
     2. Project pin: when `current_setting('app.ephemeral_project_id', true)` is non-empty, any `projects`/`issues`/`docs`/`pages`/`stickies` row whose `project_id` is distinct from `app.ephemeral_project_id::uuid` (including `project_id IS NULL` workspace-wide docs unless linked to the project? Strictly `project_id = app.ephemeral_project_id::uuid` per `Invoker ∩ Agent ∩ Project`) is invisible (`0` search rows, equalized `404 NOT_FOUND`).
     3. PostgreSQL `TRANSACTION READ ONLY` provides a kernel-level defense-in-depth guarantee that no code path under an ephemeral token can ever `INSERT`/`UPDATE`/`DELETE` domain rows.
5. **Error codes appended (`mcp/errors.py`):** `EPHEMERAL_TOOL_FORBIDDEN`, `EPHEMERAL_CALL_BUDGET_EXCEEDED`.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/security/test_ephemeral_mcp_tokens.py`, `mcp/tests/test_ephemeral_auth.py`
- **Required Test Cases:**
  1. Positive read-only lookup: mint `kb_agt_eph_*` for `(execution_id, @adam, agent=agy-gate, project=KAN, max_calls=3, ttl=60s)`; `tools/list` on `/mcp/agent` lists only `[search_tickets, read_ticket]` (consumes `0` calls); `tools/list` on `/mcp/docs` lists only `[search_knowledge, read_doc]`; calling `search_tickets`, `read_ticket("KAN-1")`, and `read_doc("docs/kan-spec")` succeeds (`calls_used == 3`).
  2. Call-budget & TTL hard caps: 4th `tools/call` on the `max_calls=3` token fails immediately with `EPHEMERAL_CALL_BUDGET_EXCEEDED` (including under 10 concurrent `asyncio.gather` calls on a `max_calls=5` token: exactly `5` succeed and `5` fail); minting `ttl_seconds=121` or `max_calls=26` returns `422` (and DB CHECK rejects direct SQL insert); frozen clock at `+121s` returns `401`; `revoke` by `execution_id` invalidates the token on the very next call (`0s` cache delay).
  3. Write-tool & surface isolation: calling `create_ticket`, `add_comment`, `transition_ticket`, or `upsert_doc` directly via `tools/call` with a `kb_agt_eph_*` token returns `EPHEMERAL_TOOL_FORBIDDEN`; presenting `kb_agt_eph_*` on `/mcp/admin` returns `403 SURFACE_KEY_MISMATCH` before network; attempting to mint `allowed_tools=["create_ticket"]` fails `422` and DB CHECK.
  4. Triple-intersection confinement (`Invoker ∩ Agent ∩ Project`): seed projects `KAN` and `SEC` where **both** `@adam` and `agy-gate` hold `VIEW` on `KAN` and `SEC`, plus issue `KAN-2` where `@adam` holds `VIEW` but `agy-gate` has no grant, and `KAN-3` where `agy-gate` holds `VIEW` but `@adam` has `DENY VIEW`. Using a `kb_agt_eph_*` token pinned to `KAN`, verify `read_ticket("SEC-1")`, `read_ticket("KAN-2")`, and `read_ticket("KAN-3")` all return byte-identical `NOT_FOUND`, and `search_tickets(query="*")` returns only `KAN-1`.
  5. mTLS mint boundary: `mcp-gateway` service principal attempting `POST /internal/v1/mcp/ephemeral-tokens` is rejected `403` (only `agent-runtime` / `kanban-api` may mint).
