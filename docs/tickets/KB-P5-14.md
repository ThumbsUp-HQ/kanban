### User Story
As a **systems security architect**, I need **a hardened Tier B `nsjail` runner backed by `deploy/seccomp/sandbox-profile.json` (`<= 128 MiB` cgroup RAM, `<= 3,000ms` timeout, read-only tmpfs root, zero internet route), an out-of-sandbox Unix-socket egress proxy that injects short-lived tokens (`TTL <= 15s`, `<= 10` GETs, `X-Kanban-Script-Depth: 1`) without exposing raw tokens inside the sandbox, and a startup `CLONE_NEWUSER` probe that fails closed in standalone `docker run`** so that **polyglot custom scripts can never steal bearer credentials, make arbitrary network connections, recurse infinitely, or execute unsandboxed when Linux user namespaces are unavailable**.

**Requirement Traceability:** `S13.3` item 2 (Tier B `nsjail`: `<= 128 MiB` cgroup v2 RAM, `<= 3,000ms` timeout, read-only tmpfs root, zero internet route) and item 3 (Out-of-Sandbox Egress Proxy on Unix socket, `TTL <= 15s`, `max_requests <= 10`, allowlisted `/api/v1/...` GET routes, `X-Kanban-Script-Depth: 1`, zero raw token inside sandbox), `S2.2` item 5 (`CLONE_NEWUSER` probe at startup fails closed with `SANDBOX_UNAVAILABLE_IN_STANDALONE`), `S2.1` (`deploy/seccomp/sandbox-profile.json`), `S2.4` (`script-sandbox` container) | Original requirement `#14` | **Dependencies:** `KB-P5-13`, `KB-P0-08`, `KB-P0-09`

### Scoped Technical Actions
1. **Target Files:**
   - `deploy/seccomp/sandbox-profile.json` (OCI / Kafel-compatible strict seccomp-BPF syscall allowlist)
   - `kanban/sandbox/probe.py` (`SandboxProbeResult`, `probe_nsjail_userns()`)
   - `kanban/sandbox/egress_proxy.py` (`TokenInjectingEgressProxy`, `EgressProxyPolicy`)
   - `kanban/sandbox/nsjail_runner.py` (`TierBNsjailRunner` implementing `TierBRunner` from `KB-P5-13`, `NsjailCommandBuilder`, `SubprocessLauncher` protocol)
   - `kanban/api/middleware/script_depth.py` (`ScriptDepthGuardMiddleware` enforcing `X-Kanban-Script-Depth`)
   - `deploy/standalone/storage_probe.py` (modify: include `tier_b_sandbox_available: bool` and `tier_b_unavailable_reason: str | None` in `StandaloneStatus`)
   - `kanban/GEMINI.md` (update sandbox contracts & failure codes)
2. **Strict Seccomp Profile (`deploy/seccomp/sandbox-profile.json`):**
   - `defaultAction`: `"SCMP_ACT_ERRNO"` (`errnoRet: 1` `EPERM`), architectures `SCMP_ARCH_X86_64` and `SCMP_ARCH_AARCH64`.
   - Allowlist minimal userland runtime syscalls (`read`, `write`, `openat`, `close`, `fstat`, `newfstatat`, `mmap`, `mprotect`, `munmap`, `brk`, `rt_sigaction`, `rt_sigprocmask`, `rt_sigreturn`, `pread64`, `readv`, `writev`, `pipe2`, `dup`, `dup2`, `dup3`, `fcntl`, `ioctl` on stdio only, `nanosleep`, `clock_gettime`, `getpid`, `gettid`, `getuid`, `geteuid`, `getgid`, `getegid`, `execve`, `exit`, `exit_group`, `wait4`, `futex`, `set_tid_address`, `set_robust_list`, `rseq`, `prlimit64`, `getrandom`, `poll`, `ppoll`, `epoll_create1`, `epoll_ctl`, `epoll_pwait`, `getcwd`, `readlinkat`, `getdents64`, `connect`, `sendto`, `recvfrom`, `shutdown`).
   - `socket` syscall allowed **strictly** when arg `0` (`domain`) == `AF_UNIX` (`1`); `AF_INET` (`2`), `AF_INET6` (`10`), `AF_NETLINK` (`16`), `AF_PACKET` (`17`), and `AF_VSOCK` (`40`) fail with `EPERM`.
   - Explicitly absent / denied (verified by unit test): `ptrace`, `mount`, `umount2`, `pivot_root`, `chroot`, `unshare`, `setns`, `clone3`, `bpf`, `perf_event_open`, `userfaultfd`, `io_uring_setup`, `io_uring_enter`, `keyctl`, `add_key`, `request_key`, `kexec_load`, `init_module`, `finit_module`, `acct`, `swapon`, `reboot`, `syslog`.
3. **Startup `CLONE_NEWUSER` Fail-Closed Probe (`kanban/sandbox/probe.py`):**
   - `probe_nsjail_userns(*, nsjail_bin: Path = Path("/usr/bin/nsjail"), runner: SubprocessLauncher) -> SandboxProbeResult`:
     1. Verifies `nsjail_bin` exists, is owned by `UID 0`, and is not group/world-writable (`(mode & 0o022) == 0`).
     2. Executes a 500ms dry self-test (`nsjail` `CLONE_NEWUSER | CLONE_NEWNS | CLONE_NEWNET | CLONE_NEWPID` running `/bin/true` inside empty read-only root).
     3. If `nsjail` is absent or kernel blocks unprivileged `CLONE_NEWUSER` (as in default unprivileged `docker run -p 8080:8080`), returns `SandboxProbeResult(available=False, error_code="SANDBOX_UNAVAILABLE_IN_STANDALONE")`.
   - **Hard Invariant:** `TierBNsjailRunner` checks cached startup probe (and handles runtime `nsjail` namespace setup failure); if `available == False`, it immediately raises `SandboxUnavailableError("SANDBOX_UNAVAILABLE_IN_STANDALONE")` and **never** spawns the target binary directly outside `nsjail`.
4. **Out-of-Sandbox Unix-Socket Token-Injecting Egress Proxy (`kanban/sandbox/egress_proxy.py`):**
   - Per invocation, creates a `0700` host runtime directory `/run/kanban/sandbox/<invocation_uuid>/` with Unix stream socket `proxy.sock` (`0600`).
   - Mints a short-lived script token (`TTL <= 15s`, bound to `definition.target_scope` and `definition.credential_mode`) stored solely in a host-side `bytearray` zeroed (`b[:] = b"\x00" * len(b)`) in `finally`. **Zero token bytes** ever appear in sandbox env vars, argv, stdin, or mounted files.
   - HTTP/1.1 parser over `proxy.sock` enforcing:
     - Total request count per invocation `<= 10` (`429 PROXY_MAX_REQUESTS_EXCEEDED` on request 11).
     - Hard wall-clock lifetime `<= min(timeout_ms, 15_000) ms`; proxy closes socket and rejects requests once `monotonic() >= token_expires_at` (`401 PROXY_TOKEN_EXPIRED`).
     - Method MUST be `"GET"` (`405 PROXY_METHOD_NOT_ALLOWED` on `POST`/`PUT`/`PATCH`/`DELETE`/`CONNECT`).
     - Request target path normalized via POSIX path resolution (rejecting `%2e`, `%2f`, `\`, NUL, `..`, authority-form URLs, and header CR/LF); path must match one pattern in `definition.egress_allowlist` (all under `/api/v1/...`), else `403 PROXY_ROUTE_NOT_ALLOWLISTED`.
     - Strips any sandbox-supplied `Authorization`, `Cookie`, `Host`, `X-Forwarded-*`, and `X-Kanban-*` headers; injects `Authorization: Bearer <token>` and `X-Kanban-Script-Depth: 1`; forwards to internal `kanban-api` with `follow_redirects=False` and caps response body at `512 KiB`.
5. **Recursion Guard (`kanban/api/middleware/script_depth.py`):**
   - Inspects `X-Kanban-Script-Depth` on incoming requests: any non-digit or integer `>= 1` attempting to hit `/api/v1/issues/*/custom-fields/*/execute`, `/api/v1/issues/*/transitions`, or `/mcp/*` is rejected immediately with `409 SCRIPT_RECURSION_BLOCKED` (and `GET /api/v1/issues/*/custom-fields` returns cached rows only without triggering nested script runs when `depth >= 1`).
6. **Tier B `nsjail` Runner (`kanban/sandbox/nsjail_runner.py`):**
   - Spawns `nsjail` via `asyncio.create_subprocess_exec` (never shell) with explicit argv:
     - `--mode o` (once), `--time_limit 3`, `--rlimit_as 256`, `--rlimit_fsize 4`, `--rlimit_nofile 64`, `--rlimit_nproc 32`
     - `--cgroup_mem_max 134217728` (`128 MiB`), `--cgroup_pids_max 32`, `--cgroup_cpu_ms_per_sec 500`
     - `--disable_clone_newnet=false` (isolated loopback-down netns, zero internet route), `--chroot` to minimal `:ro` rootfs, `--mount none:/tmp:tmpfs:size=16777216,mode=1777,noexec,nosuid,nodev`, bind-mount `proxy.sock` -> `/run/sandbox/proxy.sock` (`rw` socket file only), `--seccomp_policy` derived from `deploy/seccomp/sandbox-profile.json`
     - `--keep_env=false`, `--env PATH=/usr/bin:/bin`, `--env KANBAN_EGRESS_SOCK=/run/sandbox/proxy.sock`
   - Streams `kb-field-input/v1` JSON over `FD 0 (stdin)`, enforces monotonic `3,000ms` host timeout (kills process group), caps `stdout` at `64 KiB`, deletes runtime socket dir and zeroes token buffer in `finally`.

- **Test File(s):**

- **Required Test Cases:**
  1. Positive: `TierBNsjailRunner` (with `FakeSubprocessLauncher` recording exact `nsjail` argv/env and driving real Unix-socket requests through `TokenInjectingEgressProxy` to an ASGI test app) fetches 2 allowlisted `GET /api/v1/issues/KAN-10` calls, computes JSON output, and zeroes the token `bytearray` upon completion.
  2. Security (zero token inside sandbox): recorded `nsjail` argv, `--env` flags, stdin bytes, and bind-mounted files contain `0` occurrences of the minted token substring; sandbox-supplied `Authorization: Bearer attacker` header is overwritten by the proxy.
  3. Security (proxy policy): `POST /api/v1/issues` -> `405 PROXY_METHOD_NOT_ALLOWED`; `GET /api/v1/admin/ai/providers` (not in allowlist) -> `403 PROXY_ROUTE_NOT_ALLOWLISTED`; `GET /api/v1/issues/KAN-1/../../admin` and `%2e%2e` -> `403`; 11th `GET` -> `429 PROXY_MAX_REQUESTS_EXCEEDED`; request at `t = 15.001s` (fake clock) -> `401 PROXY_TOKEN_EXPIRED`.
  4. Security (infinite recursion block): proxy injects `X-Kanban-Script-Depth: 1`; upstream request carrying `X-Kanban-Script-Depth: 1` to `POST .../execute` or `POST .../transitions` returns `409 SCRIPT_RECURSION_BLOCKED` and `GET .../custom-fields` triggers `0` nested script executions.
  5. Security (standalone fail-closed): when `probe_nsjail_userns` reports `CLONE_NEWUSER` denied (`EPERM`) or missing/world-writable `nsjail` binary, `TierBNsjailRunner.run()` raises `SANDBOX_UNAVAILABLE_IN_STANDALONE` with `0` script subprocess spawns; `StandaloneStatus` serializes `tier_b_sandbox_available: false`.
  6. Security (seccomp profile validation): parses `deploy/seccomp/sandbox-profile.json`, asserts `defaultAction == "SCMP_ACT_ERRNO"`, `socket` syscall restricted to `AF_UNIX`, and none of the 23 forbidden escape syscalls appear in any `SCMP_ACT_ALLOW` rule.
  7. Boundary: child exceeding `3,000ms` -> process group killed and `SCRIPT_TIMEOUT` returned; stdout exceeding `64 KiB` -> `SCRIPT_OUTPUT_TOO_LARGE`; exact cgroup flag `--cgroup_mem_max 134217728` present in argv.
- **Coverage:** `>= 95%` line + branch across `kanban.sandbox.probe`, `kanban.sandbox.egress_proxy`, `kanban.sandbox.nsjail_runner`, and `kanban.api.middleware.script_depth`.
