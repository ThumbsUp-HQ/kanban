### User Story
As a **systems architect enforcing hard latency SLAs in CI**, I need **an automated performance budget suite and threshold gate (`scripts/perf_budget_gate.py`) verifying optimistic board drag `< 12ms`, Sparkle FIM p95 `< 150ms` (fixture), sync Wasm workflow hooks p95 `< 25ms`, `1,000` clean-DB `SAVEPOINT` tests `< 10s`, and warm standalone container boot `< 3s`** so that **any latency regression fails the build immediately with quantitative percentile evidence**.

**Requirement Traceability:** Spec S1.3 item 2 & S6.4 item 1 (`< 12ms` optimistic drag + 1-row `board_rank` move); S9.1 & S9.3 (`< 150ms` p95 Sparkle FIM with `18ms` RLS vector timeout); S14.1 (`< 25ms` Tier A Wasm sync hooks); S15.1 (`1,000+` clean-DB `SAVEPOINT` tests in `< 10s`); S2.2 (`< 3s` standalone boot); requirement `#3`, `#7`, `#9j` | **Dependencies:** `KB-P5-09`, `KB-P5-17a`, `KB-P3-37`, `KB-P0-08`, `KB-P0-06`

   - `.github/workflows/ci.yml` (add `perf-budgets` job executing `scripts/perf_budget_gate.py` and uploading `perf-report.json` with `if: always()`)
2. **Five Enforced SLA Benchmarks:**
   1. **Board Optimistic Drag Frame (`< 12.0ms`, `kanban/web/e2e/perf-board-drag.spec.ts`):**
      - Seeds a 200-card virtualized board (`5` columns x `40` cards) against the mock/in-process API (`KB-P3-32` / `KB-P3-37`).
      - Instruments `performance.mark` from `drop` dispatch to React DOM state commit + `PerformanceObserver('longtask')` / CDP `Tracing.start` across `20` consecutive card drags; records `p50_ms`, `p95_ms`, and `max_ms` of optimistic frame commit into `perf-drag.json` (`SLA: p95_ms < 12.0`).
   2. **Sparkle FIM Endpoint Latency (`p95 < 150.0ms`, `tests/perf/test_perf_sparkle_sla.py`):**
      - Seeds `500` `object_embeddings` rows across `3` projects (2 readable, 1 restricted under `app_rls_reader` `FORCE RLS`) and configures `FixtureLLMProvider` (`simulated_ttft_ms=18`, streaming `24` tokens).
      - Fires `10` warm-up + `200` measured requests to the Sparkle FIM endpoint (`KB-P5-07`, including outbound secret scrubber + `app_rls_reader` `18ms` vector retrieval + output sanitizer); records `ttft_p95_ms` and `total_p95_ms` (`SLA: total_p95_ms < 150.0`, `error_rate == 0.0`).
   3. **Sync Tier A Wasm Workflow Hooks (`p95 < 25.0ms`, `tests/perf/test_perf_sync_hooks_sla.py`):**
      - Attaches `3` enabled Tier A `Wasmtime` hooks (`2` `sync_validator` + `1` `sync_mutator` compiled `.wasm` fixtures from `KB-P5-13`/`KB-P5-17a`) on `In Review -> Done`.
      - Executes `10` warm-up + `200` measured transitions through `TransitionEngine` (`KB-P5-17a`) plus `200` `POST /api/v1/issues/{ref}/move` 1-row fractional rank moves (`KB-P3-12`); records `sync_pipeline_p95_ms` (`SLA: < 25.0`) and asserts `board_move_rows_touched == 1`.
   4. **1,000 Clean-DB `SAVEPOINT` Tests (`wall_clock < 10.0s`, `tests/perf/test_perf_clean_db_1000.py`):**
      - Defines `@pytest.mark.parametrize("slot", range(1000))` where every test binds RLS session context, inserts an `objects` + `issues` row (`canonical_key = 'PERF-1'` - identical key in every test, proving `100%` clean `SAVEPOINT` rollback isolation because any leaked row would fail `UNIQUE (workspace_id, object_type, canonical_key)`!), queries it back under `FORCE RLS`, and commits the nested savepoint.
      - Measured by `scripts/perf_budget_gate.py` invoking `uv run pytest tests/perf/test_perf_clean_db_1000.py -n auto -q` (`SLA: wall_clock_s < 10.0`, `passed == 1000`).
   5. **Standalone Warm Boot (`< 3.0s`, `tests/perf/test_perf_standalone_boot.py`):**
      - Marked `@pytest.mark.container`: initializes a named volume on cold run, stops container, then measures `3` warm boots from `docker start` monotonic timestamp to HTTP `200` on `GET http://127.0.0.1:18080/` (`SLA: max_warm_boot_s < 3.0`).
3. **Unified Budget Evaluator (`scripts/perf_budget_gate.py`):**
   - Orchestrates all 5 benchmarks (or `--evaluate-only <dir>` for unit testing the gate logic), aggregates raw distributions (`min`, `p50`, `p95`, `p99`, `max`, `samples`) into `perf-report.json`, renders a Markdown pass/fail table to stdout, and exits `0` iff every metric strictly satisfies its SLA ceiling (`exit 2` on budget breach, `exit 1` on runner error). Zero `sleep`-padding or mocked clocks in measured benchmarks.
