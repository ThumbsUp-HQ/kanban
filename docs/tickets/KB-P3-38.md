### User Story
As a **project member scanning or auditing work items in `/projects/:projectKey/issues?layout=list` or `?layout=table`**, I need **a Plane-parity grouped List view with calm `46px` (`--list-row-h`) breathable rows and a configurable, sortable Table view whose column chooser unmounts `Modules` completely when `modules_enabled = false`** so that **high-volume backlogs remain airy and scannable without verbose inline status text, and power users can inspect structured columns without density clutter**.

**Requirement Traceability:** `S6.1` (`--list-row-h: 46px`, `--board-canvas-pad`, `--font-mono`), `S6.2` (`🛡️`, `🔥/⚡/🔹/💤`, `🏷️`, `🤖`, `⏳🤖/🛑🤖/✅🤖`), `S6.4 item 2` (`List` grouped sections and `Table` native views backed by `Views` object), `S7.2 8e` (overdue date indicator suppressed on `completed`/`cancelled`), `S7.2 8f` (`Modules` column and option `100%` unmounted when `projects.modules_enabled = FALSE`), requirements `#9j`, `#15`, `#8f` | **Dependencies:** `KB-P3-34` (AppShell, `LayoutSwitcher`, router), `KB-P3-11` (views & query engine), `KB-P3-01b` (states, priorities, labels)

   - `kanban/web/src/features/table/TableView.tsx` (semantic `<table>` with sticky header, sortable columns, `46px` row height)
   - `kanban/web/src/features/table/ColumnConfigurator.tsx` (`Columns` popover menu toggling visible columns, column order Move Up/Down, and Reset to defaults)

2. **Breathable `ListView` & `ListRow` (`S6.1`, `S6.4 item 2`):**
   - Groups issues by active `groupBy` (default `state`, ordered by `workflow_states.sort_order`; empty states rendered with `0` count and collapsible via `<button aria-expanded>`). Section header height `40px`, `padding: 0 var(--space-4)` (`16px`), gap between sections `var(--space-6)` (`24px`).
   - Every `.list-row` has `min-height: var(--list-row-h)` (`46px` exact on single-line items; never `< 46px` at any breakpoint, zero `compact`/`dense` variants), `padding: var(--space-2) var(--space-4)` (`8px 16px`), `column-gap: var(--space-3)` (`12px`), `border-bottom: 1px solid var(--border-subtle)`, hover `--bg-hover`.
   - Left cluster: selection `<input type="checkbox" aria-label="Select <KEY>">` (wired to `selectedIds` / `onToggleSelect` prop on `IssueViewProps` so `KB-P3-40` bulk selection works with zero rewrite), state icon (`aria-hidden`), priority `<EmojiHint>` (`🔥/⚡/🔹/💤`), `.mono` `<a href="?layout=list&peek=<KEY>"><KEY></a>`, plain-text `summary` (`flex: 1`, single-line ellipsis on desktop/tablet, 2-line clamp on mobile).
   - Right cluster (`column-gap: var(--space-2)` `8px`): gate `<EmojiHint>` (`⏳🤖`/`🛑🤖`/`✅🤖`) if present, `🛡️` `<EmojiHint kind="access">` when `has_explicit_acl` is true, up to 2 label dots/chips (`+N` overflow), cycle pill, `Modules` pill (ONLY when `project.modules_enabled === true`), due-date pill (overdue highlight suppressed when `state.group` is `completed` or `cancelled`), and assignee chips (including dashed `🏷️` `<EmojiHint kind="externalAssignee">` pill for free-text assignees).
   - Mobile (`<= 767px`): secondary right-cluster pills (`labels`, `cycle`, `modules`) collapse gracefully while keeping `min-height: 46px`, checkbox (`44x44` hit target), priority `<EmojiHint>`, key, summary, `🛡️`/gate `<EmojiHint>`, and primary assignee visible without horizontal page overflow.
3. **Configurable `TableView` & `ColumnConfigurator` (`S6.4 item 2`, `S7.2 8f`):**
   - Scroll container `overflow-x: auto` with `border: 1px solid var(--border-subtle)`, `border-radius: var(--radius-lg)`, `background: var(--bg-surface)`.
   - Semantic `<table>`: sticky `<thead>` (`height: 40px`, `--bg-surface-raised`), `<tbody>` rows `height: var(--list-row-h)` (`46px` minimum, `padding: 0 var(--space-4)` `16px` per `<td>`). Sticky first column (`Select` + `.mono` `Key`) on horizontal scroll.
   - Available columns in `tableColumns.ts`: `key` (locked visible), `summary` (locked visible), `state`, `priority`, `assignees`, `labels`, `cycle`, `modules`, `start_date`, `due_date`, `created_by`, `access`.
   - **Conditional `Modules` invariant (`S7.2 8f`):** When `project.modules_enabled === false`, the `modules` column is completely excluded from both the rendered `<table>` (`<th>`/`<td>` absent from DOM) AND `ColumnConfigurator` options list (even if a stale `localStorage` or saved-view config lists `"modules"`).
   - Sorting: clicking a sortable `<th aria-sort="none|ascending|descending">` header button cycles `ascending -> descending -> none` and passes `sort_by` / `sort_dir` to the issues query (with client-side deterministic tie-break on `sequence_id`).
   - `ColumnConfigurator`: toolbar button `Columns (<visible>/<total>)` opening a non-modal `role="dialog"` `aria-label="Configure table columns"` with checkboxes + `Move up` / `Move down` buttons + `Reset defaults`; persists validated column IDs to `localStorage['kb.tableCols.' + projectKey]` (and `PATCH`es active saved view `display_json.table_columns` when a saved view ID is active). Unknown/corrupt storage values fall back cleanly to default columns.
4. **Keyboard & security invariants:**
   - `ArrowDown` / `ArrowUp` (and `J`/`K` hook via `focusedKey` prop) move roving row highlight; `Enter` opens `?peek=<KEY>`.
   - Zero `dangerouslySetInnerHTML`, zero inline `style` attributes, all issue/label/assignee strings rendered as React text nodes; label `color_hex` validated against `/^#[0-9A-Fa-f]{6}$/` and mapped to a discrete semantic swatch class or CSSOM property on a dot ref, never unvalidated CSS text.

  2. Positive (`TableView` & `ColumnConfigurator`): renders default columns, toggles `Start date` on and `Cycle` off, reorders `Due date` before `Assignees`, persists to `localStorage['kb.tableCols.KAN']`, and cycles `aria-sort` `ascending -> descending -> none` on `Priority` header click.
  3. Conditional `Modules` unmount (`S7.2 8f`): with `project-kan-nomodules.json` (`modules_enabled: false`) AND `localStorage['kb.tableCols.KAN'] = '["key","summary","modules"]'`, neither `ListView`, `TableView` (`queryByRole('columnheader', { name: /modules/i })`), nor `ColumnConfigurator` (`queryByLabelText(/modules/i)`) mounts any `Modules` element in the DOM.
  4. Negative / security: corrupt `localStorage['kb.tableCols.KAN'] = '{"__proto__":1}'` or `'["<script>"]'` falls back to default columns without throwing; hostile issue summary `<img src=x onerror=alert(1)>` and label `color_hex = "red;background:url(//evil)"` render literal text and drop the invalid hex.
  5. Boundary: empty project (`0` issues) renders calm empty state with `+ Create first work item` button; completed issue with past `due_date` does NOT receive `.due-pill--overdue`; single-key locked columns (`key`, `summary`) have disabled checkboxes in `ColumnConfigurator`.
