### User Story
As a **workspace member or security reviewer inspecting any Project, Issue, Sticky, Doc, Page, or View**, I need **clicking the `🛡️` Access Pill to open the Effective Access Inspector popover listing Inherited Scope, direct Users, synced Groups, active `🤖` Agents with an admin `[ Kill Switch ]` hook, `🔒` Explicit DENY overrides, and redacted external principals** so that **sharing scope is 100% transparent on every object without cross-scope principal enumeration**.

**Requirement Traceability:** `S3.4` (Effective Access Inspector wireframe, same-workspace co-viewers, redacted `{ "redacted": true, "label": "1 External Collaborator" }`, indistinguishable `404`), `S3.2` (explicit deny precedence & OBO/autonomous agent grants), `S6.1` (`--prop-row-h`, `--space-*`), `S6.2` (`🛡️`, `🤖`, `🔒` `<EmojiHint>` rows), requirement `#1` | **Dependencies:** `KB-P3-34` (`registerShellPanel`, `HeaderPills`), `KB-P2-11` (`GET /api/v1/objects/{id}/access` `access_manifest`)

2. **Activation & Positioning Contract (`useAccessInspector.ts`):**
   - Registers the `'access'` panel in `ShellPanelsProvider` (`KB-P3-34` Action 7: `openPanel('access', projectObjectId)`) AND listens for `window` `kb:open-access-inspector` (`{ detail: { objectId, anchorEl? } }` from `KB-P3-41` `IssueHeader`, `KB-P3-50` `Docs`, `KB-P3-51` `Stickies`).
   - Validates `objectId` against UUID regex `/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i`; malformed ids are ignored with `0` API calls.
   - Desktop/tablet (`> 767px`): anchored non-clipped `role="dialog" aria-modal="true"` popover (`width: min(520px, 100vw - 32px)`, `max-height: min(680px, 85vh)`, positioned via `positionHint` CSSOM coordinates from `KB-P3-31`, zero `style` attribute strings). Mobile (`<= 767px`): full-width bottom sheet (`width: 100vw`, `max-height: 88dvh`). Focus trapped while open; `Escape` or outside click closes and restores focus to the invoking `🛡️` button.
3. **Wireframe Sections & Breathable Row Rhythm (`AccessInspectorPopover.tsx`, `S3.4`):**
   - Consumes `useQuery(qk.access(objectId))` (`GET /api/v1/objects/{object_id}/access`, `KB-P2-11`). Indistinguishable `404` / `403` renders `Object was not found or you do not have access.` (zero existence oracle).
   - **Header Row:** Title `EFFECTIVE ACCESS FOR <OBJECT_TYPE> <CANONICAL_KEY>` (e.g. `EFFECTIVE ACCESS FOR ISSUE KAN-142`, `.mono` key) + `[Manage Access...]` button rendered ONLY when `manifest.caller_capabilities` includes `'SHARE'` or `'ADMIN'` (dispatches `kb:open-manage-access` `{ detail: { objectId } }`).
   - **Inherited Scope Banner:** `Inherited Scope:` followed by scope badge (`Private`, `📂 Project "<project_name>" (Workspace: <workspace_name>)`, or `Workspace: <workspace_name>`).
   - **Four Ordered Principal Sections** (each row `min-height: var(--prop-row-h)` `38px`, `padding: var(--space-2) var(--space-4)`, section gap `var(--space-5)` `20px`; empty sections render a calm `None` muted line rather than vanishing so security reviewers immediately verify `0` agents or `0` overrides):
     1. **`👤 USERS (<N> Direct)`:** Display name, `.mono` `@handle`, highest effective capability badge (`Admin`, `Edit`, `Comment`, `View`), and provenance tag (`[Project Owner]`, `[Direct Share]`, `[Workspace Admin]`).
     2. **`👥 GROUPS (<N>)`:** Group name, member count + directory origin (`(<count> members, LDAPS synced)`, `(<count> members, OIDC)`, or `(<count> members)`), effective capability badge, and provenance tag (`[Project Role]`, `[Direct Share]`).
     3. **`🤖 AGENTS & WORKFLOW RUNNERS (<N> Active)`:** Header includes `AgentKillSwitchControl` when `caller_capabilities` includes `'ADMIN'` and `agents.length > 0`. Each row renders `<EmojiHint kind="agent">` (`🤖`, tooltip showing harness, OBO delegator if any, and effective permission intersection per `S6.2`), agent display name, harness/model mono descriptor (e.g. `ollama/qwen2.5-coder` or `cli: agy -p, :ro repo`), role badge (`Read`, `Gate`, `OBO`), and scope tag (`[Project Scoped]`, `[In Review->Done]`).
     4. **`🔒 RESTRICTED OVERRIDES (<N>)`:** Each row renders `<EmojiHint kind="restricted">` (`🔒`), target user/group name, and high-contrast `Explicit DENY` pill (`--danger-bg` / `--danger-fg`, `>= 4.5:1` contrast) listing denied capability bits.
   - **Anti-Enumeration Redacted Principals (`S3.4 item 2`):**
     - Any manifest entry with `redacted: true` (or top-level `redacted_count > 0`) renders strictly as a neutral summary row: `<N> External Collaborator(s) - outside your visibility boundary` (`singular` when `N === 1`: `1 External Collaborator`). The component strictly ignores and never renders any unexpected extra fields on a `redacted: true` object (defense-in-depth against serializer regressions).
4. **Agent Kill Switch Hook (`AgentKillSwitchControl.tsx`):**
   - Renders `[ Kill Switch ]` button in the `🤖 AGENTS & WORKFLOW RUNNERS` section header for object/project `ADMIN` callers.
   - Clicking `[ Kill Switch ]` opens an inline confirmation strip (`Revoke all active agent grants on <CANONICAL_KEY>?` + `[Confirm Kill Switch]` + `[Cancel]`, focus moved to `Cancel` by default to prevent accidental Enter activation).
   - Confirming executes `useOptimisticMutation` (`KB-P3-33`) calling `POST /api/v1/objects/{object_id}/access/agent-kill-switch` (with `X-CSRF-Token` via `apiFetch`), optimistically clearing `manifest.agents` to `[]` and adding explicit `DENY` / revoked audit state, rolling back and announcing via `announce()` on `403`/`409`/`500`, and invalidating `qk.access(objectId)` on settle.

  4. **Agent Kill Switch Flow & Rollback:** Clicking `[ Kill Switch ]` reveals `[Confirm Kill Switch]` with focus on `[Cancel]`; confirming sends `POST /api/v1/objects/{id}/access/agent-kill-switch` with `X-CSRF-Token`, optimistically updates active agents to `0`, and on mocked `500` rolls back to `2` active agents and announces rollback in `role="status"`.
  5. **Activation & Keyboard A11y:** Both `openPanel('access', uuid)` and `window.dispatchEvent(new CustomEvent('kb:open-access-inspector', { detail: { objectId: uuid } }))` open the dialog; invalid `objectId: "../../admin"` triggers `0` fetches; `Tab` wraps inside focus trap; `Escape` closes and returns focus to the trigger.
  6. **Indistinguishable 403/404:** Both HTTP `403` and `404` from `GET /api/v1/objects/{id}/access` render the byte-identical message `Object was not found or you do not have access.`.
