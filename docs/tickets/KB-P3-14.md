### User Story
As a **project member or knowledge agent**, I need **REST endpoints to create, edit, move, and organize hierarchical Docs and `ltree` Pages (`max_depth <= 10`), extract heading outlines, and inspect or restore immutable `page_versions` snapshots** so that **permanent architecture specs live in canonical Markdown with ETag concurrency and explicit sharing visibility**.

**Requirement Traceability:** Spec S8.1 (`Docs` + `Pages` `ltree` `max_depth <= 10`, outline rail, version history snapshots, `🛡️` sharing pill); S5.1 (canonical Markdown-only DB); S12.2 (`docs`, `pages`, `page_versions`); S3.4 (`access_manifest`, indistinguishable `404`); requirements `#11`, `#5`, `#13c`, `#13i`, `#1` | **Dependencies:** `KB-P2-13`, `KB-P2-11`, `KB-P1-09`, `KB-P1-14`

### Scoped Technical Actions
1. **Target Files:** `kanban/api/v1/docs.py`, `kanban/api/v1/schemas/docs.py`, `kanban/services/docs.py`, `kanban/services/markdown_outline.py`, `kanban/services/activity.py` (append event types).
2. **Heading Outline Extractor (`kanban/services/markdown_outline.py`):**
   - `extract_markdown_outline(body_markdown: str) -> list[OutlineEntry]`:
     - Parses ATX headings (`#` through `######`) strictly outside fenced code blocks (` ``` ` and `~~~`, honoring fence length) and HTML comments.
     - Strips inline Markdown formatting (`**`, `*`, `` ` ``, `[text](url)` -> `text`) for display `text`, and computes deterministic GitHub-slug `anchor` (`lowercase`, strip non-alphanumeric except spaces/hyphens, spaces -> `-`, duplicate slugs suffixed `-1`, `-2`).
     - Returns `[{"level": 2, "text": "PKCE (S256)", "anchor": "pkce-s256", "start_line": 12}]` (reused by `KB-P3-17` and `KB-P4-08`).
3. **Endpoints:**

   | Method + Path | Capability | Success | Errors |
   | :-- | :-- | :-- | :-- |
   | `GET /api/v1/docs?project=` | `VIEW` (RLS filtered; omit `project` for workspace-scoped docs) | `200` | `404` (unreadable project) |
   | `POST /api/v1/docs` | `EDIT` on project (or workspace `MEMBER` when `project_id=null`) | `201` + `ETag` | `404`, `403`, `422` |
   | `GET /api/v1/docs/{doc_ref}` | `VIEW` | `200` + `ETag`; `304` on `If-None-Match` | `404` |
   | `PATCH /api/v1/docs/{doc_ref}` | `EDIT` | `200` + new `ETag` | `404`, `403`, `412`, `428`, `422` |
   | `DELETE /api/v1/docs/{doc_ref}` | `DELETE` | `200` (soft-trash `objects.deleted_at`) | `404`, `403` |
   | `GET /api/v1/docs/{doc_ref}/tree` | `VIEW` on doc | `200` nested `ltree` tree | `404` |
   | `POST /api/v1/docs/{doc_ref}/pages` | `EDIT` on doc (and parent page when set) | `201` + `ETag` | `404`, `403`, `422 PAGE_MAX_DEPTH_EXCEEDED`, `422` |
   | `GET /api/v1/pages/{page_ref}` | `VIEW` | `200` + `ETag`; `304` on `If-None-Match` | `404` |
   | `PATCH /api/v1/pages/{page_ref}` | `EDIT` | `200` + new `ETag` | `404`, `403`, `412`, `428`, `422` |
   | `POST /api/v1/pages/{page_ref}/move` | `EDIT` on page + new parent | `200` | `404`, `403`, `409 PAGE_CYCLE`, `422 PAGE_MAX_DEPTH_EXCEEDED`, `422 PAGE_PARENT_DOC_MISMATCH` |
   | `DELETE /api/v1/pages/{page_ref}` | `DELETE` | `200` (soft-trash page + subtree) | `404`, `403` |
   | `GET /api/v1/pages/{page_ref}/versions?cursor=&limit=` | `VIEW` | `200` | `404` |
   | `GET /api/v1/pages/{page_ref}/versions/{version_seq}` | `VIEW` | `200` | `404` |
   | `POST /api/v1/pages/{page_ref}/versions/{version_seq}/restore` | `EDIT` (`If-Match` required) | `200` + new `ETag` | `404`, `403`, `412`, `428` |

   - `doc_ref` / `page_ref` accept UUID or human canonical slug path (`docs/<doc-slug>` / `docs/<doc-slug>/<page-slug>`, stored in `objects.canonical_key`).
   - Validation & ETag contract:
     - `title`: plain-text normalized (`U+200B..U+200F` stripped), `btrim` `1..500` chars (`422 TITLE_LENGTH`).
     - `body_markdown`: passed through `normalize_to_markdown()` (`KB-P2-13`), max `1048576` bytes (`422 BODY_TOO_LARGE`).
     - `ETag` = `"<lowercase hex of body_sha256>"`. Any `PATCH` modifying `body_markdown` or `POST .../restore` MUST include `If-Match` (`428 PRECONDITION_REQUIRED` if missing, `412 PRECONDITION_FAILED` with `current_etag` on mismatch, enforced via `UPDATE ... WHERE id=:id AND body_sha256=:expected`).
   - Tree & Breadcrumbs:
     - `GET /api/v1/docs/{doc_ref}/tree` orders siblings by `sort_rank COLLATE "C" ASC, id ASC`. If a caller has `VIEW` on a child page `P2` while an explicit `DENY VIEW` hides ancestor `P1`, `P1` renders in `tree` and `breadcrumbs` solely as `{"restricted": true, "label": "🔒 Restricted Page"}` with zero `id`, `title`, or `slug` leakage.
     - `POST /api/v1/pages/{page_ref}/move` accepts `{"parent_page_id": "<uuid>|null", "after_page_id": "<uuid>|null", "before_page_id": "<uuid>|null"}`; computes Base-62 `sort_rank` (`KB-P3-12` `midpoint_rank` if present, or shared `kanban/services/lexorank.py` Base-62 helper - extract `kanban/services/lexorank.py` if `KB-P3-12` is not yet merged) and maps `KB-P1-09` trigger exceptions `PAGE_CYCLE` -> `409`, `PAGE_MAX_DEPTH_EXCEEDED` -> `422`, `PAGE_PARENT_DOC_MISMATCH` -> `422`.
   - Append-only Version Restore:
     - `POST .../versions/{version_seq}/restore` loads the historical `(title, body_markdown)` from `page_versions` and updates `pages` under `If-Match`; the `KB-P1-09` `pages_versioning_bu` trigger snapshots the pre-restore state into `page_versions` and increments `pages.version_seq` by `1` (never mutates or deletes historical `page_versions` rows).
   - Serializer (`GET` doc/page): includes `id`, `canonical_key`, `title`, `body_markdown`, `body_sha256`, `version_seq`, `breadcrumbs`, `outline` (from `extract_markdown_outline`), `access_manifest` (`KB-P2-11`), and `capabilities`.
4. **Activity events emitted (category `HISTORY`):** `DOC_CREATED`, `DOC_UPDATED {old_sha256, new_sha256, version_seq}`, `DOC_TRASHED`, `PAGE_CREATED`, `PAGE_UPDATED {old_sha256, new_sha256, version_seq}`, `PAGE_MOVED {old_parent_id, new_parent_id, new_sort_rank}`, `PAGE_VERSION_RESTORED {restored_from_seq, new_version_seq}`, `PAGE_TRASHED`.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/api/test_docs_pages.py`, `kanban/tests/services/test_markdown_outline.py`
- **Required Test Cases:**
  1. Positive lifecycle: create doc `201`, create nested pages `P1 -> P2 -> P3`, update `P2` twice (`If-Match` enforced, `version_seq == 3`), list versions returns seq `1` and `2`, restore seq `1` yields `version_seq == 4` with seq `3` preserved in `page_versions` and content equal to seq `1`.
  2. Tree move & DAG guards: move `P2` (with child `P3`) to doc root -> `P3` `hierarchy_path` rebased; moving `P1` under its own descendant `P3` returns `409 PAGE_CYCLE`; creating or moving a subtree so resulting depth exceeds `10` returns `422 PAGE_MAX_DEPTH_EXCEEDED`; moving under a page in another doc returns `422 PAGE_PARENT_DOC_MISMATCH`.
  3. Outline extraction: headings `# H1`, `## PKCE (S256)`, duplicate `## PKCE (S256)` produce anchors `h1`, `pkce-s256`, `pkce-s256-1`; `# not a heading` inside ` ```python ` or `~~~` fence is ignored.
  4. Security & RLS: non-viewer `GET` on doc/page/versions returns equalized `404`; hidden CSS `<span style="opacity:0">inject</span>` stripped on write; explicit `DENY VIEW` on intermediate page `P1` while `P2` is directly shared renders `P1` as `restricted: true` in `breadcrumbs` and `tree` without `P1`'s title.
  5. Concurrency & boundaries: `PATCH` body without `If-Match` returns `428`; stale `If-Match` returns `412` with `current_etag`; `1048576`-byte body succeeds, `1048577` returns `422 BODY_TOO_LARGE`; 501-char title returns `422`.
- Clean-DB `SAVEPOINT` harness (`KB-P0-05`). Touched-module coverage `>= 95%`.
