### User Story
As a **knowledge worker**, I need **comments, project stickies, docs, and hierarchical pages with version snapshots, all stored only as canonical Markdown with a STORED SHA-256 hash** so that **no HTML or AST ever reaches PostgreSQL, every prose body has a tamper-evident ETag, and sticky promotion state is persisted**.

**Requirement Traceability:** `S5.1` (zero `*_html` / `*_ast` columns), `S8.1` (`ltree` pages `max_depth <= 10`, 6-color palette), `S8.2` (`promotion_recommended`, `promotion_snoozed_at_length`), `S12.2` (prose contract lines for `issue_comments`, `stickies`, `docs`, `pages`), Requirements `#5 #10 #11 #8k #13b #13c #13i` | **Dependencies:** `KB-P1-05`

### Scoped Technical Actions
1. **Target Files:**
   - `database/migrations/versions/p1_09_prose_tables.py`
   - `database/migrations/sql/p1_09_prose_tables.up.sql`, `database/migrations/sql/p1_09_prose_tables.down.sql`
2. **Size caps** (the spec fixes only issues `1048576` and projects `524288`; this ticket sets): comments `262144` bytes, stickies `65536` bytes, docs/pages/page_versions `1048576` bytes.
3. **DDL:**
   ```sql
   CREATE TABLE issue_comments (
       id                 UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id       UUID NOT NULL,
       issue_id           UUID NOT NULL REFERENCES issues(id) ON DELETE RESTRICT,
       parent_comment_id  UUID REFERENCES issue_comments(id) ON DELETE RESTRICT,
       author_id          UUID NOT NULL REFERENCES principals(id) ON DELETE RESTRICT,
       body_markdown      TEXT NOT NULL CHECK (octet_length(body_markdown) BETWEEN 1 AND 262144),
       body_sha256        BYTEA GENERATED ALWAYS AS (digest(body_markdown, 'sha256')) STORED,
       created_at         TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       edited_at          TIMESTAMPTZ,
       deleted_at         TIMESTAMPTZ);
   CREATE TABLE docs (
       id               UUID PRIMARY KEY,
       object_type      object_kind NOT NULL DEFAULT 'doc' CHECK (object_type = 'doc'),
       workspace_id     UUID NOT NULL,
       project_id       UUID REFERENCES projects(id) ON DELETE RESTRICT,
       title            TEXT NOT NULL CHECK (char_length(btrim(title)) BETWEEN 1 AND 500),
       body_markdown    TEXT NOT NULL DEFAULT '' CHECK (octet_length(body_markdown) <= 1048576),
       body_sha256      BYTEA GENERATED ALWAYS AS (digest(body_markdown, 'sha256')) STORED,
       hierarchy_path   ltree NOT NULL,
       version_seq      INTEGER NOT NULL DEFAULT 1,
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT);
   CREATE TABLE pages (
       id               UUID PRIMARY KEY,
       object_type      object_kind NOT NULL DEFAULT 'page' CHECK (object_type = 'page'),
       workspace_id     UUID NOT NULL,
       doc_id           UUID NOT NULL REFERENCES docs(id) ON DELETE RESTRICT,
       parent_page_id   UUID REFERENCES pages(id) ON DELETE RESTRICT,
       title            TEXT NOT NULL CHECK (char_length(btrim(title)) BETWEEN 1 AND 500),
       body_markdown    TEXT NOT NULL DEFAULT '' CHECK (octet_length(body_markdown) <= 1048576),
       body_sha256      BYTEA GENERATED ALWAYS AS (digest(body_markdown, 'sha256')) STORED,
       hierarchy_path   ltree NOT NULL CHECK (nlevel(hierarchy_path) BETWEEN 2 AND 11), -- doc label + up to 10 page levels
       version_seq      INTEGER NOT NULL DEFAULT 1,
       sort_rank        TEXT COLLATE "C" NOT NULL DEFAULT 'a0',
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT);
   CREATE INDEX pages_hierarchy_gist ON pages USING gist (hierarchy_path);
   CREATE TABLE page_versions (
       page_id        UUID NOT NULL REFERENCES pages(id) ON DELETE CASCADE,
       version_seq    INTEGER NOT NULL,
       workspace_id   UUID NOT NULL,
       title          TEXT NOT NULL,
       body_markdown  TEXT NOT NULL CHECK (octet_length(body_markdown) <= 1048576),
       body_sha256    BYTEA GENERATED ALWAYS AS (digest(body_markdown, 'sha256')) STORED,
       created_by_id  UUID,
       created_at     TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       PRIMARY KEY (page_id, version_seq));
   CREATE TABLE stickies (
       id                          UUID PRIMARY KEY,
       object_type                 object_kind NOT NULL DEFAULT 'sticky' CHECK (object_type = 'sticky'),
       workspace_id                UUID NOT NULL,
       project_id                  UUID REFERENCES projects(id) ON DELETE RESTRICT,
       body_markdown               TEXT NOT NULL DEFAULT '' CHECK (octet_length(body_markdown) <= 65536),
       body_sha256                 BYTEA GENERATED ALWAYS AS (digest(body_markdown, 'sha256')) STORED,
       color_token                 TEXT NOT NULL DEFAULT 'amber'
                                   CHECK (color_token IN ('amber','mint','sky','lavender','coral','slate')),
       promotion_recommended       BOOLEAN NOT NULL DEFAULT FALSE,
       promotion_snoozed_at_length INTEGER CHECK (promotion_snoozed_at_length IS NULL OR promotion_snoozed_at_length >= 0),
       promoted_to_doc_id          UUID REFERENCES docs(id) ON DELETE SET NULL,
       sort_rank                   TEXT COLLATE "C" NOT NULL DEFAULT 'a0',
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT);
   ```
4. **Triggers:**
   - `*_spine_match_biu` for docs/pages/stickies: workspace (and project where present) equal the `objects` row (`PROSE_SPINE_MISMATCH`); `issue_comments_workspace_bi` sets `workspace_id` from the issue; `parent_comment_id` must belong to the same issue (`COMMENT_PARENT_MISMATCH`).
   - `docs_hierarchy_bi`: `NEW.hierarchy_path := text2ltree('d' || replace(NEW.id::text,'-',''))`.
   - `pages_hierarchy_biu` (BEFORE INSERT OR UPDATE OF parent_page_id, doc_id): parent page must have the same `doc_id` (`PAGE_PARENT_DOC_MISMATCH`); lock ancestor pages `FOR UPDATE` ordered by `nlevel`; reject cycles (`PAGE_CYCLE`); path = `docs.hierarchy_path || 'p<hex>'` or `parent.hierarchy_path || 'p<hex>'`; reject when resulting page depth (`nlevel - 1`) plus moved subtree height `> 10` (`PAGE_MAX_DEPTH_EXCEEDED`); AFTER UPDATE rebases descendants (same pattern as KB-P1-06).
   - `pages_versioning_bu` (BEFORE UPDATE OF title, body_markdown): `INSERT INTO page_versions(page_id, version_seq, workspace_id, title, body_markdown, created_by_id) VALUES (OLD.id, OLD.version_seq, OLD.workspace_id, OLD.title, OLD.body_markdown, app_current_principal_id())`; `NEW.version_seq := OLD.version_seq + 1`. Direct writes to `version_seq` raise `VERSION_SEQ_MANAGED`.
   - `docs_versioning_bu`: increments `docs.version_seq` on body/title change (no snapshot table for docs).
   - `page_versions_immutable_bud`: `BEFORE UPDATE OR DELETE` raises `PAGE_VERSION_IMMUTABLE` (cascade delete from `pages` is allowed only when `pg_trigger_depth() > 1`).
   - `stickies_promotion_guard_bu`: `promoted_to_doc_id` may change only from NULL to a doc in the same workspace (`STICKY_PROMOTION_INVALID`).
5. **Down migration:** drops triggers/functions, `page_versions`, `stickies`, `pages`, `docs`, `issue_comments`.

### Mandatory Feature Unit Tests
- **Test File(s):** `database/tests/test_p1_09_prose.py`, `database/tests/test_p1_09_markdown_only_schema.py`, `database/tests/migrations/test_p1_09_migration.py`
- **Required Test Cases:**
  1. Positive: comment, sticky, doc, page each store `body_markdown`; each `body_sha256` equals Python `hashlib.sha256(body.encode()).digest()`.
  2. Positive (versions): updating a page body twice yields `version_seq = 3` and two `page_versions` rows (seq 1, 2) holding the prior bodies.
  3. Positive (tree): doc D, pages P1 <- P2 <- P3; moving P2 under root of D rebases P3 path.
  4. Negative/security (schema-wide catalog test in `test_p1_09_markdown_only_schema.py`): `SELECT table_name, column_name FROM information_schema.columns WHERE table_schema='public' AND (column_name ~ '_html$' OR column_name ~ '_ast$' OR column_name ~ '^html_' OR (data_type='jsonb' AND column_name ~ '(body|description|content)'))` returns `0` rows; and every column named `*_markdown` in `issues, issue_comments, docs, pages, page_versions, stickies` has a sibling `*_sha256` column with `is_generated = 'ALWAYS'`.
  5. Negative: `color_token='red'` raises `23514`; page cycle raises `PAGE_CYCLE`; parent page from another doc raises `PAGE_PARENT_DOC_MISMATCH`; `UPDATE page_versions` raises `PAGE_VERSION_IMMUTABLE`; explicit `body_sha256` insert raises `428C9`.
  6. Boundary: page at depth 10 accepted, depth 11 raises `PAGE_MAX_DEPTH_EXCEEDED`; sticky body of 65536 bytes accepted, 65537 rejected; empty comment body rejected.
  7. Migration up/down: upgrade `p1_09_prose_tables` -> 5 tables exist; downgrade to `previous_of(...)` -> absent; re-upgrade succeeds.
  - All non-migration tests run under the KB-P0-05 clean-DB `SAVEPOINT` harness; touched-module coverage `>= 95%`.
