### User Story
As an **AI/LLM systems engineer responsible for availability and data residency**, I need **a `ProviderRouter` that wraps every `LLMProvider` call with a per-(workspace, provider) 3-state circuit breaker, fails over only within the same data-residency tier, and blocks cloud providers before DNS resolution when `air_gap_mode = TRUE`** so that **provider outages degrade predictably and no prompt ever leaves an air-gapped or residency-pinned workspace**.

**Requirement Traceability:** `S10.2 (air_gap_mode, CLOSED -> OPEN -> HALF_OPEN, same-residency failover)`, `S15.2 (429 backoff, TTFT SLA timeout, breaker trip fault fixtures)`, `S15.3`, original requirement `#2` | **Dependencies:** `KB-P5-01`, `KB-P5-02`, `KB-P5-03`

### Scoped Technical Actions
1. **Target Files:**
   - `agent/providers/circuit_breaker.py` (new)
   - `agent/providers/air_gap.py` (new)
   - `agent/providers/router.py` (new)
   - `agent/cli.py` (modify: add `--air-gap` flag and `--provider router --route <kind>,<kind>`)
   - `agent/GEMINI.md` (update: breaker thresholds, failure modes)
2. **`CircuitBreaker` (`agent/providers/circuit_breaker.py`):**
   - States `CLOSED`, `OPEN`, `HALF_OPEN` (`enum.StrEnum`). Key: `(workspace_id: UUID, provider_config_id: UUID)`; registry is an in-process `dict` guarded by `asyncio.Lock` (per-replica state is acceptable and documented).
   - Trip conditions (each counts as one failure): `ProviderHTTPError` with status `429` or `>= 500`, `ProviderTimeout`, `ProviderUnavailable`, TTFT SLA breach (`ttft_ms > request.ttft_deadline_ms`). `ProviderSchemaError`, `ProviderSafetyBlock`, `ProviderRefusal`, `ProviderPolicyError` do NOT count (they are content/policy outcomes, not availability).
   - Defaults (spec gives no numbers; recorded as constants in `GEMINI.md`): `failure_threshold = 5` consecutive failures -> `OPEN`; `open_cooldown_s = 30`; after cooldown -> `HALF_OPEN` admitting exactly `1` probe call; probe success -> `CLOSED` (counter reset), probe failure -> `OPEN` with cooldown restarted. A `Retry-After` header on `429` extends cooldown to `max(open_cooldown_s, retry_after)` capped at `300s`.
   - Clock injected (`Callable[[], float]`, default `time.monotonic`) so tests never sleep.
3. **`AirGapGuard` (`agent/providers/air_gap.py`):**
   - `check(provider_kind, settings, *, air_gap_mode: bool) -> None`. When `air_gap_mode` is TRUE, only `ollama` and `fixture` kinds are permitted; `openai` and `gemini` raise `EgressDenied(code="AIR_GAP_EGRESS_DENIED")`.
   - The check runs BEFORE provider construction and BEFORE any resolver call (test asserts resolver call count `0` and transport call count `0`).
   - Ollama under air-gap still passes through `net_guard.resolve_and_pin` (KB-P5-01).
   - `air_gap_mode` value is supplied by the caller from workspace/project settings (`configure_workspace`, KB-P4-09); the router never defaults it to FALSE when the value is unknown - an unknown value is treated as TRUE (fail closed).
4. **`ProviderRouter` (`agent/providers/router.py`):**
   - `RouteCandidate(provider_config_id, provider: LLMProvider, residency_tier: str, priority: int)`.
   - `ProviderRouter(workspace_id, candidates, *, air_gap_mode, breakers, clock)` exposes the same four `LLMProvider` methods plus `last_route_trace` (list of `{provider_config_id, outcome, breaker_state, ttft_ms}` for CLI reports).
   - Selection: candidates sorted by `priority`; skip any whose breaker is `OPEN`; the first chosen candidate fixes the request's `residency_tier`; failover candidates MUST have `residency_tier ==` that value (cloud never fails over to another vendor tier; air-gap never fails over to cloud). If no eligible candidate remains -> `AllProvidersUnavailable(code="NO_PROVIDER_IN_RESIDENCY_TIER")`.
   - Failover only for availability errors listed in action 2; never for policy/content errors.
   - Streaming: failover allowed only before the first chunk is yielded; after the first chunk, an error propagates (no mixed-provider output).
   - TTFT deadline: `stream_complete` wraps first-chunk wait in `asyncio.timeout(ttft_deadline_ms / 1000)`; on expiry the provider stream is `aclose()`d (cancellation propagated) and counted as a breaker failure.
   - Max attempts per request: `min(len(eligible), 3)`.

### Mandatory Feature Unit Tests
- **Test File(s):** `agent/tests/providers/test_circuit_breaker.py`, `agent/tests/providers/test_air_gap.py`, `agent/tests/providers/test_router.py`
- **Cassettes (new, under `tests/fixtures/ai/`, consumed through `FixtureLLMProvider`):** `router_primary_ok.yaml`, `router_fault_429_retry_after.yaml`, `router_fault_503.yaml`, `router_fault_ttft_breach.yaml` (`simulated_ttft_ms: 400`), `router_fault_schema_error.yaml`, `router_stream_error_after_first_chunk.yaml`
- **Required Test Cases:**
  1. Positive: primary healthy -> single call, trace shows `CLOSED`.
  2. Breaker: 5 consecutive `503` -> `OPEN`; 6th call skips provider (transport count unchanged); after `30s` (fake clock) -> `HALF_OPEN` admits 1 probe; probe success -> `CLOSED`; probe failure -> `OPEN`.
  3. Breaker: `429` with `Retry-After: 120` -> cooldown `120s`; `Retry-After: 9999` capped at `300s`.
  4. Breaker: schema error x10 does not trip (state stays `CLOSED`).
  5. Failover: primary `ollama` tier `local` fails -> secondary `ollama` tier `local` used; a `gemini` candidate with tier `gemini-vertex:europe-west4` is never selected.
  6. Security (air-gap): `air_gap_mode=True` with `gemini`/`openai` candidates -> `AIR_GAP_EGRESS_DENIED`, resolver and transport call counts `0`.
  7. Security (air-gap fail closed): `air_gap_mode=None` treated as TRUE.
  8. Security: air-gap with only cloud candidates -> `NO_PROVIDER_IN_RESIDENCY_TIER` never falls back to cloud.
  9. Fault: TTFT breach with `ttft_deadline_ms=150` -> `ProviderTimeout`, upstream stream `aclose()` called, counted as failure.
  10. Fault: error after first streamed chunk -> propagated, no failover call.
  11. Boundary: per-key isolation - breaker `OPEN` for workspace A does not affect workspace B with same provider config.
  12. Boundary: max 3 attempts with 5 eligible failing candidates.
- **Coverage:** `>= 95%` line + branch for the three new modules; zero `asyncio.sleep` with real time in tests.
