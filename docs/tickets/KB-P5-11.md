### User Story
As a **Project or Server Admin defining computed ticket properties**, I need **the `custom_field_definitions` and `custom_field_values` tables with PostgreSQL `FORCE ROW LEVEL SECURITY` (`WITH CHECK` restricting writes strictly to `PROJECT_ADMIN` / `SERVER_ADMIN`), a strict 7-format `output_format_metadata` JSON Schema that bans raw HTML, and admin CRUD endpoints** so that **standard users (`MEMBER`, `VIEWER`, `GUEST`) can never define or alter custom scripts at any layer and field outputs can never inject unsanitized HTML or arbitrary CSS**.

**Requirement Traceability:** `S13.1` (Admin-only definition gate across RBAC, API, MCP, and PG `WITH CHECK` RLS; 7 typed `output_format_metadata` formats, zero raw HTML), `S13.2` (default `PROJECT` + `INVOKING_USER`, deterministic `manifest_sha256` computation), `S3.3` (`FORCE ROW LEVEL SECURITY`), `S7.1` (`Custom Fields (Admin-Defined 🧪)`) | Original requirement `#14` | **Dependencies:** `KB-P1-14`, `KB-P2-05a`, `KB-P2-13`

2. **DDL (`p5_11_custom_fields.py`):**
   ```sql
   CREATE TABLE custom_field_definitions (
       id                      UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id            UUID NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
       project_id              UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
       slug                    TEXT NOT NULL CHECK (slug ~ '^[a-z0-9][a-z0-9-]{1,62}$'),
       name                    TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 80),
       tier                    TEXT NOT NULL DEFAULT 'wasm' CHECK (tier IN ('wasm', 'nsjail')),
       output_format           TEXT NOT NULL CHECK (output_format IN (
                                   'text', 'number', 'badge', 'markdown_snippet', 'url', 'json_table', 'severity_pill'
                               )),
       output_format_metadata  JSONB NOT NULL DEFAULT '{}'::jsonb
                               CHECK (jsonb_typeof(output_format_metadata) = 'object'
                                  AND octet_length(output_format_metadata::text) <= 16384),
       script_source           TEXT NOT NULL CHECK (octet_length(script_source) BETWEEN 1 AND 131072),
       wasm_module_sha256      BYTEA CHECK (wasm_module_sha256 IS NULL OR octet_length(wasm_module_sha256) = 32),
       script_version          INTEGER NOT NULL DEFAULT 1 CHECK (script_version >= 1),
       target_scope            TEXT NOT NULL DEFAULT 'PROJECT'
                               CHECK (target_scope IN ('PROJECT', 'WORKSPACE', 'SERVER')),
       credential_mode         TEXT NOT NULL DEFAULT 'INVOKING_USER'
                               CHECK (credential_mode IN ('INVOKING_USER', 'PROJECT_ADMIN_SP', 'SERVER_ADMIN_SP')),
       egress_allowlist        TEXT[] NOT NULL DEFAULT '{}'
                               CHECK (cardinality(egress_allowlist) <= 16),
       manifest_sha256         BYTEA NOT NULL CHECK (octet_length(manifest_sha256) = 32),
       is_enabled              BOOLEAN NOT NULL DEFAULT TRUE,
       created_by_id           UUID NOT NULL REFERENCES principals(id),
       created_at              TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       updated_at              TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       UNIQUE (project_id, slug)
   );

   CREATE TABLE custom_field_values (
       id                UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id      UUID NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
       project_id        UUID NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
       issue_id          UUID NOT NULL REFERENCES issues(id) ON DELETE CASCADE,
       field_id          UUID NOT NULL REFERENCES custom_field_definitions(id) ON DELETE CASCADE,
       script_version    INTEGER NOT NULL,
       user_access_hash  BYTEA NOT NULL CHECK (octet_length(user_access_hash) IN (0, 32)),
       value_json        JSONB NOT NULL CHECK (octet_length(value_json::text) <= 65536),
       last_latency_ms   INTEGER NOT NULL CHECK (last_latency_ms >= 0),
       computed_at       TIMESTAMPTZ NOT NULL DEFAULT clock_timestamp(),
       expires_at        TIMESTAMPTZ NOT NULL,
       UNIQUE (issue_id, field_id, script_version, user_access_hash)
   );
   ```
   - Enable `ENABLE ROW LEVEL SECURITY` and `FORCE ROW LEVEL SECURITY` on both tables.
   - `custom_field_definitions` policies:
     - `SELECT`: `workspace_id = current_setting('app.workspace_id', true)::uuid` AND caller holds `VIEW` on `project_id` via `effective_resource_access`. Non-admin viewers receive public projection only (`script_source` omitted by serializer unless caller holds `ADMIN` on `project_id`).
     - `INSERT`, `UPDATE`, `DELETE` (`USING` and `WITH CHECK`): `workspace_id = current_setting('app.workspace_id', true)::uuid` AND caller holds `PROJECT_ADMIN` on `project_id` OR `SERVER_ADMIN`, AND `coalesce(current_setting('app.aal_level', true)::int, 0) >= 2`. Standard roles (`MEMBER`, `VIEWER`, `GUEST`) are rejected by PostgreSQL `WITH CHECK` even if application code is bypassed.
   - `custom_field_values` policies:
     - `SELECT`: caller holds `VIEW` on `issue_id` AND (`user_access_hash = ''::bytea` OR `user_access_hash = app_caller_access_hash()`).
     - `INSERT`, `UPDATE`, `DELETE`: workspace match + `VIEW` on `issue_id` and matching `user_access_hash` (so User A can never poison or read User B's partitioned `INVOKING_USER` cache row).
3. **7-Format `output_format_metadata` Schema & Output Value Validator (`kanban/custom_fields/output_formats.py`):**
   - Discriminated union on `format` (`extra="forbid"`, `strict=True`; format enum NEVER includes `html` or `raw_html`):
     1. `text`: `{format: "text", max_length: int = 280 (1..280), prefix?: str (<= 16), monospace: bool = False}` -> value `str` (`<= max_length`, control chars stripped).
     2. `number`: `{format: "number", maximum_fraction_digits: int = 2 (0..6), unit_suffix?: str (<= 12), min_value?: float, max_value?: float}` -> value finite `int | float` (`NaN` / `Infinity` rejected).
     3. `badge`: `{format: "badge", color_token: Literal["neutral", "info", "success", "warning", "danger", "accent"], allowed_labels?: list[str] (<= 32)}` -> value `str` (`1..64` chars; arbitrary CSS/hex colors in metadata or value are rejected).
     4. `markdown_snippet`: `{format: "markdown_snippet", max_chars: int = 2000 (1..2000)}` -> value `str` passed through `KB-P2-13` canonical Markdown normalizer with images and raw HTML tags stripped.
     5. `url`: `{format: "url", allowed_schemes: tuple[Literal["https", "http"], ...] = ("https",), allowed_host_suffixes?: list[str]}` -> value `str` parsed by `urllib.parse.urlsplit`; rejects `javascript:`, `data:`, `vbscript:`, `file:`, `blob:`, embedded credentials, and non-matching host suffixes.
     6. `json_table`: `{format: "json_table", columns: list[{key: str, label: str}] (1..10), max_rows: int = 50 (1..50)}` -> value `list[dict[str, str | int | float | bool | None]]` (cells coerced to plain scalars, nested objects/HTML rejected, capped at `50` rows x `10` columns).
     7. `severity_pill`: `{format: "severity_pill"}` -> value `{level: Literal["low", "medium", "high", "critical"], score?: float (0.0..10.0), label?: str (<= 32)}`.
4. **Canonical Manifest Hash (`compute_field_manifest_sha256`):**
   - Exact S13.2 binding: `SHA256(canonical_json({"script_source": ..., "output_format": ..., "output_format_metadata": ..., "tier": ..., "target_scope": ..., "credential_mode": ..., "egress_allowlist": sorted(...)}))` using UTF-8 `sort_keys=True, separators=(",", ":")`.
   - On `PATCH`, if `script_source` or `output_format` or `output_format_metadata` changes, `script_version` increments atomically (`script_version + 1`) and `manifest_sha256` is recomputed.
   - `egress_allowlist` validation: each entry must match `^/api/v1/[A-Za-z0-9/_*{}-]{1,120}$` with no `..`, `?`, `#`, or whitespace.
5. **REST Endpoints (`kanban/api/v1/custom_fields.py`):**
   - `GET /api/v1/projects/{project}/custom-fields`: returns definitions for callers with `VIEW` on `{project}` (`404` otherwise); omits `script_source` for non-admin callers; includes `manifest_sha256` hex when caller holds `PROJECT_ADMIN` or `SERVER_ADMIN`.
   - `POST /api/v1/projects/{project}/custom-fields` and `PATCH|DELETE /api/v1/projects/{project}/custom-fields/{field_id}`: require `PROJECT_ADMIN` (or `SERVER_ADMIN`) + CSRF; return `404` to non-admins without project admin visibility (`403` only where appropriate per KB-P2-01), `403 AAL2_REQUIRED` if session `aal_level < 2`, `422 OUTPUT_FORMAT_INVALID` on schema violation.
   - Writes emit `CUSTOM_FIELD_CREATED`, `CUSTOM_FIELD_UPDATED`, `CUSTOM_FIELD_DELETED` rows to `activity_records`.

### Mandatory Feature Unit Tests
- **Test File(s):**
  - `database/tests/test_custom_fields_rls.py` (clean-DB `SAVEPOINT` harness from `KB-P0-05`)
  - `kanban/tests/custom_fields/test_output_formats.py`
  - `kanban/tests/custom_fields/test_custom_fields_api.py`
- **Required Test Cases:**
  1. Positive: `PROJECT_ADMIN` with `aal_level=2` creates definitions for all 7 output formats (`text`, `number`, `badge`, `markdown_snippet`, `url`, `json_table`, `severity_pill`); `manifest_sha256` is 32 bytes (64 hex chars) and `script_version == 1`.
  2. Security (RLS `WITH CHECK` admin-only): direct SQL `INSERT` and `UPDATE` on `custom_field_definitions` executed under `kanban_app` with `MEMBER`, `VIEWER`, and `GUEST` principals fail with PostgreSQL RLS violation; `PROJECT_ADMIN` with `app.aal_level = '1'` also fails `WITH CHECK`.
  3. Security (no raw HTML / CSS / URI injection): `output_format="html"` rejected (`422`); `badge` with `color_token="#ff0000;background:url(x)"` rejected; `url` output value `"javascript:alert(1)"` and `"data:text/html,<script>"` rejected; `markdown_snippet` value `"<script>alert(1)</script><img src=x onerror=alert(1)>**ok**"` strips `<script>`, `<img>`, and `onerror`.
  4. Security (cache isolation RLS): `custom_field_values` row inserted for User A's `user_access_hash` is invisible (`0` rows) when queried under User B's RLS session.
  5. Security (anti-enumeration & source secrecy): `MEMBER` calling `GET /api/v1/projects/{project}/custom-fields` receives field metadata without `script_source`; `MEMBER` calling `POST`/`PATCH`/`DELETE` cannot mutate definitions; cross-workspace admin gets `404`.
  6. Boundary: `script_source` of `131,073` bytes rejected; `json_table` with `11` columns or `51` rows rejected; `number` value ` float("nan")` / `float("inf")` rejected; `egress_allowlist` entry `"/api/v1/../admin"` or `"https://evil.com"` rejected; editing 1 byte of `script_source` increments `script_version` to `2` and changes `manifest_sha256`.
  7. Schema parity: committed `output-format-metadata-v1.json` equals live Pydantic JSON Schema export.
- **Coverage:** `>= 95%` line + branch across `kanban.custom_fields`, `kanban.api.v1.custom_fields`, and `database.models.custom_field`.
