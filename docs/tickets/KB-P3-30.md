### User Story
As a **frontend implementer building every later `kanban/web` screen**, I need **a single, exact implementation of the S6.1 breathable whitespace tokens plus light/dark semantic colour variables, self-hosted Inter / JetBrains Mono variable fonts, base typography and a visual token story page** so that **all later components consume one source of spacing truth, never drift into a cramped high-density layout, and render under the strict `style-src 'self'; font-src 'self'` CSP with zero network font fetches**.

**Requirement Traceability:** `S6.1`, `S5.3 item 3` (semantic vars `--bg-surface`, `--fg-primary`, `--border-strong`, `--accent-primary` consumed by the Mermaid worker), `S5.4` (CSP `font-src 'self'`, `style-src 'self'`), `S8.1 item 2` (6 sticky palette names), requirements `#9`, `#15` | **Dependencies:** `KB-P0-03`

2. **`tokens.css` (exact S6.1 block, no additions, no edits):** Copy the S6.1 `:root` block verbatim including comments:
   ```css
   :root {
     --font-sans: 'Inter Variable', -apple-system, BlinkMacSystemFont, sans-serif;
     --font-mono: 'JetBrains Mono Variable', ui-monospace, monospace;
     --text-body: 0.9375rem;
     --leading-prose: 1.73;
     --sidebar-w: 256px;
     --topbar-h: 52px;
     --board-canvas-pad: 24px 28px;
     --board-col-w: 324px;
     --board-col-gap: 20px;
     --card-pad: 16px 18px;
     --card-gap: 12px;
     --list-row-h: 46px;
     --drawer-w: min(960px, 68vw);
     --prose-pad: 32px 40px;
     --prop-row-h: 38px;
     --section-gap: 32px;
   }
   ```
   A unit test parses this file and asserts each of the 16 names maps to exactly the value above (string compare after whitespace trim). Any other custom property in `tokens.css` fails the test.
3. **`spacing.css` (supplemental scale, used only where S6.1 has no token):** `--space-1: 4px; --space-2: 8px; --space-3: 12px; --space-4: 16px; --space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px; --space-12: 48px; --radius-sm: 4px; --radius-md: 6px; --radius-lg: 10px; --emoji-pill: 24px; --hint-max-w: 360px; --hint-pad: 12px 14px; --focus-ring-w: 2px; --tap-min: 44px;`. No value below `4px` except `0`. No "compact" / "dense" variants of any token anywhere in the repo (test greps `src/styles` for `dense|compact` and fails on a hit).
4. **`theme.css` semantic colours:** Define in `:root` (light) and override in `[data-theme="dark"]` and in `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } }`: `--bg-canvas`, `--bg-surface`, `--bg-surface-raised`, `--bg-hover`, `--fg-primary`, `--fg-secondary`, `--fg-muted`, `--border-subtle`, `--border-strong`, `--accent-primary`, `--accent-primary-fg`, `--focus-ring`, `--warn-bg`, `--warn-fg`, `--danger-bg`, `--danger-fg`, `--ok-fg`, `--sticky-amber`, `--sticky-mint`, `--sticky-sky`, `--sticky-lavender`, `--sticky-coral`, `--sticky-slate`. Light palette follows the Plane reference: white surface, near-white canvas (`#f7f8fa`-class), 1px `--border-subtle` hairlines, blue accent. Contrast rule (enforced by test): `--fg-primary` on `--bg-surface` `>= 7:1`, `--fg-secondary` on `--bg-surface` `>= 4.5:1`, `--fg-muted` on `--bg-surface` `>= 4.5:1`, `--accent-primary-fg` on `--accent-primary` `>= 4.5:1`, `--warn-fg` on `--warn-bg` `>= 4.5:1`, `--danger-fg` on `--danger-bg` `>= 4.5:1`, in BOTH themes. Colours are hex literals only (test computes WCAG relative luminance from the hex values parsed out of `theme.css`).
5. **`fonts.css`:** Two `@font-face` rules: `font-family: 'Inter Variable'; src: url('/fonts/InterVariable.woff2') format('woff2'); font-weight: 100 900; font-display: swap;` and the same for `'JetBrains Mono Variable'` (`font-weight: 100 800`). Zero `http:`/`https:` URLs in any CSS file (test). Vendored files: record upstream release tag and SHA-256 of each `.woff2` in `docs/qa/<TICKET_ID>/dependency-evaluation.md`.
6. **`base.css`:** `html { font-size: 100%; } body { margin: 0; background: var(--bg-canvas); color: var(--fg-primary); font-family: var(--font-sans); font-size: var(--text-body); line-height: var(--leading-prose); -webkit-font-smoothing: antialiased; }`; `.mono, kbd, code { font-family: var(--font-mono); font-variant-numeric: tabular-nums; }`; `:focus-visible { outline: var(--focus-ring-w) solid var(--focus-ring); outline-offset: 2px; }`; `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }`; heading scale `h1 1.5rem/1.35`, `h2 1.25rem/1.4`, `h3 1.0625rem/1.45` with `margin: 0 0 var(--space-3)`.
7. **`breakpoints.ts`:** `export const BP = { mobileMax: 767, tabletMax: 1279 } as const; export type Breakpoint = 'mobile' | 'tablet' | 'desktop'; export function useBreakpoint(): Breakpoint` using `window.matchMedia('(max-width: 767px)')` and `('(max-width: 1279px)')` with `change` listeners removed on unmount. Responsive rule documented in a TSDoc block: S6.1 card padding, row heights and gaps are NEVER reduced at any breakpoint; the only mobile exception is board canvas padding `16px` (applied by KB-P3-37).
8. **`ThemeProvider` / `useTheme()`:** State `'light' | 'dark' | 'system'`, persisted in `localStorage['kb.theme']`; any stored value outside the 3 literals is ignored and reset to `'system'` (hostile storage tolerance). Applies `document.documentElement.dataset.theme = 'light' | 'dark'` or removes the attribute for `'system'`. Exposes `resolvedTheme` (`'light' | 'dark'`) via `matchMedia('(prefers-color-scheme: dark)')`. No inline `<style>` injection (CSP `style-src 'self'`).
9. **`TokenStory.tsx` (`/__dev/tokens`):** Renders: (a) a table listing every S6.1 token name, its raw value and its computed px value from `getComputedStyle(document.documentElement)`; (b) a spacing ruler showing a sample card using `--card-pad`, two stacked cards separated by `--card-gap`, two lanes `--board-col-w` wide separated by `--board-col-gap`, a `--list-row-h` row, a `--prop-row-h` row; (c) colour swatches for every semantic var with its contrast ratio printed; (d) a prose paragraph at `--text-body`/`--leading-prose`; (e) a mono issue key `KAN-142`; (f) a 3-way theme switcher (`Light` / `Dark` / `System`) as a `role="radiogroup"` with arrow-key navigation. Every element carries `data-testid` used by the e2e spec.
