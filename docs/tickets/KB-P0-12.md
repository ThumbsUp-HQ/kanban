### User Story
As an **AI/LLM systems engineer**, I need **a vendor-neutral `LLMProvider` protocol, typed request/response and error models, a JSON-Schema-validated YAML cassette loader, `FixtureLLMProvider`, and `FixtureCLIRunner`** so that **all downstream AI providers, Sparkle FIM pipelines, and CLI/workflow gates run deterministically in `< 10s` under `--disable-socket` with zero external network calls**.

**Requirement Traceability:** `S10.1` (`LLMProvider` protocol: `stream_complete`, `generate_structured`, `embed_batch`, `health_probe`; `FixtureLLMProvider`), `S15.2` (YAML cassettes, `tool_script`, `simulated_ttft_ms`, `final_verdict`, `FixtureCLIRunner`, fault injection for `429`/timeout/malformed stdout), `S2.5` (permissive supply chain), Requirement `#2` | **Dependencies:** `KB-P0-01`

2. **Typed Error Hierarchy (`agent/providers/errors.py`, re-exported from `agent/providers/base.py`):**
   - `class ProviderError(Exception)` with `code: str` (`^[A-Z][A-Z0-9_]{2,63}$`) and `message: str` (redacting any bearer/key substrings).
   - Subclasses: `ProviderHTTPError(ProviderError)` (adds `status: int`, `retry_after_s: float | None = None`), `ProviderTimeout(ProviderError)`, `ProviderUnavailable(ProviderError)`, `AllProvidersUnavailable(ProviderUnavailable)`, `ProviderProtocolError(ProviderError)`, `ProviderSchemaError(ProviderError)`, `ProviderSafetyBlock(ProviderError)`, `ProviderRefusal(ProviderError)`, `ProviderPolicyError(ProviderError)`, `EgressDenied(ProviderPolicyError)`.

3. **Vendor-Neutral Protocol & DTOs (`agent/providers/base.py`, Pydantic v2 `ConfigDict(frozen=True, extra="forbid")`):**
   - `CompletionRequest`: `model: str`, `prompt: str`, `suffix: str | None = None`, `system_prompt: str | None = None`, `temperature: float = 0.15` (`0.0..2.0`), `max_output_tokens: int = 256` (`1..32768`), `ttft_deadline_ms: int | None = None` (`1..60000`), `metadata: dict[str, str] = {}`.
   - `StreamChunk`: `delta: str`, `index: int` (`>= 0`), `finish_reason: Literal["stop", "length", "tool_calls"] | None = None`, `ttft_ms: float | None = None`, `prompt_tokens: int | None = None`, `completion_tokens: int | None = None`.
   - `ToolCallStep`: `tool: str`, `args: dict[str, Any]`, `result: dict[str, Any] | str | None = None`.
   - `StructuredRequest(Generic[TModel])`: `model: str`, `prompt: str`, `response_model: type[TModel]`, `system_prompt: str | None = None`, `temperature: float = 0.0`, `max_output_tokens: int = 1024`, `ttft_deadline_ms: int | None = None`, `metadata: dict[str, str] = {}`.
   - `StructuredResponse(Generic[TModel])`: `parsed: TModel`, `raw_json: str`, `tool_trace: tuple[ToolCallStep, ...] = ()`, `ttft_ms: float`, `total_latency_ms: float`, `prompt_tokens: int = 0`, `completion_tokens: int = 0`.
   - `EmbedBatchRequest`: `model: str`, `inputs: tuple[str, ...]` (validated `1 <= len(inputs) <= 64`, each `1 <= len(s) <= 8192` chars; violation raises `ValueError` before I/O).
   - `HealthStatus`: `ok: bool`, `latency_ms: float`, `models: tuple[str, ...] = ()`, `detail: str | None = None`.
   - `@runtime_checkable class LLMProvider(Protocol)`: `residency_tier: str` property plus `stream_complete(req) -> AsyncIterator[StreamChunk]`, `async generate_structured(req) -> StructuredResponse[TModel]`, `async embed_batch(req) -> list[list[float]]`, `async health_probe() -> HealthStatus`.
   - CLI runner contract: `CLIRunRequest(argv: tuple[str, ...], stdin_bytes: bytes, timeout_s: float = 30.0, env_keys: tuple[str, ...] = ())` (rejects empty `argv` or `/bin/sh` / `bash -c` wrappers with `ValueError`), `CLIRunResult(stdout: bytes, stderr: bytes, exit_code: int, duration_ms: float)`, and `@runtime_checkable class CLIRunner(Protocol)` (`async def run(self, req: CLIRunRequest) -> CLIRunResult`).

4. **Cassette Schema & Deterministic Fixtures (`agent/testing/cassette.schema.json`, `agent/testing/fixtures.py`):**
   - JSON Schema (Draft 2020-12) requiring `cassette_version: 1`, `matcher` (`agent_slug`, `provider`, `model`, `transition_to`, `prompt_contains: list[str]`, `stdin_contains: list[str]`, `argv_prefix: list[str]`), optional `tool_script` (`list[{call: {tool, args}, returns?}]`), `simulated_ttft_ms` (`>= 0`, default `5.0`), `usage` (`{prompt_tokens, completion_tokens}`), and outcome/fault blocks (`stream_chunks: list[str]`, `final_verdict: object`, `structured_output: object`, `embeddings: list[list[float]] | {dimension: int, seed: int}`, `cli_result: {stdout: str, stderr: str, exit_code: int, duration_ms: number}`, `fault: {kind: enum[http_429, http_500, http_503, timeout, ttft_sla_breach, unavailable, schema_error, safety_block, refusal, malformed_stdout, stream_error_after_chunk], retry_after_s?: number, after_chunks?: integer}`).
   - `load_cassette(path: Path) -> Cassette`: rejects files `> 1_048_576` bytes (`CassetteValidationError`), parses exclusively via `yaml.safe_load` (`yaml.load` / unsafe tags forbidden), validates against `cassette.schema.json` (`Draft202012Validator`), raises `CassetteValidationError` on invalid schema.
   - `FixtureLLMProvider`: `residency_tier = "fixture"`; matches requests against loaded cassettes in order (all specified `matcher` predicates must match; unmatched raises `CassetteMismatchError`); records every invocation in `call_log`; replays `stream_chunks`, validates `final_verdict` / `structured_output` into `req.response_model` (raising `ProviderSchemaError` on mismatch), generates deterministic L2-normalized vectors when `embeddings` specifies `{dimension, seed}`, and raises exact `ProviderError` subclasses for `fault.kind` without real wall-clock sleep (injectable `sleep` hook defaulting to no-op).
   - `FixtureCLIRunner`: matches `CLIRunRequest` (`argv_prefix` + `stdin_contains` against UTF-8 decoded `stdin_bytes`), replays `cli_result` or raises `ProviderTimeout` (`fault.kind == "timeout"`) / returns non-JSON garbage stdout (`fault.kind == "malformed_stdout"`), zero `subprocess` calls.
   - Include `tests/fixtures/ai/transition_rls_veto.yaml` matching the exact S15.2 example (`agent_slug: forensic-code-check`, `transition_to: Done`, `prompt_contains: ["KAN-142", "auth_provider_cards"]`, `simulated_ttft_ms: 18`, `decision: reject`).

### Mandatory Feature Unit Tests
- **Test File(s):** `agent/tests/providers/test_base_protocol.py`, `agent/tests/testing/test_fixtures.py`
- **Required Test Cases:**
  1. Positive (stream & structured): `FixtureLLMProvider` replays `echo_stream_ok.yaml` chunk-by-chunk with `ttft_ms` on chunk 0 and `finish_reason="stop"` on the final chunk; replays `transition_rls_veto.yaml` via `generate_structured` returning a validated Pydantic verdict model and populated `tool_trace` of length 2.
  2. Positive (embeddings & CLI): `embed_batch` returns deterministic equal-dimension L2-normalized vectors; `FixtureCLIRunner` replays `cli_agy_approve_ok.yaml` matching `argv_prefix: ["/usr/local/bin/agy", "-p"]` and `stdin_contains`.
  3. Fault injection: cassettes with `http_429` (`retry_after_s: 30`), `http_503`, `timeout`, `ttft_sla_breach` (when `simulated_ttft_ms > req.ttft_deadline_ms`), `safety_block`, `refusal`, `schema_error`, and `stream_error_after_chunk` raise the exact typed `ProviderError` subclass; `fault_malformed_stdout.yaml` returns unparseable stdout bytes via `FixtureCLIRunner`.
  4. Negative/security: YAML containing `!!python/object/apply:os.system` is rejected by `yaml.safe_load` (`CassetteValidationError`); cassette `> 1 MiB` or `cassette_version: 2` or unknown field raises `CassetteValidationError`; `CLIRunRequest(argv=("/bin/sh", "-c", "id"), stdin_bytes=b"")` raises `ValueError`.
  5. Negative: unmatched prompt or `stdin_bytes` raises `CassetteMismatchError`; `EmbedBatchRequest` with `0` or `65` inputs or an `8193`-char input raises `ValueError`.
  6. Boundary: `isinstance(FixtureLLMProvider([]), LLMProvider)` and `isinstance(FixtureCLIRunner([]), CLIRunner)` are `True`; all tests pass with `--disable-socket --allow-unix-socket` and zero real sleep (`< 0.5s` total runtime).
