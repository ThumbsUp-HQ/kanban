### User Story
As a **maintainer enforcing the zero-warning gate**, I need **`ruff` (strict rule set), `mypy --strict` across all four Python modules, a `pre-commit` configuration, a repo-wide em/en-dash checker, and a single `make check` entry point** so that **every commit is linted, type-checked, and style-checked locally before CI runs**.

**Requirement Traceability:** `S15.4` gate 2 (`ruff --strict`, `mypy --strict`, zero warnings), AGENTS.md writing style rule (plain ASCII hyphens) | **Dependencies:** `KB-P0-01`

### Scoped Technical Actions
1. **Target Files:** `pyproject.toml` (root: `[tool.ruff]`, `[tool.mypy]`, dev group additions), `uv.lock`, `.pre-commit-config.yaml`, `Makefile`, `scripts/__init__.py`, `scripts/check_no_dashes.py`, `scripts/tests/__init__.py`, `scripts/tests/test_check_no_dashes.py`
2. **Ruff config (root `pyproject.toml`):**
   ```toml
   [tool.ruff]
   target-version = "py312"
   line-length = 100
   [tool.ruff.lint]
   select = ["ALL"]
   ignore = [
     "D203",   # conflicts with D211 (no blank line before class docstring)
     "D213",   # conflicts with D212 (multi-line summary first line)
     "COM812", # conflicts with ruff formatter
     "ISC001", # conflicts with ruff formatter
   ]
   [tool.ruff.lint.per-file-ignores]
   "**/tests/**" = ["S101", "PLR2004"]  # assert and magic values are idiomatic in pytest
   ```
   Every entry in `ignore` and `per-file-ignores` MUST carry an inline `#` justification comment. No `# noqa` without a rule code and trailing reason. `ruff format` is the formatter.
3. **Mypy config:**
   ```toml
   [tool.mypy]
   python_version = "3.12"
   strict = true
   warn_unreachable = true
   enable_error_code = ["ignore-without-code", "redundant-expr", "truthy-bool"]
   packages = ["database", "kanban", "mcp", "agent", "scripts"]
   ```
   `# type: ignore` is allowed only with an error code and a trailing reason comment.
4. **Dash checker `scripts/check_no_dashes.py`:** `main(argv: Sequence[str] | None = None) -> int`. Accepts file paths (pre-commit passes staged files) or, with `--all`, walks `docs/` and `.agents/` recursively for `*.md`, `*.yaml`, `*.yml`, `*.toml`, `*.txt`. Reports every occurrence of `U+2014` (em-dash) and `U+2013` (en-dash) as `path:line:col: forbidden dash U+2014` to stdout and returns `1` if any hit, else `0`. Files larger than `5 MiB` are skipped with a stderr notice. Files that fail UTF-8 decoding are reported as `path: not valid UTF-8` and return `1` (fail closed). Uses only the standard library.
5. **`.pre-commit-config.yaml`:** hooks (each `rev:` pinned to an exact tag, `repo: local` hooks run via `uv run` so versions come from `uv.lock`):
   - `ruff check --fix`, `ruff format`
   - `mypy` (local, `pass_filenames: false`, `entry: uv run mypy`)
   - `end-of-file-fixer`, `trailing-whitespace`, `check-merge-conflict`, `check-added-large-files` (`--maxkb=1024`) from `pre-commit/pre-commit-hooks`
   - `no-unicode-dashes` (local, `entry: uv run python -m scripts.check_no_dashes`, `files: ^(docs|\.agents)/`)
6. **`Makefile` target `check`:** runs, in order, failing on first error: `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`, `uv run lint-imports`, `uv run python -m scripts.check_no_dashes --all`. Also targets `fmt` (`ruff format .` + `ruff check --fix .`) and `.PHONY` declarations.
7. **Remediate existing tree:** Fix every ruff/mypy finding in the KB-P0-01 code and every em/en-dash in `docs/` and `.agents/` (the existing files `docs/ARCHITECTURE_AND_PRODUCT_SPEC.md`, `.agents/**` may contain hits; replace with `-`, `:`, `,` or parentheses without changing meaning).

### Mandatory Feature Unit Tests
- **Test File(s):** `scripts/tests/test_check_no_dashes.py`
- **Required Test Cases:**
  1. Positive: a `tmp_path` file containing only ASCII hyphens returns exit `0` and empty stdout.
  2. Negative: a file containing `U+2014` on line 3 column 7 returns `1` and stdout contains `:3:7:` and `U+2014`; same for `U+2013`.
  3. Negative/security: a file with invalid UTF-8 bytes (`b"\xff\xfe"`) returns `1` with `not valid UTF-8`.
  4. Boundary: a file of exactly `5 MiB + 1` bytes is skipped (exit `0`, stderr notice); `--all` mode on a `tmp_path` tree with `docs/a.md` (hit) and `other/b.md` (hit, out of scope) reports only `docs/a.md`.
  5. Boundary: empty argument list without `--all` returns `0`.
