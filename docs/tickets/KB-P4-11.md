### User Story
As a **Project or Server Admin operating via `/mcp/admin`**, I need **`override_ticket_provenance` to perform audited `Created by` overrides, Hard WIP limit overrides, and unarchivals with a mandatory justification, plus `audit_and_purge_object_links` to execute the 6-class Universal Object Graph Auditor, inspect flagged link snapshots, and purge audited entries** so that **provenance corrections and broken-link cleanup are 100% administrable via MCP without raw database access**.

**Requirement Traceability:** Spec S11.4 tools 10-11; S7.2 `8d` (`Created by` override `🔄`), `8p` (unarchive); S6.4 item 3 (Hard WIP override); S12.3 (`audit_object_links()`, `invalid_object_link_audits`, `purge_invalid_object_links()`, 6 invalidity classes); requirements `#8d`, `#12`, `#13j` | **Dependencies:** `KB-P4-09a`, `KB-P3-04`, `KB-P3-09a`, `KB-P3-12`, `KB-P1-16`

### Scoped Technical Actions
1. **Target Files:** `kanban/api/v1/admin/link_auditor.py`, `kanban/api/v1/schemas/link_auditor.py`, `kanban/services/link_auditor_admin.py`, `kanban/api/v1/issue_archive.py` (accept optional `reason` on `unarchive` and require it when called via admin provenance override), `mcp/surfaces/admin/override_ticket_provenance.py`, `mcp/surfaces/admin/audit_and_purge_object_links.py`, `mcp/surfaces/admin/__init__.py` (register tools 10 & 11), `mcp/auth.py` (`SCOPE_REQUIREMENTS`).
2. **Admin Link Auditor REST Endpoints (`kanban/api/v1/admin/link_auditor.py`):**
   - Required because `mcp-server` holds zero `data_net` / Postgres credentials (`S2.4`):

     | Method + Path | Auth / Role | Success | Errors |
     | :-- | :-- | :-- | :-- |
     | `POST /api/v1/admin/object-links:audit` | Workspace/Server `ADMIN`, AAL2 | `200` scan report | `403`, `403 AAL2_REQUIRED` |
     | `GET /api/v1/admin/object-links/audits?reason_code=&status=unpurged&limit=50&cursor=` | Workspace/Server `ADMIN` | `200` paginated snapshots | `403`, `422` |
     | `POST /api/v1/admin/object-links:purge` | `SERVER_ADMIN` or Workspace `ADMIN`, AAL2 | `200` `{purged_count, activity_ids}` | `403`, `409 LINK_NOT_FLAGGED`, `422 REASON_REQUIRED` |

   - `POST .../object-links:audit` invokes `SELECT * FROM audit_object_links(:workspace_id)` (`KB-P1-15`) inside the admin RLS session and returns counts grouped across all 6 `S12.3` reason classes (`DANGLING_SOURCE` / `DANGLING_TARGET`, `SOFT_DELETED_ENDPOINT`, `ARCHIVED_POLICY_VIOLATION`, `TYPE_MATRIX_VIOLATION`, `CROSS_WORKSPACE_LEAK`, `PERMISSION_SEVERED`).
   - `POST .../object-links:purge` requires `{"audit_ids": ["..."], "reason": "Purge severed links after Q4 project split"}` (`audit_ids` `1..200`, `reason` `btrim` `10..500` chars); delegates to `purge_invalid_object_links(p_audit_ids, p_actor_id, p_reason)` (`KB-P1-16`), mapping attempts to purge `ACTIVE` or non-existent audit IDs to `409 LINK_NOT_FLAGGED`.
3. **MCP Tool 10: `override_ticket_provenance` (`mcp/surfaces/admin/override_ticket_provenance.py`):**
   - Input schema (`additionalProperties: false`):
     ```yaml
     action: {enum: [override_creator, override_hard_wip_move, unarchive_issue, help]} # required
     issue: {type: string}             # "KAN-142" | uuid (required except help)
     new_creator: {type: string}       # "@maya" | uuid (required for override_creator)
     target_state: {type: string}      # state name | uuid (required for override_hard_wip_move)
     after_issue: {type: string}       # optional rank anchor for override_hard_wip_move
     before_issue: {type: string}      # optional rank anchor for override_hard_wip_move
     reason: {type: string, minLength: 10, maxLength: 500} # required except help
     ```
   - Scope: `admin:write` + caller AAL2 (`AAL2_REQUIRED` otherwise) + `PROJECT_ADMIN` or `SERVER_ADMIN` on the issue's project.
   - Routing:
     - `override_creator` -> `PATCH /api/v1/issues/{id}/created-by` (`KB-P3-04`), returning `summary` YAML:
       ```yaml
       status: creator_overridden
       issue: KAN-142
       original_created_by: "@bot-import"
       created_by: "@maya"
       reason: Imported from Plane under bot account
       ```
     - `override_hard_wip_move` -> `POST /api/v1/issues/{id}/move` (`KB-P3-12`) passing `wip_override_reason=reason`, returning `{status: wip_overridden_moved, issue, state, resulting_count, hard_limit}`.
     - `unarchive_issue` -> `POST /api/v1/issues/{id}/unarchive` (`KB-P3-09a`) passing `{"reason": reason}` so `ISSUE_UNARCHIVED` records `{reason, admin_override: true}`.
4. **MCP Tool 11: `audit_and_purge_object_links` (`mcp/surfaces/admin/audit_and_purge_object_links.py`):**
   - Input schema (`additionalProperties: false`):
     ```yaml
     action: {enum: [run_audit, list_flagged, purge_audited, help]} # required
     reason_filter: {enum: [DANGLING_SOURCE, DANGLING_TARGET, SOFT_DELETED_ENDPOINT, ARCHIVED_POLICY_VIOLATION, TYPE_MATRIX_VIOLATION, CROSS_WORKSPACE_LEAK, PERMISSION_SEVERED]}
     audit_ids: {type: array, items: string, minItems: 1, maxItems: 200} # required for purge_audited
     reason: {type: string, minLength: 10, maxLength: 500}              # required for purge_audited
     lod: {enum: [summary, standard, full], default: summary}
     limit: {type: integer, minimum: 1, maximum: 100, default: 50}
     cursor: {type: string}
     ```
   - Scope binding (`mcp/auth.py`): `list_flagged` -> `admin:read`; `run_audit` -> `admin:write`; `purge_audited` -> `admin:destructive` (`INSUFFICIENT_SCOPE` if key lacks `admin:destructive`).
   - `summary` YAML for `run_audit`:
     ```yaml
     flagged_total: 2
     by_reason: {ARCHIVED_POLICY_VIOLATION: 1, PERMISSION_SEVERED: 1}
     ```
5. **Error codes appended (`mcp/errors.py`):** `LINK_NOT_FLAGGED`, `CREATOR_NOT_ELIGIBLE`, `CREATOR_UNCHANGED`, `NOT_ARCHIVED` (reuses `AAL2_REQUIRED`, `INSUFFICIENT_SCOPE`, `INSUFFICIENT_PERMISSION`, `VALIDATION_FAILED`).

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/tests/api/test_admin_link_auditor.py`, `mcp/tests/admin/test_override_ticket_provenance.py`, `mcp/tests/admin/test_audit_and_purge_links.py`
- **Required Test Cases:**
  1. Positive Tool 10 (all 3 actions): via `/mcp/admin`, AAL2 admin runs `override_creator` (`KAN-142` -> `@maya`, `original_created_by` preserved, `CREATOR_OVERRIDDEN` row written), `override_hard_wip_move` into a column at `5/5` Hard WIP (`WIP_HARD_LIMIT_OVERRIDDEN` row written), and `unarchive_issue` on an archived Done ticket (`ISSUE_UNARCHIVED` with `reason` written).
  2. Positive Tool 11 (audit -> inspect -> purge): seed 1 `ARCHIVED_POLICY_VIOLATION` link (`BLOCKS` from archived issue) and 1 `PERMISSION_SEVERED` link; `run_audit` flags both (`FLAGGED_INVALID`); `list_flagged` returns snapshot keys and audit UUIDs; `purge_audited` with `admin:destructive` scope deletes the 2 flagged links and writes `INVALID_OBJECT_LINK_PURGED` activity rows while leaving `ACTIVE` links untouched.
  3. Security & scope separation: `admin:write`-only key calling `purge_audited` -> `INSUFFICIENT_SCOPE`; AAL1 token calling `override_creator` or `purge_audited` -> `AAL2_REQUIRED`; non-admin of project calling `override_creator` -> `NOT_FOUND` / `INSUFFICIENT_PERMISSION`; `kb_agt_` key on `/mcp/admin` -> `403 SURFACE_KEY_MISMATCH`.
  4. Active-link protection & boundaries: passing a fabricated UUID or an `ACTIVE` link ID to `purge_audited` returns `LINK_NOT_FLAGGED` with `0` rows deleted; `reason` of `9` chars -> `VALIDATION_FAILED`; `audit_ids` of `201` items -> `VALIDATION_FAILED`; `unarchive_issue` on a non-archived issue -> `NOT_ARCHIVED`.
