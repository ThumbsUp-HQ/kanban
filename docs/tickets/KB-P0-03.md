### User Story
As a **frontend engineer**, I need **a locked `pnpm` workspace containing a strict-TypeScript React 19 + Vite SPA at `kanban/web` with ESLint, `vitest` coverage thresholds of `95%`, and a production build that emits Brotli/gzip siblings plus an SRI manifest** so that **all Phase 3 UI work starts from a reproducible, CSP-compatible build with enforced coverage**.

**Requirement Traceability:** `S2.1` (static React 19 / TypeScript SPA in `kanban/web/`), `S2.5` (React 19, Vite; runtime CSS-in-JS banned), `S15.1` item 4 (`vitest` thresholds `95/95/95/95`), Requirement `#3`, `#9` | **Dependencies:** `KB-P0-01`

### Scoped Technical Actions
1. **Target Files:**
   - Root: `package.json` (private, `"packageManager": "pnpm@<exact>"`, `engines.node: ">=22 <23"`), `pnpm-workspace.yaml` (`packages: ["kanban/web"]`), `pnpm-lock.yaml`, `.npmrc` (`engine-strict=true`, `ignore-scripts=true`, `save-exact=true`)
   - `kanban/web/package.json`, `kanban/web/tsconfig.json`, `kanban/web/tsconfig.node.json`, `kanban/web/eslint.config.js`, `kanban/web/vite.config.ts`, `kanban/web/vitest.config.ts`, `kanban/web/index.html`
   - `kanban/web/build/precompress.ts` (local Vite plugin, zero third-party deps)
   - `kanban/web/src/main.tsx`, `kanban/web/src/App.tsx`, `kanban/web/src/App.css`
   - `kanban/web/src/App.test.tsx`, `kanban/web/build/precompress.test.ts`
2. **`kanban/web/package.json` scripts (exact names):** `dev` (`vite`), `build` (`tsc -b && vite build`), `preview` (`vite preview --port 4173 --strictPort`), `typecheck` (`tsc -b --noEmit`), `lint` (`eslint . --max-warnings 0`), `test:unit` (`vitest run`). All dependency versions exact (no `^`/`~`).
3. **TypeScript strict:** `tsconfig.json` sets `"strict": true`, `"noUncheckedIndexedAccess": true`, `"exactOptionalPropertyTypes": true`, `"noImplicitOverride": true`, `"noFallthroughCasesInSwitch": true`, `"verbatimModuleSyntax": true`, `"jsx": "react-jsx"`, `"target": "ES2022"`.
4. **ESLint (flat config):** `typescript-eslint` `strictTypeChecked` + `stylisticTypeChecked`, `eslint-plugin-react-hooks` recommended; rule `no-restricted-imports` banning `styled-components`, `@emotion/*`, `next`, `@tiptap-pro/*` (S2.5 banned list).
5. **Vitest:** `environment: "jsdom"`, coverage provider `v8`, `include: ["src/**/*.{ts,tsx}", "build/**/*.ts"]`, `exclude: ["src/main.tsx", "**/*.test.*"]`, `thresholds: { lines: 95, functions: 95, branches: 95, statements: 95 }`.
6. **App skeleton:** `App.tsx` exports `App(): JSX.Element` rendering `<main data-testid="app-root"><h1>Kanban</h1></main>`. Styles only via static `.css` files imported in modules (no inline `style=` attributes, no runtime style injection) so the S5.4 CSP `style-src 'self'` holds. `index.html` contains no inline `<script>` or `<style>` blocks.
7. **`build/precompress.ts` Vite plugin `precompress(): Plugin`:** In `closeBundle`, for every emitted file in `dist/` with extension in `.js`, `.css`, `.html`, `.svg`, `.json`, `.wasm`, `.txt` and size `>= 1024` bytes, write `<file>.br` via `node:zlib` `brotliCompressSync` (`BROTLI_PARAM_QUALITY = 11`) and `<file>.gz` via `gzipSync` (`level: 9`). Write `dist/sri-manifest.json` mapping each original asset path (POSIX, relative to `dist/`) to `sha384-<base64>` computed with `node:crypto`. Exports pure helpers `shouldCompress(path: string, size: number): boolean` and `sriHash(bytes: Uint8Array): string` for unit testing. Path traversal: helpers reject any path containing `..` segments.
8. **Vite config:** `build.outDir = "dist"`, `build.assetsDir = "assets"`, hashed filenames (default), `build.sourcemap = false`, `plugins: [react(), precompress()]`.
9. **Supply chain:** `pnpm install --frozen-lockfile --ignore-scripts` succeeds; zero packages with `postinstall` are required to run.

### Mandatory Feature Unit Tests
- **Test File(s):** `kanban/web/src/App.test.tsx`, `kanban/web/build/precompress.test.ts`
- **Required Test Cases:**
  1. Positive: `App` renders and `getByTestId("app-root")` contains heading text `Kanban`.
  2. Positive: `sriHash(new TextEncoder().encode("abc"))` equals `sha384-ywB1P0WjXou1oD1pmsZQBycsMqsO3tFjGotgWkP/W+2AhgcroefMI1i67KE0yCWn`.
  3. Negative/security: `shouldCompress("../etc/passwd.js", 4096)` returns `false` (traversal rejected); `shouldCompress("assets/a.png", 4096)` returns `false` (extension not allowlisted).
  4. Boundary: `shouldCompress("assets/a.js", 1023)` is `false`; `shouldCompress("assets/a.js", 1024)` is `true`.
  5. Positive: running the plugin's `closeBundle` against a temp directory with one `2048`-byte `.js` file produces `.br` and `.gz` siblings that decompress to the original bytes, and `sri-manifest.json` with one entry.
