### User Story
As a **homelab or evaluation operator running `docker run -p 8080:8080 kanban:latest`**, I need **clicking the topbar `⚠️` Standalone badge to open a status panel showing live volume persistence (`overlayfs` ephemeral warning vs mounted volume), Tier B `nsjail` sandbox availability, an encrypted backup download trigger, and a 1-click `docker-compose.yml` production export guide** so that **I never lose data to ephemeral container storage and can promote cleanly to the hardened multi-container stack**.

**Requirement Traceability:** `S2.2 item 1` (`/proc/mounts` `overlayfs` warning `Mount -v kanban_data:/var/lib/kanban/data`), `S2.2 item 5` (`⚠️` topbar badge click panel: volume status, encrypted backup, & 1-click `docker-compose.yml` export; `SANDBOX_UNAVAILABLE_IN_STANDALONE` disclosure), `S2.4` (production `docker-compose.yml` promotion path), `S6.2` (`⚠️` `warning` `<EmojiHint>`), `S3.5` (Standalone Misconfiguration row) | **Dependencies:** `KB-P3-34` (`HeaderPills` `openPanel('standalone')`, `useSystemStatus`), `KB-P0-09` (`/run/kanban/standalone_status.json`), `KB-P2-05` (AAL2 admin session check)

### Scoped Technical Actions
1. **Target Files:**
   - `kanban/api/v1/system_status.py` (FastAPI router serving `GET /api/v1/system/status`, `POST /api/v1/admin/standalone/backup`, and `GET /api/v1/admin/standalone/compose-export`)
   - `kanban/standalone/export_service.py` (reads `KB_STANDALONE_STATUS_PATH` from `KB-P0-09`, streams AES-256-GCM encrypted `pg_dump -Fc` archive, and builds secret-free `docker-compose.yml` + migration runbook payload)
   - `kanban/tests/api/test_system_status.py`
   - `kanban/web/src/features/standalone/StandaloneStatusPanel.tsx` + `StandaloneStatusPanel.css`
   - `kanban/web/src/features/standalone/ComposeExportTab.tsx` (1-click `docker-compose.yml` download + copyable `pg_restore` promotion checklist)
   - `kanban/web/e2e/fixtures/standalone-detail-ephemeral.json`, `kanban/web/e2e/fixtures/standalone-detail-persistent.json`, `kanban/web/e2e/fixtures/compose-export-sample.json`
   - Edits: `kanban/app.py` (mount `system_status` router), `kanban/web/src/app/AppShell.tsx` (register `'standalone'` panel via `registerShellPanel('standalone', StandaloneStatusPanel)`)
2. **Backend Status, Encrypted Backup & Compose Export API (`system_status.py`, `export_service.py`):**
   - `GET /api/v1/system/status` (authenticated user):
     - Reads `/run/kanban/standalone_status.json` (`KB_STANDALONE_STATUS_PATH` from `KB-P0-09`) when present, else reports `deployment_mode: "production_multi_container"`.
     - Returns `{ deployment_mode: "standalone_embedded_pg" | "production_multi_container", persistent_volume: bool, data_mount_point: str | null, data_mount_fstype: str | null, tier_b_sandbox_available: bool, air_gap_mode: bool, local_llm_endpoint_host: str | null, is_server_admin: bool }` (`data_mount_point`, `data_mount_fstype`, and `local_llm_endpoint_host` populated ONLY when caller holds `SERVER_ADMIN`, else `null` to prevent host topology disclosure to regular members).
   - `POST /api/v1/admin/standalone/backup` (`SERVER_ADMIN` + `AAL2` session required; only enabled when `deployment_mode == "standalone_embedded_pg"`, else `409 NOT_STANDALONE_MODE`):
     - Accepts `{ passphrase: str }` (`16..256` chars; never logged) OR `{ use_master_kek: true }`.
     - Invokes `/usr/bin/pg_dump --format=custom --no-password` over direct `execve` (`asyncio.create_subprocess_exec`, zero shell, Unix socket only), encrypts the dump with `AES-256-GCM` (`PBKDF2-HMAC-SHA256` `600,000` iterations + `16`-byte CSPRNG salt when passphrase-derived, or HKDF subkey from `KB_MASTER_KEK_B64`), records `STANDALONE_BACKUP_EXPORTED` in `activity_records`, and streams `application/octet-stream` with `Content-Disposition: attachment; filename="kanban-backup-<UTC-ISO>.kbkp"`.
   - `GET /api/v1/admin/standalone/compose-export` (`SERVER_ADMIN` required):
     - Returns `{ filename: "docker-compose.yml", compose_yaml: str, env_template: str, migration_steps_markdown: str }` generated from the canonical `S2.4` / `KB-P0-11` production template (`edge_net`, `app_net`, `data_net` internal, `sandbox_net` internal, `egress_llm_net`; zero secret values or keyring material ever included).
3. **Frontend Standalone Status Modal/Popover (`StandaloneStatusPanel.tsx`, `ComposeExportTab.tsx`):**
   - Registered via `registerShellPanel('standalone', StandaloneStatusPanel)` (`KB-P3-34` Action 7: activated when clicking/tapping `⚠️` in `HeaderPills`).
   - Renders as a breathable `role="dialog" aria-modal="true" aria-label="Standalone deployment status"` (`width: min(640px, 100vw - 32px)`, inner `padding: var(--space-6)` `24px`, section gap `var(--space-6)` `24px`, full-screen sheet on `<= 767px` mobile; focus trapped; `Escape` closes and returns focus to `⚠️` pill).
   - **Section 1 - Storage & Sandbox Health Cards:**
     - When `persistent_volume === false`: high-contrast warning banner (`--warn-bg` / `--warn-fg`, `>= 4.5:1`) showing exact literal guidance: `Ephemeral Storage Detected (overlayfs): Mount -v kanban_data:/var/lib/kanban/data to persist data across container removal` plus a 1-click `Copy docker run command` button (`docker run -d -p 8080:8080 -v kanban_data:/var/lib/kanban/data kanban:latest`).
     - When `persistent_volume === true`: calm `Persistent Volume Mounted` badge displaying `data_mount_point` (`/var/lib/kanban/data`) and `data_mount_fstype` (`ext4` / `xfs`) for `SERVER_ADMIN` (or `Persistent volume verified` for non-admin).
     - Sandbox disclosure row (`S2.2 item 5`): displays `Tier A Wasmtime: Active` and `Tier B nsjail CLI Sandbox: Disabled in Standalone (SANDBOX_UNAVAILABLE_IN_STANDALONE)` when `tier_b_sandbox_available === false`.
   - **Section 2 - Encrypted Database Backup (`SERVER_ADMIN` only):**
     - Passphrase input (`type="password"`, `autoComplete="new-password"`, `minLength={16}`, client strength/length hint `Minimum 16 characters; never stored on server`) + `[Download Encrypted Backup (.kbkp)]` button submitting `POST /api/v1/admin/standalone/backup` with `X-CSRF-Token` and triggering browser blob download (revoking temporary `blob:` URL immediately after click). Non-admin members see `Contact a Server Administrator to export backups or promote this instance.` and zero admin controls.
   - **Section 3 - 1-Click `docker-compose.yml` Export & Promotion Guide (`ComposeExportTab.tsx`, `SERVER_ADMIN` only):**
     - `[Download docker-compose.yml]` button + `[Copy .env.example]` button + 4-step monospace promotion checklist (`1. Generate secrets`, `2. Download encrypted backup`, `3. docker compose up -d postgres`, `4. kanban-ctl restore / pg_restore into external PostgreSQL 16`).

### Mandatory Feature Unit Tests
- **Test File(s):**
  - `kanban/tests/api/test_system_status.py`
  - `kanban/web/src/features/standalone/StandaloneStatusPanel.test.tsx`
- **Required Test Cases:**
  1. **Backend Status & Redaction (`test_system_status.py`):** Reading fixture `standalone_status.json` (`persistent_volume: false`, `fstype: "overlay"`) returns full fields to `SERVER_ADMIN` and nulls `data_mount_point`, `data_mount_fstype`, and `local_llm_endpoint_host` for a non-admin `MEMBER`.
  2. **Backend Encrypted Backup & Zero-Shell Security:** `POST /api/v1/admin/standalone/backup` with mocked `create_subprocess_exec` (`pg_dump`) produces a valid AES-256-GCM `.kbkp` payload that decrypts back to the exact mock dump bytes, rejects `passphrase` `< 16` chars (`422`), rejects `AAL1` or non-admin callers (`403`), rejects in `production_multi_container` mode (`409`), and never leaks `MASTER_KEK` or passphrase in response headers/logs.
  3. **Backend Compose Export Secret Audit:** `GET /api/v1/admin/standalone/compose-export` returns valid YAML containing `edge_net`, `app_net`, `data_net`, `mcp-server` (not on `data_net`), and zero substrings from `keyring.json`.
  4. **Frontend Ephemeral vs Persistent UI (`StandaloneStatusPanel.test.tsx`):** With `persistent_volume: false`, renders exact ephemeral warning and copies `docker run -d -p 8080:8080 -v kanban_data:/var/lib/kanban/data kanban:latest`; with `persistent_volume: true`, renders `Persistent Volume Mounted` (`ext4`).
  5. **Frontend Admin Gate & Passphrase Boundary:** When `is_server_admin: false`, backup form and compose download buttons are absent from DOM; when `is_server_admin: true`, a `15`-char passphrase disables/blocks submit with `role="alert"` (`Passphrase must be at least 16 characters`), while `16` chars posts with `X-CSRF-Token` and revokes the download `blob:` URL.
  6. **Keyboard A11y:** Clicking `⚠️` in `HeaderPills` opens `StandaloneStatusPanel` (replacing `Panel not available yet` fallback from `KB-P3-34`); `Tab` traps focus inside dialog; `Escape` closes and returns focus to `⚠️`.
- Coverage on touched Python and TypeScript files `>= 95%` lines/functions/branches/statements.
