### User Story
As a **Project Admin configuring ScriptRunner validators and AI/CLI transition gates**, I need **the Workflow Transition Studio UI (`/projects/:projectKey/settings/workflows`) matching the S14.4 wireframe with `(from_state -> to_state)` rule cards, drag-and-keyboard hook ordering, agent/Wasm selector, `allowed_mutable_fields` chips, `AAL2` step-up handling, and an interactive `[▶ Dry-Run Against Sample Ticket]` runner** so that **I can compose, audit, reorder, and dry-run synchronous Wasm hooks alongside `agy -p` / `codex -p` / `ollama` / `gemini` interceptors on breathable enterprise whitespace**.

**Requirement Traceability:** `S14.4` (Admin Workflow Transition Studio wireframe: `⚙️ Project KAN > Workflow & Transition Interceptors`, `[+ Add Transition Rule]`, `[ 🟣 In Review ] ========( 3 Active Hooks )========> [ 🟢 Done ]`, ordered `sync_validator` / `sync_mutator` / `agent_interceptor` rows, repo/MCP/mutable-field badges, `[▶ Dry-Run Against Sample Ticket]`), `S14.2` (`hook_kind`, `sort_rank`, `allowed_mutable_fields`, `failure_policy`, `manifest_sha256`), `S6.1` (spatial whitespace tokens), `S6.2` (`🤖` `<EmojiHint>`) | ScriptRunner & `#9`, `#15` | **Dependencies:** `KB-P5-17b`, `KB-P5-16`, `KB-P5-19b`, `KB-P3-34`

   - `kanban/web/src/features/workflows/WorkflowStudioPage.tsx`
   - `kanban/web/src/features/workflows/TransitionRuleCard.tsx`
   - `kanban/web/src/features/workflows/HookPipelineRow.tsx` (drag-and-drop via `@atlaskit/pragmatic-drag-and-drop` + accessible `Move up` / `Move down` keyboard buttons)
   - `kanban/web/src/features/workflows/AttachHookDialog.tsx` (creates/edits `sync_validator`, `sync_mutator`, or `agent_interceptor` hooks)
   - `kanban/web/src/features/workflows/DryRunDrawer.tsx` (`[▶ Dry-Run Against Sample Ticket]` interactive panel)
   - `kanban/web/src/features/workflows/api.ts` (typed client + TanStack Query hooks consuming `KB-P5-17b`, `KB-P5-16`, and `KB-P5-19b`)
   - `kanban/web/src/features/workflows/workflows.css` (uses `tokens.css` variables only; zero runtime CSS-in-JS; zero inline styles)
   - `kanban/web/src/app/routes.tsx` (wire `/projects/:projectKey/settings/workflows`)
2. **Endpoints Consumed (`KB-P5-17b`, `KB-P5-16`, `KB-P5-19b`):**
   - `GET /api/v1/projects/{project}/workflow-hooks`
   - `POST /api/v1/projects/{project}/workflow-hooks`
   - `PATCH /api/v1/workflow-hooks/{hook_id}`, `POST /api/v1/workflow-hooks/{hook_id}/enable`, `POST /api/v1/workflow-hooks/{hook_id}/disable`, `DELETE /api/v1/workflow-hooks/{hook_id}`
   - `POST /api/v1/projects/{project}/workflow-hooks/reorder`
   - `POST /api/v1/projects/{project}/workflow-hooks/dry-run`
   - `GET /api/v1/workspaces/{workspace}/agent-definitions` and `GET /api/v1/projects/{project}/repo-bindings`
3. **Layout & Wireframe Fidelity (`WorkflowStudioPage`, `TransitionRuleCard`, `HookPipelineRow` - S14.4):**
   - Non-admin guard: if caller's project capability set lacks `ADMIN`, renders the standard `Not found or no access` view (`S3.4` anti-enumeration parity) with zero write API calls.
   - Header: `⚙️ Project <KEY> > Workflow & Transition Interceptors` with primary button `+ Add Transition Rule`.
   - Transition Rule Card (`padding: var(--card-pad)`, section spacing `var(--section-gap)` `32px`):
     - Top arrow bar: `[ <from_state badge or '* Any State'> ] ========( <N> Active Hooks )========> [ <to_state badge> ]`.
     - Ordered hook rows (`min-height: var(--list-row-h)` `46px`, `gap: var(--card-gap)` `12px`):
       - Sync hook badge: `⚡ [Sync Wasm Validator]` or `⚡ [Sync Wasm Mutator]`, hook `name` in `--font-mono`, target latency `<25ms` budget pill, `Fail-Closed` / `Fail-Open (Warn)` badge, copyable truncated `manifest_sha256` chip, enable/disable switch, edit & detach actions.
       - Agent gate badge: `<EmojiHint emoji="🤖">` (`[CLI Agent Gate]`, `[Local Ollama Gate]`, `[SDK Agent Gate]`, or `[Remote WSS Gate]`), hook `name` + harness command summary (e.g., ``(`${context} | agy -p`)`` or `(`ollama/qwen2.5-coder`)`), timeout in seconds (`60s`), `Fail-Closed` / `Fail-Open (Warn)` badge, metadata subtitle `Repo: <slug> (:ro mount) | MCP: Read-Only (<KEY>) | Mutable Fields: [<chips>]`.
   - Reordering: dragging a hook row or pressing `Move up` / `Move down` optimistically reorders the list and calls `POST .../workflow-hooks/reorder`; rolls back cleanly with inline banner on `422 REORDER_SET_MISMATCH`.
4. **Attach / Edit Hook Dialog (`AttachHookDialog`):**
   - `from_state` (`* Any State` -> `null`, or specific project state) and `to_state` (required; prevents `from_state === to_state`).
   - `hook_kind` radiogroup: `Sync Wasm Validator`, `Sync Wasm Mutator`, `Agent Interceptor`.
   - Conditional fields:
     - Sync kinds: approved Wasm module selector (shows module name + `sha256`).
     - `agent_interceptor`: `AgentDefinition` selector grouped by harness (`in_app_sdk`, `cli_pipe`, `remote_runner`), displaying read-only summary of validated `cli_args` (`codex -p -s read-only`, `agy -p`), `repo_access_mode`, and `timeout_ms`.
   - `allowed_mutable_fields` multi-select restricted strictly to `MUTABLE_FIELD_UNIVERSE` (`labels`, `priority`, `assignees`, `start_date`, `due_date`, `cycle`, `custom_fields.<slug>`) for `sync_mutator` and `agent_interceptor` (disabled/empty for `sync_validator`); displays explicit note `summary, description_markdown, state, parent, and created_by are immutable to preserve zero-TOCTOU guarantees.`
   - Step-up handling: any `403 AAL2_REQUIRED` response on create/update/reorder/enable/disable/delete opens the `KB-P2-05a`/`KB-P2-05b` AAL2 verification modal and retries the mutation once upon elevation.
5. **Sample-Ticket Dry-Run Panel (`DryRunDrawer`):**
   - Opened by `[▶ Dry-Run Against Sample Ticket]` on any transition card.
   - Mode toggle: `Pick existing issue` (`issue_key` combobox) OR `Sample ticket` (`summary`, `description_markdown`, `priority`, `labels` form prefilled with a realistic template).
   - Calls `POST /api/v1/projects/{project}/workflow-hooks/dry-run` and renders ordered step results: `allowed` (`✅`), `mutated` (`✏️` + diff of `field_updates`), `rejected` (`🛑` + scrubbed `reason`), `error` (`⚠️`), and `skipped_async` (`🤖 Async gate - copy CLI command:` with a 1-click copyable `uv run kanban-agent validate-transition ...` snippet pre-populated for that agent and transition!), plus `would_commit` summary banner and per-hook `duration_us` formatted in `ms`.
6. **Security Invariants:** Zero `dangerouslySetInnerHTML`; all hook names, reasons, and `cli_args` rendered strictly as React text nodes; strict `style-src 'self'` compliance.
