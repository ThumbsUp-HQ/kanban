### User Story
As a **backend engineer**, I need **strictly typed SQLAlchemy 2.0 `DeclarativeBase` models for every Phase 1 table (zero `SQLModel`), an `RLSSessionFactory` that binds `SET LOCAL` session context per transaction and refuses unbound queries, and a typed `BaseRepository`** so that **Phase 2+ services query the Universal Object Graph with full `mypy --strict` safety and impossible cross-transaction RLS context leakage**.

**Requirement Traceability:** `S3.3` (`SET LOCAL` binding `app.principal_id`, `app.workspace_id`, `app.token_scopes`, `app.aal_level` under `kanban_app`), `S2.5` (`SQLAlchemy 2.0` + `asyncpg`; `SQLModel` explicitly banned), `S12.1` - `S12.3`, Requirement `#1`, `#13` | **Dependencies:** `KB-P1-14`, `KB-P1-16`

2. **Base Metadata, Enums & `LtreeType` (`database/models/base.py`, zero `sqlmodel`):**
   - `class Base(DeclarativeBase)` using `Mapped[...]` and `mapped_column(...)` exclusively (`mypy --strict` clean with SQLAlchemy 2.0 native typing).

   - Python `StrEnum` mirrors matching PostgreSQL enums verbatim: `ObjectKind` (9 values), `LinkKind` (13 values), `ViewLayout` (5 values), `RbacRole` (7 values), `InvalidLinkReason` (7 values), bound with `PG_ENUM(..., create_type=False)`.

4. **RLS Session Binder & Guard (`database/session.py`):**
   - Exceptions: `RLSContextError(RuntimeError)`, `UnboundRLSSessionError(RLSContextError)`, `RLSRoleViolationError(RLSContextError)`.
   - `@dataclass(frozen=True, slots=True) class RLSContext`: `principal_id: UUID`, `workspace_id: UUID`, `token_scopes: tuple[str, ...] = ()`, `aal_level: Literal[1, 2] = 1`. `__post_init__` validates `aal_level in (1, 2)` and every scope matches `^[a-z0-9][a-z0-9:._-]{0,63}$` (rejects commas or whitespace with `ValueError`).
   - `async def bind_rls_context(session: AsyncSession, ctx: RLSContext) -> None`:
     - Raises `RLSContextError` if `not session.in_transaction()`.
     - Executes one round-trip matching S3.3 verbatim:
       ```sql
       SELECT set_config('app.principal_id', :principal_id, true),
              set_config('app.workspace_id', :workspace_id, true),
              set_config('app.token_scopes', :token_scopes, true),
              set_config('app.aal_level',    :aal_level,    true)
       ```
       passing `str(ctx.principal_id)`, `str(ctx.workspace_id)`, `",".join(ctx.token_scopes)`, `str(ctx.aal_level)` inside an internal `_binding_in_progress` flag, then sets `session.info["rls_bound"] = True` and `session.info["rls_context"] = ctx`.
   - Event guards registered on `RLSSessionFactory`'s `async_sessionmaker`:
     - `do_orm_execute` hook: raises `UnboundRLSSessionError` if `not session.info.get("rls_bound", False)` and `not session.info.get("_binding_in_progress", False)`.
     - `after_transaction_end` hook: when `transaction.parent is None`, pops `"rls_bound"` and `"rls_context"` from `session.info` so any subsequent statement on that session without re-binding raises `UnboundRLSSessionError`.
   - `class RLSSessionFactory`:
     - `create_rls_engine(dsn: str, *, pool_size: int = 10, max_overflow: int = 10) -> AsyncEngine`.
     - `async def verify_non_bypass_role(self) -> None`: queries `SELECT rolsuper, rolbypassrls FROM pg_roles WHERE rolname = current_user` and raises `RLSRoleViolationError` if either is `True` (called at app startup so misconfigured `kanban_migrator`/`postgres` credentials fail closed immediately).
     - `@asynccontextmanager async def session(self, ctx: RLSContext) -> AsyncIterator[AsyncSession]`: opens `AsyncSession(expire_on_commit=False)`, begins transaction, calls `bind_rls_context(session, ctx)`, yields, commits on clean exit, rolls back on exception.

5. **Typed Repository Base (`database/repositories.py`):**
   - `class BaseRepository(Generic[TModel])`: initialized with `(session: AsyncSession, model: type[TModel])`; verifies `session.info.get("rls_bound") is True` (`UnboundRLSSessionError` otherwise); provides `async get_by_id(entity_id: UUID) -> TModel | None`, `async list_all(*, limit: int = 100, offset: int = 0) -> Sequence[TModel]` (`limit` bounded `1..500`), `add(entity: TModel) -> TModel`, `async delete(entity: TModel) -> None`, `async flush() -> None`.

### Mandatory Feature Unit Tests
- **Test File(s):** `database/tests/test_p1_17_models.py`, `database/tests/test_p1_17_rls_session.py`, `database/tests/test_p1_17_repositories.py`
- **Required Test Cases:**
  1. Positive (ORM schema parity): compare `Base.metadata.tables.keys()` against `pg_tables` in `public` (excluding `alembic_version` and `activity_records_y*` child partitions) -> exact 1:1 set equality across all 31 tables; perform round-trip ORM `INSERT` + `SELECT` for `Issue`, `Doc`, `Page`, `Sticky`, `View`, `ObjectLink`, verifying `Computed` SHA-256 / `search_tsv` / `effective_mask` columns populate without being sent in `INSERT`.
  2. Positive (`SET LOCAL` binding & isolation): open `RLSSessionFactory` (`pool_size=1`, `max_overflow=0` as `kanban_app` in `@pytest.mark.committed_db`); run txn 1 bound to `U_ws1` -> reads `WS1` issues and `0` `WS2` issues; run txn 2 on the same pooled connection bound to `U_ws2` -> reads `WS2` issues and `0` `WS1` issues; open a raw connection from the same pool without binding -> `current_setting('app.principal_id', true)` is `''`/NULL and `SELECT count(*) FROM issues` returns `0`.
  3. Security (unbound session guard & role check): executing `await session.execute(select(Issue))` on a session from `RLSSessionFactory` before `bind_rls_context` or after `commit()` raises `UnboundRLSSessionError` before hitting PostgreSQL; calling `bind_rls_context` outside a transaction raises `RLSContextError`; calling `verify_non_bypass_role()` on a superuser or `kanban_migrator` engine raises `RLSRoleViolationError`, while `kanban_app` and `app_rls_reader` pass.
  4. Negative/validation: `RLSContext` with `aal_level=3` or `token_scopes=("issue:read,admin",)` raises `ValueError`; `LtreeType` with `"bad-hyphen-label"` raises `ValueError`; `BaseRepository.list_all(limit=501)` or `limit=0` raises `ValueError`; instantiating `BaseRepository` with an unbound `AsyncSession` raises `UnboundRLSSessionError`.
  5. Supply-chain check: `assert "sqlmodel" not in sys.modules` and `grep` / `importlib.metadata` confirms `sqlmodel` is not installed.
  - Non-pool-reuse tests run under the KB-P0-05 clean-DB `SAVEPOINT` harness (using `join_transaction_mode="create_savepoint"` + `SET LOCAL ROLE kanban_app` + `bind_rls_context`); touched-module coverage `>= 95%`.
