### User Story
As an **engineer or administrator managing personal agents, project/workspace CI tokens, cross-workspace bots (`meatloaf-bot`), and headless SSH CLI tools**, I need **RFC 8628 Device-Code browser approval (`/activate`) plus a breathable Web UI Studio for minting, scoping, copying ready-to-use `.gemini/settings.json` / `mcp_config.json` snippets, and revoking Personal, Project, Workspace, and Global MCP keys and OAuth grants** so that **every credential and headless session is approved with explicit visual scope boundaries and revocable in one click.**

**Requirement Traceability:** `S11.1` (RFC 8628 Device Authorization Grant, Scopable Personal/Project/Workspace/Global Keys, RFC 7009 / Self-Service Deauth), `S6.1` (breathable whitespace tokens), `S6.2` (`<EmojiHint>` `🛡️`, `🤖`, `🔒`), requirement `#1`, `#6`, `#12`, `#15` | **Dependencies:** `KB-P4-14`, `KB-P4-15`, `KB-P4-02b`, `KB-P3-34`

### Scoped Technical Actions
1. **Target Files:**
   - `database/migrations/versions/<rev>_oauth_device_codes.py` - `oauth_device_codes` (`device_code_sha256`, `user_code` `XXXX-XXXX` Base-20 consonant-safe alphabet, `resource`, `requested_scopes`, `approved_grant_id`, `expires_at` TTL `600s`, `interval_sec = 5`, `last_polled_at`).
   - `kanban/oauth/device.py` & `kanban/api/v1/oauth.py` - `POST /oauth/device/authorize`, `GET/POST /activate` (approval UI route), and `POST /oauth/token` (`grant_type=urn:ietf:params:oauth:grant-type:device_code` returning `authorization_pending`, `slow_down` if polled `< 5s`, `access_denied`, `expired_token`, or the scoped JWT + refresh token). Advertise `device_authorization_endpoint` in `/.well-known/oauth-authorization-server`.
   - `kanban/web/src/features/settings/McpAccessStudio.tsx` - unified breathable settings surface mounted at:
     - `/settings/mcp` (Personal User Keys & Connected OAuth Apps),
     - `/projects/:projectKey/settings/mcp` (Project-Scoped Bot Keys, `PROJECT_ADMIN`),
     - `/workspaces/settings/mcp` (Workspace Bot Keys & Pending OAuth Client Approvals, `WORKSPACE_ADMIN`),
     - `/admin/mcp` (Global Cross-Workspace Bot Keys e.g. `meatloaf-bot`, `SERVER_ADMIN`).
   - `kanban/web/src/features/settings/McpConfigSnippetModal.tsx` - one-time plaintext key reveal (`byte[]` / React state cleared on close) + interactive **Config Snippet Generator** with tabs for `Gemini CLI (.gemini/settings.json)`, `Antigravity (mcp_config.json)`, and `Claude Code / Codex` across **Global** (`/mcp/{s}`), **Workspace** (`/mcp/{s}/w/{slug}`), and **Project** (`/mcp/{s}/w/{slug}/p/{key}`) URLs.
   - `kanban/web/src/features/oauth/DeviceActivatePage.tsx` - `/activate` user-code entry + Scope/Tier/Project approval screen (`AAL2` step-up enforced when `resource` is `/mcp/admin`).
2. **UI Spacing, `<EmojiHint>` & Security Invariants:**
   - Uses S6.1 breathable spacing (`--prose-pad: 32px 40px`, `--prop-row-h: 38px`, `--section-gap: 32px`) and `<EmojiHint>` badges (`🛡️` showing exact scope tier `Global` / `Workspace: kanban` / `Project: KANBA`, `🤖` for `service_bot` principal, `🔒` when restricted by `allowed_tools` or `allowed_cidrs`).
   - Plaintext `kb_*` secret is shown **once** inside `McpConfigSnippetModal` immediately after `POST`, never stored in `localStorage`/`sessionStorage`, and wiped from component state upon modal close; table rows show only `kb_agt_...<display_hint>`.
   - Clicking `[Revoke]` opens an inline confirmation bar (`[Cancel]` focused first, `[Confirm Revoke]`) calling `DELETE /api/v1/auth/mcp-keys/{id}`, `DELETE /api/v1/admin/mcp-keys/{id}`, or `DELETE /api/v1/auth/oauth-grants/{id}`, immediately marking the row `Revoked`.

### Mandatory Feature Unit Tests
- **Test File(s):**
  - Backend: `kanban/tests/oauth/test_device_flow.py`
  - Frontend Unit (`vitest` `>= 95%` coverage): `kanban/web/src/features/settings/__tests__/McpAccessStudio.test.tsx`, `kanban/web/src/features/oauth/__tests__/DeviceActivatePage.test.tsx`
  - E2E (`Playwright`): `kanban/web/e2e/mcp-access-studio.spec.ts`
- **Required Test Cases:**
  1. Positive (RFC 8628 Device Approval): CLI calls `POST /oauth/device/authorize` for `/mcp/agent` -> polls `/oauth/token` receiving `400 authorization_pending` -> user visits `/activate`, enters `WDJB-MJHT`, narrows scope to `Project: KANBA` + `agent:read`, clicks `Approve` -> next poll receives `ES256` JWT locked to `aud=/mcp/agent` and `allowed_projects=[KANBA]`.
  2. Security (Device Flow Abuse): polling faster than `5s` returns `400 slow_down` and increments required interval; brute-forcing invalid `user_code` > 5 times per IP/session triggers rate limit (`429`); approving `/mcp/admin` at `AAL1` prompts `AAL2` Passkey/TOTP step-up before issuing grant; expired code (`601s`) returns `expired_token`.
  3. Positive (Studio Mint + Snippet Generator + Memory Wipe): minting a `Project: KANBA` key renders `McpConfigSnippetModal` with exact `.gemini/settings.json` JSON (`"url": "https://.../mcp/agent/w/kanban/p/KANBA"`), copies via clipboard mock, and closing the modal removes the plaintext key from DOM (`kb_agt_...` full string absent; only 4-char `display_hint` remains).
  4. Positive & Security (Deauth / Revoke): revoking a personal key and disconnecting a `Claude Code` OAuth grant calls the exact `DELETE` endpoints with `X-CSRF-Token`, updates UI state, and hostile client names (`<img src=x onerror=alert(1)>`) render strictly as escaped text.
