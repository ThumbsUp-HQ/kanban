### User Story
As a **project administrator**, I need **the `projects` table exactly as specified, per-project workflow states grouped into the 5 Plane state groups, per-project priorities seeded with Plane defaults and emojis, and labels with optional exclusive groups** so that **issues (KB-P1-05) can reference a valid state, priority, and label set scoped to their own project**.

**Requirement Traceability:** `S12.2` (`projects` DDL), `S7.2 8c` (priorities), `8f` (`modules_enabled`), `8i` (labels + `exclusive_group`), `8p` (`state.group IN ('completed','cancelled')`, auto-archive), Requirement `#8` | **Dependencies:** `KB-P1-02`

### Scoped Technical Actions
1. **Target Files:**
   - `database/migrations/versions/p1_04_projects.py`
   - `database/migrations/sql/p1_04_projects.up.sql`, `database/migrations/sql/p1_04_projects.down.sql`
2. **`projects` verbatim from S12.2** (identifier regex `^[A-Z][A-Z0-9]{1,9}$`, `description_markdown` `<= 524288` bytes, `modules_enabled DEFAULT FALSE`, `issue_seq_counter BIGINT DEFAULT 0`, `auto_archive_days BETWEEN 1 AND 365`, `UNIQUE (workspace_id, identifier)`, composite FK to `objects`):
   ```sql
   CREATE TABLE projects (
       id                      UUID PRIMARY KEY,
       object_type             object_kind NOT NULL DEFAULT 'project' CHECK (object_type = 'project'),
       workspace_id            UUID NOT NULL,
       identifier              TEXT NOT NULL CHECK (identifier ~ '^[A-Z][A-Z0-9]{1,9}$'),
       name                    TEXT NOT NULL,
       description_markdown    TEXT NOT NULL DEFAULT '' CHECK (octet_length(description_markdown) <= 524288),
       modules_enabled         BOOLEAN NOT NULL DEFAULT FALSE,
       issue_seq_counter       BIGINT NOT NULL DEFAULT 0,
       auto_archive_days       INTEGER CHECK (auto_archive_days IS NULL OR auto_archive_days BETWEEN 1 AND 365),
       UNIQUE (workspace_id, identifier),
       FOREIGN KEY (id, object_type) REFERENCES objects (id, object_type) ON DELETE RESTRICT
   );
   ALTER TABLE objects ADD CONSTRAINT objects_project_fk
       FOREIGN KEY (project_id) REFERENCES projects(id) ON DELETE RESTRICT DEFERRABLE INITIALLY DEFERRED;
   ```
   - Trigger `projects_spine_match_biu`: `objects.workspace_id = NEW.workspace_id` and `objects.canonical_key = NEW.identifier` -> else `PROJECT_SPINE_MISMATCH`.
   - Trigger `projects_seq_guard_bu`: a direct `UPDATE` that decreases `issue_seq_counter` raises `ISSUE_SEQ_DECREASE_FORBIDDEN`.
3. **`workflow_states`:**
   ```sql
   CREATE TABLE workflow_states (
       id            UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id  UUID NOT NULL,
       project_id    UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       name          TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 100),
       state_group   TEXT NOT NULL CHECK (state_group IN ('backlog','unstarted','started','completed','cancelled')),
       color_hex     TEXT NOT NULL CHECK (color_hex ~ '^#[0-9A-Fa-f]{6}$'),
       sort_order    INTEGER NOT NULL DEFAULT 0,
       is_default    BOOLEAN NOT NULL DEFAULT FALSE,
       UNIQUE (project_id, name)
   );
   CREATE UNIQUE INDEX workflow_states_one_default ON workflow_states (project_id) WHERE is_default;
   ```
4. **`project_priorities` (S7.2 8c column list verbatim):**
   ```sql
   CREATE TABLE project_priorities (
       id          UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id UUID NOT NULL,
       project_id  UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       slug        TEXT NOT NULL CHECK (slug ~ '^[a-z][a-z0-9_-]{0,31}$'),
       label       TEXT NOT NULL CHECK (char_length(btrim(label)) BETWEEN 1 AND 50),
       emoji       TEXT CHECK (emoji IS NULL OR char_length(emoji) BETWEEN 1 AND 8),
       color_hex   TEXT NOT NULL CHECK (color_hex ~ '^#[0-9A-Fa-f]{6}$'),
       sort_order  INTEGER NOT NULL,
       is_default  BOOLEAN NOT NULL DEFAULT FALSE,
       UNIQUE (project_id, slug)
   );
   CREATE UNIQUE INDEX project_priorities_one_default ON project_priorities (project_id) WHERE is_default;
   ```
5. **`project_labels` (S7.2 8i):**
   ```sql
   CREATE TABLE project_labels (
       id              UUID PRIMARY KEY DEFAULT uuidv7(),
       workspace_id    UUID NOT NULL,
       project_id      UUID NOT NULL REFERENCES projects(id) ON DELETE RESTRICT,
       name            TEXT NOT NULL CHECK (char_length(btrim(name)) BETWEEN 1 AND 100),
       color_hex       TEXT NOT NULL CHECK (color_hex ~ '^#[0-9A-Fa-f]{6}$'),
       exclusive_group TEXT CHECK (exclusive_group IS NULL OR exclusive_group ~ '^[a-z][a-z0-9_-]{0,31}$'),
       UNIQUE (project_id, name)
   );
   ```
   For all 3 child tables, trigger `*_workspace_match_biu` sets/validates `NEW.workspace_id = projects.workspace_id` (`PROJECT_CHILD_WORKSPACE_MISMATCH`).
6. **Seeding trigger `projects_seed_defaults_ai` (AFTER INSERT ON projects, SECURITY DEFINER):**
   - States (name, group, color, sort, default): `Backlog/backlog/#A3A3A3/0/TRUE`, `Todo/unstarted/#3B82F6/1`, `In Progress/started/#F59E0B/2`, `Done/completed/#16A34A/3`, `Cancelled/cancelled/#DC2626/4`.
   - Priorities (slug, label, emoji, color, sort, default) = Plane defaults per S7.2 8c: `urgent/Urgent/🔥/#DC2626/0`, `high/High/⚡/#F97316/1`, `medium/Medium/🔹/#EAB308/2`, `low/Low/💤/#22C55E/3`, `none/None/NULL/#A3A3A3/4/TRUE`.
   - Colors and state names are seed values chosen by this ticket (the spec fixes only slugs/labels/emojis).
7. **Deletion guard `workflow_states_group_guard_bd`:** deleting the last state of group `completed` or `cancelled` in a project raises `LAST_TERMINAL_STATE_REQUIRED` (S7.2 8p archive rule depends on these groups existing).
8. **Down migration:** drops triggers/functions, `project_labels`, `project_priorities`, `workflow_states`, constraint `objects_project_fk`, `projects`.
