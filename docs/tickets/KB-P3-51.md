### User Story
As a **project contributor capturing rapid triage scratchpads and architecture notes on Project Overview or Workspace Stickies**, I need **a breathable 6-palette Markdown Stickies grid whose `1,000 ms` idle heuristic surfaces a non-intrusive `💡📄` promotion banner (with `>= 1.5x` snooze memory) and 1-click ACL-preserving `Promote to Doc` conversion into a Promoted Doc Stub** so that **fast notes stay friction-free when short and graduate cleanly into permanent Docs without privilege widening when they grow into specs**.

**Requirement Traceability:** `S8.1 item 2` (6-palette `amber`, `mint`, `sky`, `lavender`, `coral`, `slate` Stickies on Project Overview & Workspace `/stickies`), `S8.2` (`1,000ms` idle debounce, 5 complexity triggers, `💡📄` banner, `promotion_snoozed_at_length` `>= 1.5x` snooze rule, `POST /api/v1/stickies/{id}/promote-to-doc`, Promoted Doc Stub `[📄 Open Doc]` / `[Unarchive Copy]`), `S6.1` (`--card-pad`, `--space-5`, `--sticky-*`), `S6.2` (`💡📄` `stickyPromotion`, `🛡️` `access`), requirement `#11` | **Dependencies:** `KB-P3-34` (routes `/projects/:projectKey/overview` & `/stickies`), `KB-P3-45` (`MarkdownEditor`), `KB-P3-15` (Stickies & Promote REST API)

2. **Exact `S8.2` Complexity Heuristic & `>= 1.5x` Snooze Engine (`stickyHeuristic.ts`):**
   ```ts
   export type StickyColorToken = 'amber' | 'mint' | 'sky' | 'lavender' | 'coral' | 'slate';
   export interface StickyComplexityEvaluation {
     exceeded: boolean;
     reasons: string[];      // e.g. ["740 chars (> 600)", "2 headings (>= 2)"]
     charLength: number;     // Unicode code-point count matching PG char_length()
     shouldShowBanner: boolean;
   }
   ```
   - `STICKY_IDLE_DEBOUNCE_MS = 1000` (injectable timer for unit tests).
   - Evaluates `bodyMarkdown` (ignoring `#` headings and `[links](...)` inside fenced code blocks when counting prose headings/links):
     1. `charLength > 600` (`[...bodyMarkdown].length > 600`) -> reason `"<N> chars (> 600)"`.
     2. `lineCount > 10` (`bodyMarkdown.split('\n').length > 10`) -> reason `"<N> lines (> 10)"`.
     3. `headingCount >= 2` (`>= 2` ATX headings `^#{1,6}\s+`) -> reason `"<N> headings (>= 2)"`.
     4. Contains a GFM pipe table, a fenced ```` ```mermaid ```` or ```` ```svg ```` block, OR any fenced code block whose inner line count is `> 6` -> reason `"table, diagram, or >6-line code block"`.
     5. `outboundLinkCount >= 3` (`>= 3` Markdown links or `https?://` autolinks) -> reason `"<N> links (>= 3)"`.
   - `exceeded = reasons.length > 0`.
   - **Snooze Suppression (`S8.2`):** Given `promotionSnoozedAtLength: number | null`:
     - If `promotionSnoozedAtLength === null`, `shouldShowBanner = exceeded`.
     - If `promotionSnoozedAtLength !== null`, `shouldShowBanner = exceeded && charLength >= Math.ceil(promotionSnoozedAtLength * 1.5)` (stays silent unless the sticky grows by at least `+50%` over the snoozed length).
3. **6-Palette Grid & Card Ergonomics (`StickiesGrid.tsx`, `StickyCard.tsx`):**
   - Queries `useQuery(qk.stickies(projectKey))` (`GET /api/v1/projects/{projectKey}/stickies`, or `/api/v1/stickies` on `/stickies`).
   - CSS Grid: `grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))` (1 column on `390px` mobile), `gap: var(--space-5)` (`20px`), card `padding: var(--card-pad)` (`16px 18px`), `border-radius: var(--radius-lg)`.
   - Palette tokens (`amber`, `mint`, `sky`, `lavender`, `coral`, `slate`) apply CSS classes `.sticky-card--amber` .. `.sticky-card--slate` referencing strictly `var(--sticky-amber)` .. `var(--sticky-slate)` from `KB-P3-30` `theme.css` (zero inline `style` hex strings; WCAG AA `>= 4.5:1` text contrast in both Light and Dark themes).
   - Card header: 6-swatch `role="radiogroup" aria-label="Sticky color"` (arrow-key operable, optimistic `PATCH /api/v1/stickies/{id}` `{ color_token }`), `<EmojiHint kind="access" variant="interactive">` (`🛡️`, dispatching `kb:open-access-inspector`), and `⋯` menu containing `Convert to Doc` (manual promotion regardless of snooze) and `Delete Sticky`.
   - Card body: `<MarkdownEditor surface="sticky" maxBytes={65536} .../>`. After `1,000ms` of typing inactivity, runs `evaluateStickyComplexity` and syncs changes via `PATCH /api/v1/stickies/{id}` (`If-Match` ETag).
4. **`💡📄` Non-Modal Promotion Banner (`StickyPromotionBanner.tsx`) & Atomic Promote:**
   - Rendered in the card footer when `shouldShowBanner === true` and `promoted_to_doc_id === null` (or when server `promotion_recommended === true` and snooze threshold is met).
   - Layout: `<EmojiHint kind="stickyPromotion">` (`💡📄`, hover/focus popover dynamically listing exact matched reasons: `Exceeded Sticky complexity (<reasons joined>) - click Promote to Doc to convert while preserving exact ACLs`) + concise text `Growing into a spec` + `[Promote to Doc ->]` button + `[Snooze]` button.
   - Clicking `[Snooze]` executes optimistic `PATCH /api/v1/stickies/{id}` `{ promotion_snoozed_at_length: charLength }`, immediately hiding the banner with zero modal interruption.
   - Clicking `[Promote to Doc ->]` (or manual `Convert to Doc`) calls `POST /api/v1/stickies/{id}/promote-to-doc` (`KB-P3-15`, single-transaction Doc+Page creation copying `resource_acl_entries` verbatim and creating `PROMOTED_TO_DOC` link), invalidates `qk.stickies(projectKey)` and `qk.docsTree(projectKey)`, announces `Promoted sticky to Doc` with ACL preservation confirmation, and transitions the card in-place into `PromotedStickyStub`.
5. **Promoted Doc Stub (`PromotedStickyStub.tsx`, `S8.2`):**
   - Rendered whenever `sticky.promoted_to_doc_id !== null`.
   - Displays compact muted card header (`📄 Promoted to Doc` + `🛡️` pill), 2-line plain-text summary preview, `[📄 Open Doc]` link (`/projects/:projectKey/docs/:promotedPageId`), and `[Unarchive Copy]` button (`POST /api/v1/stickies/{id}/unarchive-copy` creating a fresh editable sticky copy while keeping the promoted Doc intact).

### Mandatory Feature Unit Tests
- **Test File(s):**
  - `kanban/web/src/features/stickies/stickyHeuristic.test.ts`
  - `kanban/web/src/features/stickies/StickyCard.test.tsx`

- **Required Test Cases:**
  1. **All 5 `S8.2` Triggers (`stickyHeuristic.test.ts`):**
     - `600` chars -> `exceeded: false`; `601` chars -> `exceeded: true` (`"601 chars (> 600)"`).
     - `10` lines -> `false`; `11` lines -> `true` (`"11 lines (> 10)"`).
     - `1` heading -> `false`; `2` headings -> `true` (`"2 headings (>= 2)"`); `# comment` inside ```` ```sh ```` ignored.
     - GFM pipe table, ```` ```mermaid ```` block, ```` ```svg ```` block, and `7`-line ```` ```py ```` block each trigger `true`; `6`-line ```` ```py ```` block stays `false`.
     - `2` links -> `false`; `3` links -> `true` (`"3 links (>= 3)"`).
  2. **Snooze `>= 1.5x` Boundary Math:** Snoozed at `promotionSnoozedAtLength = 620`: at `charLength = 929` (`< 930`) `shouldShowBanner === false`; at `charLength = 930` (`620 * 1.5`) `shouldShowBanner === true`; `promotionSnoozedAtLength = 0` or `null` shows whenever `exceeded === true`.
  3. **`1,000 ms` Idle Debounce:** Typing a `650`-char note with fake timers does NOT show `StickyPromotionBanner` at `999ms`; advancing to `1000ms` renders `💡📄` `Growing into a spec` and its `<EmojiHint>` popover text `650 chars (> 600)`.
  4. **Snooze & Promote Actions:** Clicking `[Snooze]` sends `PATCH` with `promotion_snoozed_at_length: 650` and hides banner immediately; clicking `[Promote to Doc ->]` calls `POST /api/v1/stickies/{id}/promote-to-doc` with `X-CSRF-Token`, renders `PromotedStickyStub` with `[📄 Open Doc]` and `[Unarchive Copy]`, and `[Unarchive Copy]` posts `/unarchive-copy`.
  5. **Palette & Security:** Selecting `mint` in the 6-color `radiogroup` updates `.sticky-card--mint` class without setting any `style` attribute; hostile body `<img src=x onerror=alert(1)>` creates zero `<img>` elements; `65,537`-byte edit is blocked by `maxBytes={65536}`.
- Coverage on touched files under `kanban/web/src/features/stickies/` `>= 95%` lines/functions/branches/statements.
